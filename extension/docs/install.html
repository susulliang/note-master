Ecovacs Ticket DOM Scraper · Install Guide

Manifest V3 browser extension. Loaded as an unpacked extension in Chrome and Edge (one procedure, both browsers). Tier-2 MV3

What it does. Scrapes the live DOM of two open browser tabs every ~15s:
  • your CCaaS softphone (Amazon Connect CCP, Five9, Genesys, Zendesk, Talkdesk, Freshdesk)
  • your Salesforce Case / Contact / Console tab (Lightning, Classic, Visualforce).
Each scrape is pushed to the open Ticket Notes web-app tab on localhost or *.vercel.app, and auto-fills matching form fields (customer name, phone, email, serial, model, case number, …). Nothing is uploaded anywhere.

1 · Install (Chrome & Microsoft Edge)

  1. Open the extension management page:
    Chrome: navigate to chrome://extensions.
    Edge: navigate to edge://extensions.
  2. In the top-right corner, turn on the Developer mode toggle.
  3. Click Load unpacked (Chrome) or Load unpacked extension (Edge, in the top toolbar that appeared after turning Developer mode on).
  4. Select the extension/ folder inside this repo. Confirm the folder contains manifest.json.
  5. Done. A new green phone-and-ticket icon appears in the browser toolbar. Pin it for fast access.
  6. (Optional) Open the popup once, then click the Extension ID at the bottom to copy it. Paste this ID into extensionId field in the Ticket Notes settings if you want it to skip the fallback bridge.

2 · How to use

  1. Open three browser tabs in the same profile:
    • CCP tab — your Amazon Connect CCP or equivalent softphone; answer calls as normal.
    • Salesforce tab — open the Case/Contact you are working on. Make sure it's visible so the scraper can read labelled fields.
    • Ticket Notes tab — the note-master app (localhost / Vercel). Keep it open in the same profile.
  2. Start the call as usual. Whenever the CCP loads a contact, or whenever Salesforce finishes loading the Case record, the extension auto-captures the DOM within ~3 seconds and merges the fields.
  3. Click the extension icon (popup) to:
    • See the latest captured CCP + Salesforce fields.
    • Force a Re-scrape both tabs.
    • Force Push to open Ticket Notes (happens automatically if Auto-push is ON).
    • Toggle Auto-push on/off.
  4. Back in the Ticket Notes page, each pushed field gets a "Extension DOM" yellow source badge, exactly like regex/LLM fields. Bold-highlighted notes and Hang Up continue to work on top.

5 · Troubleshooting

  • No CCP tab found. Confirm your softphone URL matches one in manifest.json → content_scripts[0].matches. If you use a branded domain, add it in manifest.json and reload the extension (button on chrome://extensions card).
  • Salesforce fields are empty. Salesforce lazy-loads details panels; click the "Re-scrape both tabs" button in the popup once the Case layout is fully rendered, or wait 7 seconds — the scraper fires twice on load with a delay.
  • Push to Ticket Notes says "no open tab". The Ticket Notes tab must be in the same browser profile, and running on localhost, 127.0.0.1, or *.vercel.app. For a custom domain, add it to both host_permissions and the bridge.js content-script matches in manifest.json.
  • Amazon Connect contact attributes missing. Make sure the connect-streams library is loaded in the CCP (it usually is — the Connect CCP bootstraps it). The DOM fallback will still fill basic fields if it's not.
  • Edge popup shows "Could not reach extension background". First click of the session can race with service worker wake; click any button once and it will recover.

6 · Uninstall

  1. Open chrome://extensions or edge://extensions.
  2. Find the Ecovacs Ticket DOM Scraper card.
  3. Click Remove and confirm.

7 · Packaging for self-distribution (optional)

To distribute the `.crx` / `.nex` internally (instead of "Load unpacked"):

# Chrome: chrome://extensions → Pack extension → select extension/ folder.
# Edge:   edge://extensions  → Pack extension → select extension/ folder.
# Both browsers produce a signed .crx / .nex plus a .pem key file (keep safe for updates).

For enterprise rollout via Chrome Web Store / Edge Add-ons, the manifest already carries the required minimum_chrome_version: 114 and MV3 shape; zip the extension/ folder and upload to the respective developer dashboards.
