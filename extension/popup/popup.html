      1. Open a browser tab with https://note-master-roan.vercel.app/.
      2. Open Ecovacs Note Helper extension popup on ANY tab.
      3. Switch to this Bridge → Event log panel.
      4. On the Ticket Notes page click Hang Up → 🔎 Diagnostics → click its 🔁 Try probing bridge again action.
      5. Back in popup Bridge → Event log, click Refresh. Within 2s you should see a row bridge:handshake_request_received → that means bridge.js content script is injected on vercel and the roundtrip works. If you do NOT see that row: the content script isn't running → go to chrome://extensions, click 🔄 Reload on Ecovacs Note Helper, refresh note-master-roan.vercel.app, repeat.
      6. For Salesforce field-writes: click 📤 Push to Salesforce Case. Within seconds Bridge → Event log will show sf:apply:start → sf:apply:targetTab → then per-field wasSectionFound: false with the exact reason (layout not found / inline-edit missing / read-only). Copy/paste that row into a bug report and we can tune the selectors.
