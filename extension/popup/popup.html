      You are running: —

      1. Open the extensions manager at:
        • Edge: type edge://extensions in the address bar.
        • Chrome: type chrome://extensions in the address bar.
      2. Toggle Developer mode top-right. On the Ecovacs Note Helper card click 🔄 Reload. The card should now show v0.1.27 or newer.
      3. Open a tab at https://note-master-roan.vercel.app/ and leave it active (not discarded).
      4. Open this popup → Bridge → Tabs snapshot → find the vercel row → click 🔬 Injectable?. Within 2s it flips to YES/NO.
      5. If Injectable is YES but bridge version: null → cache issue. Click 🚀 Inject bridge now (uses scripting.executeScript, bypasses document_start content-script registration) → wait 3s → re-click 🔬 Injectable? and it should now show bridge version 0.1.27. The web app Push button goes green within 10s (next heartbeat).
      6. If Injectable is BLOCKED:host-permissions → the installed manifest is not the one you just edited (browser still has an older loaded build), OR the optional_host_permissions all_urls wasn't granted for this origin. Go to Details → Site access on the extension card and confirm.
      7. For Salesforce "nothing auto-fills": with a full Lightning Case tab open (not inline-console), click 📤 Push to Salesforce Case on the Ticket Notes page. Then come to Bridge → Event log → you will see sf:apply:start / targetTab / ok+fieldSummary with per-field wasSectionFound. Copy the red rows if 0 fields wrote.
