# GOAT / GX / ZH - How do I restore the GOAT to default settings?

## Question

How do I restore the GOAT to default settings?

## Answer

(1) You can select Settings > Reset GOAT on the display.
 (2) Simultaneously long press Start and Recharge on the GOAT for 2 seconds. Please take note that this method retains the original PIN code after default settings have been restored.
