# Puis-je partager le WINBOT W2 ?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Puis-je partager le WINBOT W2 ?

## 答案 / Answer

W00168

Le WINBOT W2 peut prendre en charge plusieurs comptes, qui peuvent être liés via Bluetooth, mais un seul compte peut le contrôler. Par exemple, si un compte A est connecté pour contrôler le robot, un compte B ne peut pas le faire fonctionner. Le compte B ne peut se connecter et utiliser le WINBOT W2 qu'après la déconnexion du compte A de l'interface d'exploitation.
