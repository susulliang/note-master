# DEEBOT / T30 S / EN - Dust collection failed, no dust bag detected or the dust bag is full, how to deal with it?

## Question

Dust collection failed, no dust bag detected or the dust bag is full, how to deal with it?

## Answer

Dust collection failed
1. Ensure that the dust bag is installed correctly and the dust bin cover is closed in place.
2. Ensure that the gem is correctly placed on the station.
No dust bag was detected
1. Open the dust collection compartment cover and check if there is a dust bag installed. If not, please install it correctly.
2. If there is a dust bag, please remove it and reinstall it
Three: After replacing the new dust bag, it still alarms that the dust bag is full
1. Turn off and restart the machine, disconnect the station power supply and reconnect it
2. Check the firmware version of the machine. If there is a prompt to update, please update to the latest version
3. Ensure that the robot is in a charged state and observe after reinstalling the dust bag
