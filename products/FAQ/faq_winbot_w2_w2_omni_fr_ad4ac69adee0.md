# Un rappel indique que la pression d'air du WINBOT W2 est insuffisante.

## Question

Un rappel indique que la pression d'air du WINBOT W2 est insuffisante.

## Answer

Étape 1 : retirez le robot de la vitre.
Utilisez l'application pour contrôler et guider le robot jusqu'à une position où vous pouvez le retirer manuellement. Fixez à nouveau le robot sur la vitre pour commencer à nettoyer. Si vous utilisez le robot sans connexion à l'application, vous pouvez le connecter de deux façons :
1. Nous vous conseillons d'utiliser l'application pour scanner le code QR directement sur le robot et de suivre les instructions de connexion dans l'application.
2. Vous pouvez également sélectionner « Add manually » (Ajouter manuellement) dans l'application et sélectionner le bon modèle pour terminer la connexion.

Étape 2 : vérifiez le robot et les fenêtres.
1. Vérifiez que le patin de lavage est correctement installé, avec les côtés larges et étroits dans la bonne position.
2. Vérifiez si la vitre comporte des espaces. N'utilisez pas le WINBOT W2 sur des surfaces présentant des espaces, car ils peuvent entraîner une pression d'air insuffisante ou une défaillance.
3. Vérifiez si la vitre comporte des obstacles bas. Si tel est le cas, couvrez-les avant d'utiliser le WINBOT W2.
