# GOAT / GOAT G1 / ZH - How should I map if there is a narrow aisle in my garden?

## Question

How should I map if there is a narrow aisle in my garden?

## Answer

The positioning signal is weak in narrow aisles with a width of less than 2 m and a blocking high wall. The GOAT cannot mow in zigzags and is likely to get stuck when passing. Try to control the GOAT to be close to the boundary.
