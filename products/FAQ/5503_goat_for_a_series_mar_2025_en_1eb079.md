# 新增区域过程中为什么没有自动生成通道？ / Why no  paths generated during the ADD New Area ?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

新增区域过程中为什么没有自动生成通道？ / Why no  paths generated during the ADD New Area ?

## 答案 / Answer

MAP

（1）新增区域时请从已创建地图区域出发，保证准确识别到通道
（2）新增区域时请尽量从临近区域出发，横穿其他区域可能导致自动生成通道失败
（3）如无法自动生成通道，请手动添加一条通道
（4）增加通道时，尽量避免过于复杂的轨迹线

(1) When adding a new area, please start from the already created map area to ensure accurate identification of the path
(2) When adding new areas, please try to start from nearby areas as crossing other areas may cause path generat failed
(3) If the channel cannot be automatically generated, please manually add a path
(4) When adding paths, try to avoid overly complex trajectory lines as much as possible
