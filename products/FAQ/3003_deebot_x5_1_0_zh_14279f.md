# How to use the YIKO voice assistant? / 1. Open the App ＞ Enter the App operation page ＞ Settings in the upper right corner ＞ YIKO Settings ＞ enable Voice Assistant. Note: If you disable the YIKO voice assistant ＞ Voice Assistant, the DEEBOT AUTO button will turn yellow. 2. OK YIKO Voice Command Guide
2.1 In YIKO voice assistant, tap All to view all YIKO voice commands.
You can try saying things like "OK YIKO, clean the house" or "OK YIKO, increase suction power" to DEEBOT.
Note: ①YIKO is always learning new voice commands. Open the App to see what voice commands you can use. ② YIKO voice commands can be triggered within a 5 m range. ③ YIKO voice assistant currently supports the following offline functions. Other voice commands can only be used once connected to a network. OK YIKO, turn on Bluetooth and connect.
OK YIKO, start mapping.
OK YIKO, start cleaning.
OK YIKO, clean the house.
OK YIKO, return to the docking station.
OK YIKO, return to charge.
OK YIKO, leave the docking station.
OK YIKO, start docking station self-cleaning
OK YIKO, turn off Child Lock.
