# GOAT / GOAT G1 / ZH - Can I change the PIN code after it has been set?

## Question

Can I change the PIN code after it has been set?

## Answer

(1) You can change it in the App by going to Settings > More Settings > Security Settings > Change PIN Code
 (2) You can change it on the display by going to Settings > Change PIN Code
