## 问题 / Question

46

## 答案 / Answer

Vous pouvez essayer les solutions suivantes :

Pour éviter d'abîmer les meubles, le paramètre par défaut est 【Standard】, et maintient une distance de sécurité par rapport aux plinthes ou aux obstacles. Pour un nettoyage plus près, allez sur l'application : 「Paramètres avancés du ROBOT」→「TruEdge 3.0」→ Sélectionnez 【Extrême】. Le robot nettoiera alors plus près des plinthes.
2. Si vous avez déjà activé le [Mode Extrême], mais que vous trouvez toujours la distance trop grande, le capteur de bord est peut-être recouvert de poussière. Essuyez-le et réessayez.
3. Pour les plinthes spéciales comme l'acier inoxydable ou les finitions mates foncées, les capteurs peuvent être affectés. Le maintien d'une distance de sécurité par le robot est un comportement normal.
