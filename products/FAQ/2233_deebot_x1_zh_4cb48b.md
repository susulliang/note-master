# As the map has positioning issues such as overlapping or lost, DEEBOT cannot find the charging dock.

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

As the map has positioning issues such as overlapping or lost, DEEBOT cannot find the charging dock.

## 答案 / Answer

As the map has positioning issues such as overlapping or lost, DEEBOT cannot find the charging dock.

1. Whether the robot is trapped during the cleaning process and alerts. If so, please help to deal with it.
2. When the map has been created, if it is confused/overlaid/tilted or inconsistent with the original created map, you can try to restore the map.
3. If the map recovery is invalid, it is recommended that you use Quick Mapping to recreate the map after deleting it.
Note: ① Restoring the map can only restore the map you saved the last time.
     ②After the map is restored successfully, the schedules and some map settings will be lost, and the 3D map will also be updated synchronously.
