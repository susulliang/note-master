# How to clean the main brush?

## Question

How to clean the main brush?

## Answer

1. Power off the DEEBOT, and turn it over gently.
2. Remove the cover of the main brush, and take out the main brush assembly.
3. Clean the entanglement on the brush. ( You can also disassemble and clean the accessories on the both sides of the main brush.)
4. Attach the main brush assembly to the robot properly.
Tips: Please rotate the main brush after installation and check if it can rotate smoothly before attaching the main brush cover.
