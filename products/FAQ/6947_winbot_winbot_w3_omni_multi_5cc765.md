# 16

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

16

## 答案 / Answer

Vous pouvez essayer les étapes suivantes :
 1.Assurez-vous que le ventilateur du WINBOT est éteint.
 2.Placez le WINBOT sur le tampon d'essuyage, en vous assurant que les deux brosses sont bien en contact avec le tampon.
 3.Appuyez simultanément sur les deux Pare-chocs situés près des brosses. Lorsque vous entendez le message vocal « Démarrer le nettoyage des brosses », relâchez vos mains. Les brosses commenceront à tourner pour effectuer le nettoyage.
 4. Lorsque vous entendez le message vocal « Nettoyage des brosses terminé », le processus est terminé.
