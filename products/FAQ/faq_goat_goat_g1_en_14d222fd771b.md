# Why does the GOAT G1 return to the docking station before mowing is complete?

## Question

Why does the GOAT G1 return to the docking station before mowing is complete?

## Answer

(1) The map is too large and cannot be covered in a single mowing cycle, so the robot needs to return and recharge. It will continue with the unfinished task when its battery level is sufficient.
(2) Please check the App and the notifications to see if there are any errors or faults with the GOAT.
