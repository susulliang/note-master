# 28

> **产品线**：DEEBOT　**语言**：multi
>

## 问题 / Question

28

## 答案 / Answer

1. Appuyez deux fois sur le bouton AUTO. La serpillère à rouleau s'étend automatiquement. Soulevez légèrement un côté de la serpillière.
2. Faites glisser le loquet bleu vers le haut pour libérer le bac à eau. Retirez le filtre et nettoyez soigneusement le bac et le filtre (utilisez des outils si nécessaire).
3. Replacez le filtre dans le bac à eau.
4. Remettez le bac en place dans le robot. Un « clic » confirme que l'installation est correcte.
5. Appuyez à nouveau deux fois sur AUTO pour rétracter la serpillère à rouleau.
Remarque : Si vous retournez le robot pour le nettoyer, retirez d'abord le réservoir d'eau sale pour éviter les fuites.
