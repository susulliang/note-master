# 为何GOAT会频繁触发撞板异常故障？

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

为何GOAT会频繁触发撞板异常故障？

## 答案 / Answer

7- 主机其他

1.检查GOAT是否在基站内处于对接状态。若是，可能因回充时未及时停止、顶到基站导致撞板持续触发，可尝试将GOAT向后拉出少许，撞板即可恢复正常。
2.GOAT可能在工作中顶到障碍物无法脱困，导致撞板持续触发，请协助其脱困。
3.移除GOAT行进路线上的障碍物；若无法移除，请设置禁区。
如以上情况均已排除但问题仍未解决，请联系科沃斯售后服务部门。

Check if GOAT is in a docked state at the station. If so, it may have failed to stop during recharging and collided with the station, causing continuous collision board triggering. Try pulling GOAT back slightly to restore normal operation.
 2. GOAT may have collided with an obstacle while running and become stuck, causing repeated collision board activation. Please assist it in escaping the obstacle.
 3. Remove obstacles from GOAT's path; if removal is impossible, set up No-Entry zones.
 If all the above situations have been ruled out but the problem remains unresolved, please contact Ecovacs after-sales services.
