# Map is confused/overlaid/tilted

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

Map is confused/overlaid/tilted

## 答案 / Answer

Map is confused/overlaid/tilted

1. When the map has been created, if the map is confused/overlaid/tilted or inconsistent with the original created map, you can try to restore the map.
2. If the map recovery is invalid, it is recommended that you use Quick Mapping to recreate the map after deleting it.
Note: ① Restoring the map can only restore the map you saved the last time.
       ②After the map is restored successfully, the schedules and some map settings will be lost, and the 3D map will also be updated synchronously.

If the verbal trick cannot solve the problem, please upgrade to HQ.
