# 我可以将RTK基站安装在屋顶或者其他高处吗？ / Can I install the RTK Reference Station on the roof or other high places?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我可以将RTK基站安装在屋顶或者其他高处吗？ / Can I install the RTK Reference Station on the roof or other high places?

## 答案 / Answer

RTK Reference Station

（1）RTK基站需要放在开阔无遮挡区域，房屋、树木都会对RTK信号造成遮挡，需要尽可能保证RTK基站周围无遮挡
（2）RTK信号良好（RTK基站信号指示灯常亮，移动后需等待1min确认）
（3）屋顶或高处满足以上条件即可安装。
*安装配件可以在官方网站上购买。
*若考虑安装在高处，请一定注意操作安全

(1) The RTK Reference Station needs to be placed in an open and unobstructed area. Houses and trees will obstruct the RTK signal, and it is necessary to ensure that there is no obstruction around the RTK Reference Station as much as possible.
(2) If the RTK signal indicator steady light, it means that the position signal is stable (after moving it, need to power it on and wait 1min to see the light effect). 
(3)The high places can be installed if the above conditions are met.
* The installation accessories like wall mount can be purchased from the official website.
*If you will install the RTK Reference Station at a high place, please pay attention to the safety of operation
