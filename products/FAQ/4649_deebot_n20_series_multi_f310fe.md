## 答案 / Answer

Disassembly, clean and installation guide of dust box

1.Please remove the Robot cover and take out the dust bin.
2. Open the dust bin and empty it.
3. Remove the filter assembly..
4. Gently tap and clean the filter assembly.
5. Clean the dust bin.
6. Dust bin and filter assembly can be washed with water, need to be placed in a well-ventilated area to dry before use.                                                                                                                                7.After cleaning, install the filter assembly and put dust bin back in the Robot.
