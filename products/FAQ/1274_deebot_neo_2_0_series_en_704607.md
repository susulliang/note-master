# About the function of the robot's key combinations (charge button and localized cleaning button)

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

About the function of the robot's key combinations (charge button and localized cleaning button)

## 答案 / Answer

Press and hold both buttons at the same time for 3 seconds to reset the WiFi. This will allow the robot to make a network re-connection.
