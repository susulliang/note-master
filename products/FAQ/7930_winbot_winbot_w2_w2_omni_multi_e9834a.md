# Can I share the WINBOT W2?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Can I share the WINBOT W2?

## 答案 / Answer

W00168

WINBOT W2 can support multiple accounts, which can be bound via Bluetooth, but only one account can control it. For example, if account A is logged in to control the robot, account B cannot control it. Account B can only log in and use the WINBOT W2 after account A logs out of the operation interface.
