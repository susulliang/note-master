# Quel type de carte SIM dois-je acheter ?

## Question

Quel type de carte SIM dois-je acheter ?

## Answer

Le module de connexion automatique est compatible avec les cartes SIM standard. Sélectionner la carte SIM de votre choix. Toutefois, lors de l'achat, vérifier auprès de l'opérateur si la carte SIM achetée doit être configurée avec un APN et si elle a un code PIN. Activer la carte SIM avant d'insérer le module et désactiver son code PIN. Après l'avoir inséré, faire régulièrement attention à l'utilisation des données.
