# Why is an abnormal Navigation Beacon displayed in the Navigation Beacon list in the App?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Why is an abnormal Navigation Beacon displayed in the Navigation Beacon list in the App?

## 答案 / Answer

G00038

Navigation Beacon

The GOAT has detected that the Navigation Beacon position may have changed and there is an error in the beacon signal.                                                                                                                                          (1) If the navigation beacon icon  is red, that means GOAT is currently unable to receive the signal from this beacon, please check if the beacon is still in place and has power
(2) If the navigation beacon icon is orange, that means this beacon has a low battery, please replace the battery as soon as possible
(3) If the navigation beacon icon  is yellow, that means the position may have moved and the signal may have shifted.
(4) If the navigation beacon icon shows that there is an upgrade, that means it has a new version that can be upgraded.
