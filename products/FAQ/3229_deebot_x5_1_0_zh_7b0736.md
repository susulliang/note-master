# クリーニングシンク内の廃水をリサイクルできない。または、廃水タンクに水がない場合も、ロボットは廃水タンクが満水になっていると警告している。 / *ステーションのインジケーターが点滅しているかを確認してください。点滅している場合は、まずステーションの電源をオフにする必要があります。次に、ステーションの電源を再度オンにして、トラブルシューティングを行います。
1. ステーションからロボットを取り外し、クリーニングシンクの穴をふさぐ異物がないかを確認します。異物がある場合は清掃してください。
2. ステーションのトップカバーを開き、洗浄水タンクと廃水タンクを取り外します。タンクのカバーを開き、シーリングプラグが正しく取り付けられているかを確認して、10秒後に閉じます。
3. 洗浄水タンクと廃水タンクのシーリングプラグを押し込みます。
4. 水タンクをステーションに戻し、押し込みます。
