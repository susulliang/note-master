# WINBOT / WINBOT mini2 .0 19langs / EN - What is the default cleaning mode and path?

## Question

What is the default cleaning mode and path?

## Answer

1. The default is Fast Cleaning Mode.
2. On standard glass (windows >50 cm wide), it performs one Z-shaped cleaning pass.
3. Cleaning 1㎡ typically takes less than 3 minutes.
