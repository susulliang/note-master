# APP中RTK基站添加失败是什么原因？ / What is the reason for the failure to add RTK base stations in the APP?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

APP中RTK基站添加失败是什么原因？ / What is the reason for the failure to add RTK base stations in the APP?

## 答案 / Answer

RTK Reference Station

（1）确认RTK基站是否已成功上电，上电成功RTK基站将会蓝灯亮起.
（2）确认RTK基站正常工作后，使用APP中Settings-＞RTK中RTK基站更多设置中，扫码添加RTK基站
 *若始终无法解决请联系科沃斯售后服务部门

(1) Confirm whether the RTK Reference Station has been successfully powered on, and the indicator will steady light if the RTK Reference Station is successfully powered on and the signal is good.
(2) After confirming that the RTK Reference Stationis working properly, enter APP- Settings -＞RTK-＞Customize in the APP to scan the code and add an RTK Reference Station
* If it cannot be resolved, please contact Ecovacs after-sales Service
