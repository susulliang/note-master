# DEEBOT / DEEBOT T30 PRO OMNI Rosé / EN - How to install and remove base?

## Question

How to install and remove base?

## Answer

1. Place the base on the ground, align it with the station, and push it inward. When you hear a "click", it means it is installed in place;
2. Press the buttons on both sides of the base and pull out the base in parallel.
