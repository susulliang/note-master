# I'm not quite sure how many navigation beacon to use for my garden, nor exactly where to put them.

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

I'm not quite sure how many navigation beacon to use for my garden, nor exactly where to put them.

## 答案 / Answer

G00023

Navigation Beacon

Scan the QR code (or use the provided web address), draw a brief floor plan of your garden in the widget, and the algorithm will automatically generate the number of beacons and placement points for you. If you are still confused, we suggest contacting after-sales customer service for a more detailed explanation for the solution.
