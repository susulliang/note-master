# DEEBOT / T30 S Combo / EN - Remove, install and clean the floor brush?

## Question

Remove, install and clean the floor brush?

## Answer

1. Press the fastening button to remove the floor brush from the handheld vacuum cleaner.
2. Press the arrow direction fluctuation button, and at the same time, rotate the end cap outward according to the direction of rotation of the end cap.
3. Take out the main brush, use a dry cloth to gently wipe the empty space and suction port of the main brush, and use a cleaning tool to clean the entanglement on the main brush
4. After cleaning, push in the main brush, rotate the end cover in the direction of rotation, and install the main brush back in place.
