# DEEBOT T30 OMNI Silver,DEEBOT T30 OMNI Black,DEEBOT T30 OMNI Rosé,DEEBOT T30 PRO OMNI Rosé,DEEBOT T30 PRO OMNI Black,DEEBOT T30 PRO OMNI Silver

## 问题 / Question

DEEBOT T30 OMNI Silver,DEEBOT T30 OMNI Black,DEEBOT T30 OMNI Rosé,DEEBOT T30 PRO OMNI Rosé,DEEBOT T30 PRO OMNI Black,DEEBOT T30 PRO OMNI Silver

Connecter le robot à l'application ECOVACS HOME

Préparer la connexion
1. Scanner le code QR sur le robot ou rechercher l'application ECOVACS HOME dans Google Play ou l'App Store d'Apple, puis télécharger et installer l'application Ecovacs Home conformément aux instructions. Autoriser la localisation associée (y compris GPS et GPRS) pour cette application. 
2. S'assurer que le smartphone est connecté au réseau Wi-Fi domestique.
Remarque : le robot est compatible avec un signal Wi-Fi 2,4 GHz ou un réseau mixte 2,4 GHz/5 GHz. Si le routeur envoie deux signaux Wi-Fi, ignorer temporairement le signal Wi-Fi 5 GHz.

Connecter le robot à l'application ECOVACS HOME
1. Scanner le code QR sur le robot et suivre les instructions de connexion. C'est la méthode conseillée. Il est également possible d'ajouter un robot manuellement dans l'application : sélectionner le modèle du robot et établir la connexion.
2 Mettre le robot sous tension. Après avoir entendu la musique de démarrage, suivre les instructions de l'application pour connecter au Wi-Fi.

Conseils :
1. Le robot étant incompatible avec un signal Wi-Fi masqué, le nom du réseau du signal Wi-Fi doit être visible sur le smartphone pour la connexion.
2. Actuellement, la connexion est incompatible avec un VPN ou un serveur proxy.
3. La connexion est incompatible avec une authentification Web ou un réseau de certification.

Connettere il robot con l'app ECOVACS HOME

Preparazione per il collegamento
1. Eseguire la scansione del codice QR sul robot o cercare l'app ECOVACS HOME in Google Play o nell'App Store di Apple, scaricare e installare l'app Ecovacs Home seguendo le istruzioni. Consentire l'autorizzazione di localizzazione correlata (inclusi GPS e GPRS) per questa app. 
2. Verificare che lo smartphone sia collegato alla rete Wi-Fi domestica.
Nota: il robot supporta il segnale Wi-Fi a 2,4 GHz o una rete mista a 2,4 GHz/5 GHz. Se il router invia due segnali Wi-Fi, ignorare temporaneamente il segnale Wi-Fi da 5 GHz.

Connettere il robot con l'app ECOVACS HOME
1. Eseguire la scansione del codice QR sul robot e seguire le istruzioni per completare la connessione. Si consiglia di eseguire questa operazione. In alternativa, è possibile scegliere di aggiungere manualmente un robot nell'app, selezionare il modello del robot e stabilire la connessione.
2. Accendere il robot. Dopo aver ascoltato il segnale acustico di avvio, seguire le istruzioni dell'app per completare la connessione Wi-Fi.

Consigli:
1. Il robot non supporta il segnale Wi-Fi nascosto, il che significa che il nome della rete del segnale Wi-Fi dovrebbe essere visibile sullo smartphone per la connessione.
2. Attualmente la connessione non supporta il server VPN o proxy.
3. La connessione non supporta l'autenticazione Web o la rete di certificazione.

Conecte el robot con la aplicación ECOVACS HOME.

Preparación para la conexión
1. Escanee el código QR del robot o busque la aplicación ECOVACS HOME en Google Play o el App Store de Apple, descargue e instale la aplicación Ecovacs Home según las instrucciones. Permita la autorización de ubicación relacionada (incluidos GPS y GPRS) para esta aplicación. 
2. Asegúrese de que el smartphone está conectado a la red Wi-Fi doméstica.
Notas: El robot admite una señal Wi-Fi de 2,4 GHz o una red mixta de 2,4 Ghz/5 GHz. Si el router envía dos señales Wi-Fi, ignore temporalmente la señal Wi-Fi de 5 GHz.

Conecte el robot con la aplicación ECOVACS HOME.
1. Escanee el código QR del robot y siga las instrucciones para completar la conexión. Se recomienda esta acción. También puede añadir un robot manualmente en la aplicación, seleccionar el modelo de robot y establecer la conexión.
2. Encienda el robot y, después de escuchar la música de inicio, siga las instrucciones de la aplicación para completar la conexión Wi-Fi.

Sugerencias:
1. El robot no admite la señal Wi-Fi oculta, lo que significa que el nombre de la red de la señal Wi-Fi debe estar visible en el smartphone para la conexión.
2. La conexión no es compatible actualmente con VPN o servidor proxy.
3. La conexión no es compatible con autenticación web ni red de certificación.

ECOVACS HOMEアプリを使用してロボットを接続する

接続の準備
1. ロボットのQRコードをスキャンするか、Google PlayまたはAppleのApp StoreでECOVACS HOMEアプリを検索し、指示に従ってECOVACS HOMEアプリをダウンロードし、インストールします。このアプリの関連する位置情報認証（GPSおよびGPRSを含む）を許可してください。 
2. スマートフォンがご家庭のWiFi環境に接続されていることを確認してください。
注：ロボットは2.4 GHzのWiFi信号または2.4 Ghz/5 GHzの混在ネットワークに対応しています。ルーターが2つのWiFi信号を送信している場合は、一時的に5 GHzのWi-Fi信号を無視してください。

ECOVACS HOMEアプリを使用してロボットを接続する
1. ロボットのQRコードをスキャンし、指示に従って接続を完了します。この方法を推奨します。もしくは、アプリでロボットを手動で追加し、ロボットモデルを選択して接続することもできます。
2. ロボットの電源を入れ、起動音が聞こえたら、アプリの指示に従ってWiFi接続を完了してください。

ヒント：
1. ロボットは非表示のWiFi信号に対応していません。つまり、接続するにはスマートフォンにWiFi信号のネットワーク名が表示されている必要があります。
2. 現在、VPNまたはプロキシサーバーでの接続はサポートされていません。
3. Web認証または認証ネットワークでの接続はサポートされていません。
