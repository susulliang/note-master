# Firmware version upgrade failed.

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

Firmware version upgrade failed.

## 答案 / Answer

Firmware version upgrade failed.

1. Please place the DEEBOT and the base station in a location with good network (preferably near the router). If the network where the DEEBOT is located is not good, there may be a download timeout causing upgrade failure.
2. Confirm whether the base station can control the robot, you can click "Start/Pause" in the middle of the base station to observe.
If it is no response, it will cause the upgrade failure. You can try to re-pair the robot and the base station, and click this link that the robot pairs with the base station. You can watch the video for help and try to upgrade again after the pairing is successful.
