# PIN 码可以修改吗？忘记了该怎么办？ / Can the PIN code be modified? What should I do if I forget it?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

PIN 码可以修改吗？忘记了该怎么办？ / Can the PIN code be modified? What should I do if I forget it?

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

5- 智能&安全

1、PIN 码支持修改，可在 APP【设置】-【更多设置】-【安全设置】-【修改 PIN 码】中操作；                                                                                                           2、若忘记 PIN 码，2.1 APP 未与 GOAT 解绑的情况下，在 APP【设置】-【更多设置】-【安全设置】-【修改 PIN 码】中点击【忘记 PIN 码】，验证 ECOVACS HOME APP 账户登录密码即可重置 PIN 码；2.2 若已解绑 APP，请联系售后进行 PIN 码重置。
