# How do I adjust the time interval for the robot to return to the station to clean the mopping pads?

## Question

How do I adjust the time interval for the robot to return to the station to clean the mopping pads?

## Answer

Setting mopping pads cleaning intervals:
Open the ECOVACS Home app and go to Smart Cleaning to set the mopping pads cleaning interval.
Note: The cleaning interval of the mopping pads can be adjusted during cleaning. If the cleaning interval is adjusted, the current cleaning interval will be based on the interval previously set. The next time the robot returns to the station, the robot will clean the mopping pads based on the newly updated interval.
