# 使用手动模式割草/打草时感觉可遥控的距离变小了。 / When using manual mode for mowing/trimming, it feels like the remote control distance has decreased.

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

使用手动模式割草/打草时感觉可遥控的距离变小了。 / When using manual mode for mowing/trimming, it feels like the remote control distance has decreased.

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

4- 割草

在遥控割草/打草时，可遥控的距离一般在固定范围内，若单次遥控任务中，发现遥控距离范围产生了变化，可能是由以下原因导致：
- 周围有其他无线设备形成信号干扰
- 周围墙壁较近，影响信号接收
- 若遥控期间，机器被遥控出边界，当回到边界内时机器仍然使用的是界外的蓝牙距离限制，若需要恢复界内的距离范围，可重新进入遥控模式。
