# Can the GOAT work properly if any Navigation Beacon is missing or broken during daily use?

## Question

Can the GOAT work properly if any Navigation Beacon is missing or broken during daily use?

## Answer

A missing or damaged Navigation Beacon can cause the number of signals received by the GOAT to be inconsistent with the number of signals received during mapping. To ensure safety, the GOAT automatically stops working when it detects an inconsistent number of signals. To get the GOAT back to normal operation, retrieve the missing beacon or repair the damaged Navigation Beacon. Otherwise, remapping will be required.
