# 我忘记了GOAT的PIN码怎么办？ / What should I do if I have forgotten the PIN code for my GOAT?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我忘记了GOAT的PIN码怎么办？ / What should I do if I have forgotten the PIN code for my GOAT?

## 答案 / Answer

5- 智能&安全

（1）如果APP未和GOAT解绑，可在 “设置”-“更多设置”-“安全设置”-“修改PIN码”-“忘记PIN码”中进行PIN码重置，此操作需要验证您的ECOVACS HOME APP账户登录密码
（2）如果已经解绑APP，请联系售后重置PIN码

(1) If your GOAT is linked to the App, you can go to Settings ＞ More Settings ＞ Security Settings ＞ Change PIN Code ＞ Forgot My PIN Code to reset the PIN code. You will be required to enter the password for your ECOVACS HOME App account.
(2) If your GOAT is no longer linked to the App, please contact Customer Care to reset the PIN code.
