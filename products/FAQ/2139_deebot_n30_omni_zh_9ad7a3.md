## 答案 / Answer

How to add more WIFI signals?

1. Please make sure that Robot has been connected to the network and is in online status.
2. Enter App-Click Robot Controls-Click Settings-Click Robot Advanced Settings-Click About Deebot-Click Wi-Fi -Click "+" to add new Wi-Fi signals.
