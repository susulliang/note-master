# Puis-je télécharger les mises à jour de version pour le robot directement à partir d'Internet ?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

Puis-je télécharger les mises à jour de version pour le robot directement à partir d'Internet ?

## 答案 / Answer

D20031

Enable

OTA

Une fois connecté à un réseau Wi-Fi, DEEBOT peut recevoir des mises à jour en ligne. L'application installe automatiquement le dernier micrologiciel. Il vous suffit de suivre les étapes de l'application pour effectuer les mises à jour.
