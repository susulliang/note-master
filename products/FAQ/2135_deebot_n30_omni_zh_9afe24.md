## 答案 / Answer

The machine did not start cleaning at the scheduled time. What should I do?

1.Ensure the robot is powered on.
2.Check if the current time is within the Do Not Disturb mode.
3.Verify if the robot's battery is fully charged.
4.Check if the scheduled tasks are correctly set or saved in the APP.
