# 毛刷起到什么作用的，是否必须要装？ / What is the function of the brush and is it necessary to install it?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

毛刷起到什么作用的，是否必须要装？ / What is the function of the brush and is it necessary to install it?

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

11- 打草头安装

建议安装
（1）GOAT在打草时，会有飞起的草屑和草浆，容易沾染在机身上，安装毛刷可以保持机身外观整洁和减少清洁频次；
（2）打草模块在工作时，会贴近边界进行工作，毛刷可以阻挡一些悬空的枝丫，防止打草绳触碰到。
