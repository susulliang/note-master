# DEEBOT / DEEBOT T30 PRO OMNI Rosé / EN - The machine's firmware version upgrade failed, what should I do?

## Question

The machine's firmware version upgrade failed, what should I do?

## Answer

1、Check whether the main unit is in charging state:
     Open the app and confirm that there is a lightning logo next to the battery icon or the main unit  AUTO button light is flashing white, indicating that the machine is charging;
2. Check the main unit’s battery:                                                                                                                                                                                                                                                                                                When main unit’s battery is low or out of power, the firmware cannot be upgraded. It is recommended to charge for 3 hours before upgrading;
3. Please place the main unit and station in a location with a good network (preferably near the router). If the network is not good, the download may time out and the upgrade cannot be performed;                                                                                                                                                                                                                                                                4.If the above possible causes have been eliminated but the problem is still not solved, please contact Ecovacs after-sales.
