# 如何切换楼层地图执行清洁任务？

## Question

如何切换楼层地图执行清洁任务？

## Answer

Vacuum Only Mode
 1.Move the robot to the target floor. In the App, tap Map and select the floor map.
 2.Set the cleaning mode to Vacuum Only.
 3.Set Auto Dust Collection to Standard.
 4.Tap Start. The robot will locate itself and begin cleaning automatically.
 5.After cleaning, the App will notify you. Move the robot back to the station for charging.
 Vacuum and Mop Mode
 1.In the App, go to Station → Wash Mopping Pads, wait for cleaning to finish, then move the robot to the target floor.
 2.Set Mopping Pad Washing Interval to Time Priority – 25 min, and adjust cleaning parameters if needed.
 3.Tap Start. The robot will locate itself and start cleaning. It will return to the station for pad washing when due; if the station isn’t found, it will finish the remaining area.
 4.After cleaning, the App will notify you. Move the robot back to the station for dust collection, pad washing, and drying.
 Tip: For large multi-floor areas, moving the station to the target floor ensures better cleaning results.
