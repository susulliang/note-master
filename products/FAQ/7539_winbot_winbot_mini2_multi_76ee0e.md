# Alerte : pression d'air insuffisante.
 Comment y remédier ?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Alerte : pression d'air insuffisante.
 Comment y remédier ?

## 答案 / Answer

Rappel :
 Si la pression d'air est faible pendant l'utilisation, vérifiez d'abord la fenêtre. Les interstices ou les obstacles bas sur le verre peuvent entraîner une perte de pression. Pour ces zones, utilisez la télécommande manuelle via l'application.
 S'il ne s'agit pas d'un problème environnemental, essayez les étapes suivantes :
 1. Utilisez l'application pour télécommander le WINBOT vers une position accessible.
 2. Saisissez la poignée et maintenez le bouton Start enfoncé pendant 2 secondes. Retirez le WINBOT une fois que le ventilateur s'est arrêté.
 3. Assurez-vous que le Tampon d'essuyage est aligné avec les bords larges et étroits et qu'il est bien fixé.
 4. Vérifiez qu'il n'y a pas d'anomalies, puis maintenez le bouton Start enfoncé pour redémarrer le ventilateur. Le WINBOT reprendra son fonctionnement une fois qu'il aura adhéré correctement.
