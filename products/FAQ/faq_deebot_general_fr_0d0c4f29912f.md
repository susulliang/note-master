# Le robot n'a pas effectué automatiquement le nettoyage à l'heure programmée ?

## Question

Le robot n'a pas effectué automatiquement le nettoyage à l'heure programmée ?

## Answer

1. Vérifier que le DEEBOT est sous tension.
2. Vérifier que le DEEBOT est complètement chargé.
3. Vérifier que le mode « Ne pas déranger » n'est pas activé dans l'application, car lorsque ce mode est actif, le robot n'effectue pas les tâches programmées.
4. Vérifier que les tâches programmées dans l'application sont correctement configurées ou enregistrées.
