# 如何使用计划清洁？

> **产品线**：ULTRAMARINE　**语言**：en
>

## 问题 / Question

如何使用计划清洁？

## 答案 / Answer

请先确认机器已绑定 ECOVACS HOME App，打开 App 后点击预约图标，开启计划清理，可选择单次预约或多次预约：
1）单次预约模式
可选择清洁地板、墙壁或全部（地板 + 墙壁）。
设置开始时间、吸力档位（轻度清洁为 Eco，其他清洁为 Std）及运行时间（30–60 分钟），将机器人放入泳池，到达设定时间后将自动开始清洁。
2）多次预约模式
仅支持地板的循环清洁，可选择一周内的多天进行预约。
设置开始时间、吸力档位（轻度清洁为 Eco，其他清洁为 Std）及单次运行时间（30–60 分钟），将机器人放入泳池，到达设定时间后将自动开始清洁。

温馨提醒
1.满电状态下，Eco 模式续航参考（在标准泳池下测试的实验室数据）：
 30 分钟 / 次 → 可使用 6 天
 45 分钟 / 次 → 可使用 4 天
 60 分钟 / 次 → 可使用 3 天
2.在设定的循环周期内，非工作时段可将机器人取出充电，充满后放回泳池，即可继续执行下一次任务。

Make sure the robot is connected to the ECOVACS HOME app. Open the app, tap the schedule icon, and enable Schedule Cleaning. You can choose Single Schedule or Multiple Schedules:
1.One-time Schedule
You can set a one-time cleaning for the floor, wall, or all (floor and wall).
After setting the start time, suction power (Eco for light cleaning, Std for other cleaning), and running time (30 to 60 minutes), place the robot in the pool. It will start cleaning automatically at the set time.
2.Cycle Schedule
Only available for floor cleaning. You can select several days a week.
After setting the start time, suction power (Eco for light cleaning, Std for other cleaning), and running time per session (30 to 60 minutes), place the robot in the pool. It will start cleaning automatically at the set time.

Tips
1.Fully charged battery reference under Eco mode (lab data):
 30 min per cycle → supports 6 days
 45 min per cycle → supports 4 days
 60 min per cycle → supports 3 days
2.During the set recurring cycle, you may take out the robot for charging when it is not working. After fully charged, place it back into the pool for the next task.
