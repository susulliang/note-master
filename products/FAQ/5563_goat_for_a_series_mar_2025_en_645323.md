# 多WIFI管理中，添加WIFI为什么添加不了？ / Is there a limit to the number of Wi-Fi networks that can be added?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

多WIFI管理中，添加WIFI为什么添加不了？ / Is there a limit to the number of Wi-Fi networks that can be added?

## 答案 / Answer

APP

多wifi添加的时候必须当手机连接了需要添加的wifi，才可以进行添加；添加之后不需要给机器重新配网

When adding multiple Wi-Fi networks, your phone must first be connected to the Wi-Fi network that needs to be added. There is no need to reconfigure the network for the mower after it has been added.
