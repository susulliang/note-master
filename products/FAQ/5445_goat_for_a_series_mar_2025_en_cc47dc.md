# 我可以将RTK杆插在植物丛中吗？ / Can I install the RTK Reference Station in the plant?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我可以将RTK杆插在植物丛中吗？ / Can I install the RTK Reference Station in the plant?

## 答案 / Answer

RTK Reference Station

RTK基站受高大的植物遮挡，可能无法收到卫星信号，建议基于以下原则，可以根据狭窄通道的情况判断是否适合。
（1）如果草丛低于RTK基站高度(1.2m)，您可以将RTK杆置于其中。请定期清理杂乱的植物以免植物长高或者缠绕了RTK基站杆。
（2）安装位置RTK基站信号良好，通电1min后，观察到基站蓝色灯常亮即可

The positioning signal will be blocked by tall plants. It is recommended to install the RTK Reference Station location based on the following principles.
(1) If the grass is lower than 1.2m the RTK Reference Stationheight, you can place the RTK Reference Station in it. Please clean up messy plant regulary if the plant is growing tall or winding the RTK Reference Station.
(2) You can confirm the signal of the RTK Reference Station good if the indicator on the RTK is steady on after the power on for 1 minute.
