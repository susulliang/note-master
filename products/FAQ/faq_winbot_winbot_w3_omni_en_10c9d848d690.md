# WINBOT / WINBOT W3 OMNI / EN - How to Use the Display Menu

## Question

How to Use the Display Menu

## Answer

1.The display is divided into three sections: Winbot, Station, and Help Guide.
2.Press and hold the Power button on the station to turn it on. Then:
Press the Function Switch button to select the Winbot icon. Use the Up/Down buttons to choose between Quick, Deep, and Edge cleaning modes (other modes are available in the App).Press the Start/Pause button to confirm and start the selected mode.
3.Press the Function Switch button to select the Station icon. Use the Up/Down buttons to choose between Standard Wash, Deep Wash, and Self-Clean modes. Press the Start/Pause button to confirm and start the selected mode.
4.Press the Function Switch button to select the Help icon. Use the Up/Down buttons to browse common questions and answers.
