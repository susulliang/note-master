# 如何将GOAT 恢复出厂设置？ / How do I restore the GOAT to default settings?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

如何将GOAT 恢复出厂设置？ / How do I restore the GOAT to default settings?

## 答案 / Answer

7- 主机其他

（1）在GOAT上同时长按“开始+回充” 5s
（2）跳出PIN码输入页面，输入PIN码，点击OK确认后，请等待机器清理内存，主机将自动重启，显示为重新设置PIN界面，此时重置成功。

(1) Simultaneously long press "START" and "CHARGE" at the same time on the GOAT for 5 seconds until the display show the PIN code input interface.
(2) When the countdown is over, the PIN code entry page will be displayed. Enter the PIN code and click OK to confirm. Please wait while the machine clears its memory. Goat will automatically restart and display the PIN reset interface. At this point, the reset is successful.
