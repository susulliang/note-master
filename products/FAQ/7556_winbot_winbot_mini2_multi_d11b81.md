# Que faire si le WINBOT émet une alarme ou revient prématurément au point de départ pendant le Nettoyage des bords ?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Que faire si le WINBOT émet une alarme ou revient prématurément au point de départ pendant le Nettoyage des bords ?

## 答案 / Answer

Étape 1 : Récupération. Utilisez l'application pour contrôler manuellement à distance le WINBOT et le placer dans une position accessible. S'il n'est pas connecté, scannez le code QR ou ajoutez manuellement le modèle dans l'application. Suivez les instructions vocales.
Étape 2 : Inspection.
1. Assurez-vous que le tampon est correctement aligné.
2. Évitez le Nettoyage des bords sur des cadres ≤ 2 mm ou du verre présentant des interstices ; utilisez plutôt le mode de Nettoyage rapide pour ces zones.
