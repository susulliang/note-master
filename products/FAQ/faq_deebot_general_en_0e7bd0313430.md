# Cleaning did not start as scheduled

## Question

Cleaning did not start as scheduled

## Answer

1.Ensure the robot is powered on.
2.Check if "Do Not Disturb" mode is enabled in the app; scheduled tasks won't run during active hours.
3.Check the battery level in the app and ensure it's sufficient.
4.Verify the scheduled task in the app settings is correctly set and saved.
