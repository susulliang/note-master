# How to handle the robot prompt "LDS component exception"?

## Question

How to handle the robot prompt "LDS component exception"?

## Answer

The robot prompts "LDS component is abnormal".
1. Lightly dial the LDS component; observe whether the LDS component rotates
2. Shutdown and restart
