# DEEBOT / T30 S / EN - Why didn't the dust collection start when Dibao returned to the station?

## Question

Why didn't the dust collection start when Dibao returned to the station?

## Answer

Why didn't the dust collection start when Dibao returned to the station?
1. Please check that the station is connected to the power supply and can work normally
2. Please check whether the power cord of the station has been properly plugged into the socket, and whether the ground treasure is connected to the station;
3. The user confirms that the automatic dust collection function is turned on in the app; you can open the app to enter the robot control > click the "drop-down button" to slide up > turn on the automatic dust collection
4. When performing automatic dust collection, the dust collection bin of the station needs to be installed in place; please check whether the dust collection bin of the station is installed in place; please remove the dust collection bin and reinstall it.
5. Please check that the disposable dust bag has been installed correctly.
6. Please check whether the APP is set to Do Not Disturb Mode, and the automatic dust collection does not start in Do Not Disturb Mode;
7. If you manually move the gem back to the station, the automatic dust collection will not start. Only when the gem returns to the station automatically will the automatic dust collection be triggered.
8. The charging pole of the station is dirty and may not be able to transmit signals. Please clean it with a dry tissue and try again.
