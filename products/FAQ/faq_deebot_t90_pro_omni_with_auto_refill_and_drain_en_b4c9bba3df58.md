# DEEBOT / T90 PRO OMNI With Auto Refill And Drain / EN - How to add standard Cleaning Solution/heavy-duty Cleaning Solution?

## Question

How to add standard Cleaning Solution/heavy-duty Cleaning Solution?

## Answer

1.. Take off the  dust collection cabin's cover, pull out the two cleaning solution boxes, and place them on a level, hard surface.
2. ①The right, bigger box is for disinfectant cleaning solution.  Open the lid, add disinfectant cleaning solution, close the lid, and place it back into the station.
②The left one is for heavy-duty cleaning solution. Open the lid, add heavy-duty cleaning solution, close the lid, and reinstall it.
3.Return the cleaning solution tank's cover and press the cover firmly to secure it in position.                                                    4.Open App>Enter>Settings>Station Advanced Settings>enable Auto Disinfectant/ Heavy-duty cleaning solution dispense.                                                                                                                             Note: 1.Only the top-of-the-line model features dual-compartment cleaning solution boxes.
2.This model features automatic detergent dispensing. You do not need to manually add cleaning solution to the water tank.
