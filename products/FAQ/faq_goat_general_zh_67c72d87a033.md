# 我应该沿草坪轮廓还是花园轮廓进行建图？

## Question

我应该沿草坪轮廓还是花园轮廓进行建图？

## Answer

If there is no height difference between the lawn area and other areas in your garden, you can create a map along the edge of the garden so that the GOAT is able to run in non-lawn areas. If the height difference between your lawn and other areas is more than 3 cm, it is recommended that you only map around the outline of the lawn. The GOAT is not able to cross over steps more than 3 cm in height.
