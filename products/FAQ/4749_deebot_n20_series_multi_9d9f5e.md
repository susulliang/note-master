# 1. S'assurer que le robot se trouve à proximité de la station de charge. Scanner le code QR pour télécharger l'application ECOVACS HOME. Vous pouvez également effectuer une recherche sur l'application. Inscrivez-vous et connectez-vous.                                              
1. Scanner le code QR, saisir le code wi-fi, puis cliquer pour entrer.
2. Mettre le robot sous tension ; appuyer brièvement sur le bouton Reset ; confirmer que le message vocal « Entrer le mode de configuration réseau » retentit ; suivre l'invite de l'application ;                                                                             3. Une fois l'opération terminée, vous pouvez nommer le robot.
