# 30

> **产品线**：DEEBOT　**语言**：multi
>

## 问题 / Question

30

## 答案 / Answer

1. Retirez le couvercle supérieur et mettez l'interrupteur d'alimentation en position « O » (arrêt).
2. Soulevez le côté du robot où est installé la serpillère à rouleau.
3. Relâchez le loquet bleu pour retirer le bac. Vérifiez que l'aimant n'est pas manquant sur le bac.
4. Si l'aimant est présent : Remettez le bac en place jusqu'à entendre un « clic ». Redémarrez le robot.
5. Si l'aimant est manquant : Contactez le service client pour obtenir de l’aide.
Remarque : Si vous retournez le robot pour l'installer, retirez d'abord le réservoir d'eau sale pour éviter les fuites.
