# DEEBOT / DEEBOT T30C / EN - Handling the issue of the mopping pad not expanding outward:

## Question

Handling the issue of the mopping pad not expanding outward:

## Answer

1.In the App, go to the DEEBOT advanced settings and check if the "TruEdge Adaptive Edge Cleaning" is enabled. If not, enable it before use.
2.Check if the cleaning mode is set to "Vacuum and Mop".
3.Manually move the right mopping pad to check for any obstructions. If there are any, remove them.
4.Turn off the Robot and restart it.
