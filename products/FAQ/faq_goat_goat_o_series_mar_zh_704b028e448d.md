# GOAT / GOAT O Series Mar / ZH - 添加计划表割草任务时，推荐的时间不准确？

## Question

添加计划表割草任务时，推荐的时间不准确？

## Answer

When you set a schedule, a recommended schedule based on the selected task type, the size of the selected area, and the set mowing efficiency parameters will generate. If there is a Do not disturb time in the schedule, as well as some impacts such as rain and temporary obstacles.
If necessary, you can extend the task time appropriately to ensure the completion of the schedule.
