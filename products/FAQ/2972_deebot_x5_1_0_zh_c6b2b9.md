# 如何正确安装地宝？ / 一：地宝安装
1.请打开外包装箱取出主机，基站，附件盒，
2.取下主机盖板，移除主机防撞保护条。
3.请将主机翻转后，底部朝上放置。在附件包装盒内取出边刷，对准卡槽后往下按，听到“嗒”一声表示安装到位。
4.取出基站回充底座对准基站前放，按压两侧并卡到位，
4.取出电源线，和基站背面电源接口连接，接通电源，寻找合适位置靠墙摆放。
（基站放置在平坦的地面，左右≧0.05m和前方≧0.8m范围内不要放置物品）
温馨提示：
基站优先放置瓷砖地面使用，若您放置在地板使用，请定期检查基站底部是否残留水渍，若有请及时清理，以防受潮
