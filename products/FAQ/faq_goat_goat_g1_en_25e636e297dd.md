# GOAT / GOAT G1 / EN - I have removed the Navigation Beacon from the current GOAT, but the Navigation Beacon cannot be paired with another machine.

## Question

I have removed the Navigation Beacon from the current GOAT, but the Navigation Beacon cannot be paired with another machine.

## Answer

The Navigation Beacon is paired with the GOAT after it is added. If the GOAT does not receive the Navigation Beacon signal when deleting the Navigation Beacon, the Navigation Beacon cannot be unpaired from the GOAT, but will be forcibly deleted from the GOAT. You can pair the Navigation Beacon with the original bound GOAT again and delete it near the GOAT after pairing.
