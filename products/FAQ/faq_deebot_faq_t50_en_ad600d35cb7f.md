# DEEBOT / FAQ T50 / EN - How to start a mopping task?

## Question

How to start a mopping task?

## Answer

1.Take out the clean water tank, add water up to the MAX line. After adding water, close the water tank and put it back to the station.
2.Remove the dust collection cabin cover, take out the cleaning solution bottle.
3.Open the bottle and add ECOVACS cleaning  solution. Close it and install it into the station. Make sure you hear the "click" sound to ensure that it is installed in place.
4.Then close the dust cabin cover.
5.Turn the robot over, install the mopping pad assembly.
6.Turn on the robot, place it in front of the station, long press the power button to make the robot  automatically return for charging.
7. Short press the power button to start cleaning task.
