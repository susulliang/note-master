# ¿Por qué las placas para la mopa de limpieza a veces se levantan y otras no cuando el DEEBOT está limpiando?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Por qué las placas para la mopa de limpieza a veces se levantan y otras no cuando el DEEBOT está limpiando?

## 答案 / Answer

D20421

Cleaning

1. Cuando el DEEBOT esté limpiando, levantará las placas para la mopa al desplazarse. A continuación, las lava y recarga para evitar la contaminación residual.
2. El DEEBOT levantará las placas para la mopa por defecto cuando pase por encima de una alfombra, cruce obstáculos o se mueva para dejar de estar atascado o enredado.
3. El DEEBOT levantará las placas para la mopa al crear un mapa.
