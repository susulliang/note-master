# Which button do I need to press to start the robot?

> **产品线**：WINBOT　**语言**：en
>

## 问题 / Question

Which button do I need to press to start the robot?

## 答案 / Answer

W00082

Usage advice

1. After the red main switch at the bottom is turned on,  press the start button (for less than 1.5 seconds) to start the fan. 
2. After the red main switch at the bottom is turned on, evenly press the WINBOT edge detection sensors to stick the robot to the glass.
