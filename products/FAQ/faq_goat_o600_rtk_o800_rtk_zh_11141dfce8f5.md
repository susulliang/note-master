# GOAT / O600 RTK & O800 RTK / ZH - 可以针对不同区域创建多张地图吗？

## Question

可以针对不同区域创建多张地图吗？

## Answer

GOAT currently does not support multiple maps. A single map can contain up to 16 zones, which can be connected by paths or remain as independent zones without paths.
