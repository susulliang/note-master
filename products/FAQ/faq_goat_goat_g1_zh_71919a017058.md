# Can I use the automatic mapping function if there is a narrow passage (covered with grass) in my garden?

## Question

Can I use the automatic mapping function if there is a narrow passage (covered with grass) in my garden?

## Answer

It depends on the width and length of the narrow passage. If the width of the narrow passage is greater than 1m and the length is less than 20m, the automatic mapping function can be used, otherwise it cannot be used.
