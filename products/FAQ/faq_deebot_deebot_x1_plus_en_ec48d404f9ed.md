# DEEBOT / DEEBOT X1 PLUS / EN - Why does DEEBOT X1 Plus make a strange noise when emptying?

## Question

Why does DEEBOT X1 Plus make a strange noise when emptying?

## Answer

(1) When DEEBOT X1 Plus returns to the charging station, there is a small possibility that it will not align with the emptying port. Tap the Recall/Exit button on the station, let the robot exit the station first and then recall it back to the station to start emptying using voice or the App.
(2) If you have purchased a dust-collecting docking station separately, make sure that the dust bin has a dust collection port.
If the problem persists, please contact ECOVACS Customer Service.
