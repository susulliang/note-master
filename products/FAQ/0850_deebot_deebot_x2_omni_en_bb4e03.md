# ¿Cómo puedo extraer/limpiar el depósito de polvo?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Cómo puedo extraer/limpiar el depósito de polvo?

## 答案 / Answer

D20402

Maintenance

1. Abra la cubierta superior del robot y extraiga el depósito de polvo. 
2. Abra el bloqueo del depósito de polvo y vacíe el contenido en la basura. 
3. Extraiga el conjunto de elementos de filtrado. 
4. Limpie el polvo del filtro principal. Nota: Límpielo tanto por dentro como por fuera. 
5. Golpee ligeramente el conjunto de elementos de filtrado para limpiar el polvo y, a continuación, lave el depósito de polvo con agua. 
6. Cuando haya terminado de limpiar, vuelva a instalar los elementos de filtrado y, a continuación, vuelva a introducirlos en el robot. 
Nota: Si limpia con agua, deje que los elementos se sequen en una zona ventilada antes de utilizarlos.
