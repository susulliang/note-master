# What should I do when the mopping pad plates are rotating intermittently or do not rotate at all?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

What should I do when the mopping pad plates are rotating intermittently or do not rotate at all?

## 答案 / Answer

D20393

Cleaning

Please first confirm which Cleaning Mode the robot is currently in. Open the ECOVACS Home app, go to Smart Cleaning ＞ Cleaning Preferences to check: 
(1) If cleaning mode is set to Vacuum, the mopping pad plates will lift up and will not rotate. 
(2) If cleaning mode is set to Mopping, the mopping pad plates will automatically lift up but not rotate when carpet is detected if the Auto strategy function is enabled . If there is no carpet and the mopping pad plates do not rotate, check whether the mopping pad plates are entangled with debris, and if so, dismantle and clean them, then re-install them. 
(3) If cleaning mode is set to Vacuum and Mopping, the mopping pad plates will automatically lift up but not rotate when carpet is detected if the Auto strategy function is enabled. If there is no carpet and the mopping pad plates do not rotate, check whether the mopping pad plates are entangled with debris, and if so, dismantle and clean them, then re-install them. 
(4) If cleaning mode is set to Mop after Vacuum, the robot will complete two cleaning processes. During the first clean, the mopping pad plates will automatically lift up but not rotate. In the second clean, if the Auto strategy function is enabled, when carpet is detected, the mopping pad plates will lift up but not rotate. If there is no carpet and the mopping pad plates do not rotate, check whether the mopping pad plates are entangled with debris, and if so, dismantle and clean them, then re-install them. 
Note: When the robot returns to the station, the mopping pad plates is in a lift-up state and does not rotate. Only after arriving at the station, when returning to charge or clean the pads, the mopping pad plates will automatically lower and rotate.
