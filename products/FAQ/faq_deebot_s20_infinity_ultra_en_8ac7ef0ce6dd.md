# DEEBOT / S20 Infinity Ultra / EN - How to remove/install the dust cabin filter sponge?

## Question

How to remove/install the dust cabin filter sponge?

## Answer

When there is an odor coming from the station, you can try the following steps:
1.Remove the dust cabin cover.
2.Take out the dust bag.
3.Pull the filter sponge holder outward and remove it.
4.Take out the filter sponge and clean it thoroughly.
5.Reinstall the filter sponge back into the holder.
6.Reinstall the filter sponge holder back into the station.
Put the dust bag back in place and close the dust cabin cover.
TIPS: After washing the filter sponge with water, please let it dry completely before using it again.
