# 拖地功能使用(水箱版） / How to Use the Mopping Function (Water Tank Version)

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

拖地功能使用(水箱版） / How to Use the Mopping Function (Water Tank Version)

## 答案 / Answer

1.取出清水箱，揭开其上盖，加水直至达到清水箱的最高水位线。加水完毕后，确保水箱上盖盖紧，随后将清水箱重新装回基站。
2.取下基站左侧的面盖，依次取出两个清洁液仓，平稳放置在硬质水平面上。
3.取下清洁液盒的盖子。将消毒清洁液倒入蓝色盒子，将重污清洁液倒入黑色盒子。盖好盒盖后，将清洁液盒子推回原位。（注意：在加重污清洁液时，切勿超过瓶身上的 MAX 线，以免溢出或影响性能。）
4.将基站左侧的面盖安装回原位，确保安装牢固。
5.确认主机处于开机状态，把主机放置在基站正前方。长按主机启动键，让主机自主返回基站进行充电。
6.待主机充电完成或无需充电时，短按主机启动键，即可启用扫拖任务。                                             温馨提示：                                                                                                                                 1.自动添加液功能默认关闭，在添加完清洁液后，需要进入APP＞进入设备＞设置＞基站高级设置＞打开“智能添加清洁消毒液/智能添加重污清洁液”开关。                                                                        2.若不添加清洁液，亦可直接开始工作。                                                                                        3.请使用科沃斯专用清洁液。

1.Remove the clean water tank, open the top cover, and fill it to the max water level. Close the lid tightly and reinstall the tank into the station.
2.Take off the cleaning solution tank's cover, pull out the two cleaning solution boxes, and place them on a level, hard surface.
 3. Remove the lids of the cleaning solution boxes. Pour the disinfectant cleaning solution into the blue box and the heavy-duty cleaning solution into the black box. After securing the box lids, push them back into the station.(Note: When filling the heavy-duty cleaning solution, do not exceed the MAX line indicated on the bottle to avoid overflow or performance issues.)
 4.Return the cleaning solution tank's cover and press the cover firmly to secure it in position.
 5. Make sure the robot is powered on. Place it in front of the station and press and hold the power button to make it return to the station and begins charging.
 6. Start the Mopping Task
 Once fully charged (or if charging isn’t needed), short press the power button to start the vacuuming & mopping task.                                                                                                                                    Warm reminder:
 1. The automatic cleaning solution adding function is turned off by default. After adding the cleaning solution, go to the APP ＞ enter the device ＞ Settings ＞ Station Advanced Settings, and turn on the Auto Disinfectant/ Heavy-duty cleaning solution dispense. 
 2. If no cleaning solution is added, Robot can still start working directly.
 3. Please use ECOVACS’ dedicated cleaning solution.
