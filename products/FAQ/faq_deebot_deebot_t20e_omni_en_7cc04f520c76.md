# DEEBOT / DEEBOT T20e OMNI / EN - How do I set up scheduled cleaning?

## Question

How do I set up scheduled cleaning?

## Answer

Robot scheduled cleaning settings:
Open the ECOVACS Home app and go to Smart Cleaning > Scheduled Cleaning to set the relevant settings, such as adding or deleting a schedule.
