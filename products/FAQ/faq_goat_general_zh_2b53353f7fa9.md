# 前后院不连通，该如何建图？

## Question

前后院不连通，该如何建图？

## Answer

1. If there is no connecting path between the front and back yards, it is recommended to create a map for only the front yard or back yard.
 2. If there is a passable path between the front and back yards, it is recommended to create a complete area encompassing both, and use the multi-zone feature to efficiently schedule mowing tasks.
 3. You can first create one zone, then add another zone in the app, and finally establish a passable path.
