# Parfois, le robot ne peut pas éviter les obstacles.

## Question

Parfois, le robot ne peut pas éviter les obstacles.

## Answer

1. Vérifier si le module laser est poussiéreux. Si nécessaire, essuyer délicatement la poussière avec du papier absorbant sec.
Remarque : confronté à des objets noirs et linéaires, le robot peut ralentir et légèrement les toucher.
