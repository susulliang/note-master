# 메인 브러시는 어떻게 청소합니까?

## Question

메인 브러시는 어떻게 청소합니까?

## Answer

1. DEEBOT의 전원을 끄고 천천히 뒤집습니다.
2. 메인 브러시의 덮개를 분리하고 메인 브러시 어셈블리를 꺼냅니다.
3. 브러시에서 얽힘을 제거합니다. (또한, 메인 브러시 양쪽에 있는 액세서리를 분해하여 청소할 수도 있습니다.)
4. 메인 브러시 어셈블리를 로봇에 올바르게 부착합니다.
팁: 메인 브러시를 설치한 후 덮개를 부착하기 전에 메인 브러시를 돌려 부드럽게 회전하는지 확인하십시오.
