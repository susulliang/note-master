# What are Cellullar Module and SIM cards used for?

## Question

What are Cellullar Module and SIM cards used for?

## Answer

Auto-Connection service is a kind of remote assistance service provided by ECOVACS that is built into the Cellullar Module. If your home has no Wi-Fi or the Wi-Fi signal is poor, you can achieve remote control through Auto-Connection service. The service does not need to be activated. You can only install the Cellullar Module and use it after starting up. If you do not want to use the Auto-Connection service, you can buy a SIM card and insert the Cellullar Module after activation to use the SIM card. GOAT uses remote service by default, you can switch it to use SIM card in "Settings" - "More Settings" - "Network Settings" - "Cellullar Module". You can use all GOAT features under the SIM card connection, firmware upgrades and video features are not available under the Auto-Connection service.
