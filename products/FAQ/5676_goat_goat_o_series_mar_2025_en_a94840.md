# 我的花园中有路能否使用自动建图功能 / Can I use the automatic mapping function if there is a road in my garden?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我的花园中有路能否使用自动建图功能 / Can I use the automatic mapping function if there is a road in my garden?

## 答案 / Answer

3- 建图

可以，但建议跟随机器以随时切入手动建图，以防止自动建图时，将花园内的路识别为地图边界。

It is recommended to follow the GOAT and switch to manual mapping if needed, in case the garden paths being identified as the map boundaries during automatic mapping.
