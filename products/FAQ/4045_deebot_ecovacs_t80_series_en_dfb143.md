# How to Set Up a scenario clean?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

How to Set Up a scenario clean?

## 答案 / Answer

1.Ensure the robot is connected to the Yeedi app and online.
2.Open the app, click "Enter ", then click "map" to create a home environment map.
3.After that, click "Settings" -"scenario" -"Add."
4.Add scenarios like "Daily Cleaning" or "Deep Cleaning" directly on the page. You can also edit areas and cleaning parameters.
5.Alternatively, manually select areas, set cleaning preferences, and save.
