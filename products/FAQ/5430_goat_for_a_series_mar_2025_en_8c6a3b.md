# 基站需要和GOAT主机进行配对吗？ / Does the base station need to be paired with the GOAT?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

基站需要和GOAT主机进行配对吗？ / Does the base station need to be paired with the GOAT?

## 答案 / Answer

Charging Station

不需要配对。GOAT的基站与主机仅靠充电接触片进行充电，无对应关系

Pairing is not required. The charging connector is used by the docking station and mower for simple communication. There is no corresponding relationship between them.
