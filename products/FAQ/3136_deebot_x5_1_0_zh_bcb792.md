# Que dois-je faire si le robot n'effectue pas de nettoyage continu ? / 1. Vérifier que le nettoyage continu est activé dans l'application. 
2. Le nettoyage continu ne peut pas se déclencher en mode Ne pas déranger. 
3. Si le robot retourne au chargeur et qu'une alerte s'active, le nettoyage continu ne peut pas se déclencher. 
4. Une fois le nettoyage continu déclenché, le robot ne peut pas être redémarré et ses réglages ne peuvent pas être réinitialisés. 

Remarque : le nettoyage continu n'est possible qu'en mode AUTO.
