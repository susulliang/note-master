# Firmware version upgrade failed.

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

Firmware version upgrade failed.

## 答案 / Answer

Firmware version upgrade failed.

1. If the firmware upgrade in the APP fails, the robot will enter the recovery mode. In this mode, pressing the start button and reset button of the robot will have no response. When this phenomenon occurs, it is recommended to manually place the robot in the base station and keep it in charging state, do not do anything in the operation. After waiting for about 2-3 hours, confirm the firmware upgrade result. (After the upgrade is successful, there will be a startup music sound.)
2. If the robot enters the recovery mode, with the consent of the user, please change the mobile hotspot name and password to the WIFI name and password used by the DEEBOT network setup, turn off the router, and wait for a successful upgrade.
(The size of the firmware is about 120M, and the download needs to consume 120M of data traffic.)
3. If the OTA does not respond for a long time, you can exit the OTA mode by the following ways:
 ①Turn off the router connected to DEEBOT and confirm it is powered off.
 ②Shut down DEEBOT and restart it. After waiting for about 10 minutes, DEEBOT will automatically restart and enter normal working mode due to timeout of connecting to the server causing OTA failure.
 ③ After confirming that the OTA fails, please turn on the router again and plug in the power.
4. If the robot has no response during the upgrade process, which cause it unusable, you can disconnect the network for about 15 minutes to make it fail to upgrade. The robot will return to the version before the upgrade, and it can be used normally.
