# 我需要购买哪种SIM卡？(北美) / What type of SIM card do I need to purchase?
（North America）

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我需要购买哪种SIM卡？(北美) / What type of SIM card do I need to purchase?
（North America）

## 答案 / Answer

4G  Cellullar Module

4G  Cellullar Module兼容常规Nano卡（兼容3G、4G卡），您可以自由选择您所需的SIM卡。但在购买时请向运营商确认购买的SIM卡是否需要设置APN，以及是否有PIN码。请将SIM卡在插入模块前进行激活并将SIM卡的PIN码禁用，插入后续定期关注流量使用情况

The 4G Cellullar Module is compatible with regular Nano cards (compatible with 3G and 4G cards), allowing you to freely choose the SIM card you need. But please confirm with the operator whether the purchased SIM card requires APN settings and whether there is a PIN code when making a purchase. Please activate the SIM card before inserting it into the module and disable the PIN code on the SIM card. After insertion, regularly monitor the data usage
