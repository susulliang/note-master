# La GOAT peut-elle fonctionner correctement si une balise de navigation est manquante ou endommagée pendant l'utilisation quotidienne ?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

La GOAT peut-elle fonctionner correctement si une balise de navigation est manquante ou endommagée pendant l'utilisation quotidienne ?

## 答案 / Answer

G00032

Enable

Navigation Beacon

Une balise de navigation manquante ou endommagée peut entraîner une incohérence entre le nombre de signaux reçus par la GOAT et le nombre de signaux reçus pendant la cartographie. Pour garantir la sécurité, la GOAT arrête automatiquement de fonctionner lorsqu'elle détecte un nombre incohérent de signaux. Pour remettre la GOAT en fonctionnement normal, récupérer la balise manquante ou réparer la balise de navigation endommagée. Dans le cas contraire, une nouvelle cartographie sera nécessaire.
