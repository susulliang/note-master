# DEEBOT / T30 S Combo / EN - Mini electric brush disassembly and cleaning?

## Question

Mini electric brush disassembly and cleaning?

## Answer

1. Press the tighten button to remove the mite brush from the handheld vacuum cleaner.
2. Press and hold the roller end cap, rotate clockwise, and pull out the main brush outward.
3. Use a cleaning tool to clean the entanglement on the main brush and clean it up.
4. Insert the main brush, rotate the main brush end cover counterclockwise, and install the main brush back in place until you hear a "click" sound, indicating that the installation is in place.
