# DEEBOT / FAQ T50 / EN - How to replace dust bag?

## Question

How to replace dust bag?

## Answer

1. Remove dust collection cabin baffle;
2. Remove and discard the dust bag;
3. Wipe the dust collection cabin with a dry rag and install a new dust bag;
4. Install the dust collection cabin flap;
