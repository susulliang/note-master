# DEEBOT / X12 PRO OMNI / EN - How to replace the dust bag / How to handle it when the robot prompts that the dust bag is full?

## Question

How to replace the dust bag / How to handle it when the robot prompts that the dust bag is full?

## Answer

When the robot displays a "Dust Bag Full" alert, you can try the following steps:
1.Remove the dust cabin cover.
2.Take out the dust bag and discard it.
3.Wipe the dust cabin clean with a dry cloth, then install a new dust bag.
4.Close the dust cabin cover.
5.Open the APP, tap "Maintenance" > "Dust Bag" > "Replaced".
