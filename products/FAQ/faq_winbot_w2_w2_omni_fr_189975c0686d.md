# Le WINBOT W2 n'a pas pu se coupler à l'application ECOVACS HOME via Bluetooth.

## Question

Le WINBOT W2 n'a pas pu se coupler à l'application ECOVACS HOME via Bluetooth.

## Answer

Le WINBOT W2 n'a pas pu se coupler à l'application ECOVACS HOME via Bluetooth.

1. Vérifier que l'application ECOVACS HOME est mise à jour à la dernière version.
2. Redémarrer le WINBOT W2.
3. Réactiver la fonction Bluetooth sur le smartphone.
4. Effectuer le couplage Bluetooth avec le WINBOT W2 dans l'interface de l'application ECOVACS HOME. Ne pas coupler le Bluetooth avec le WINBOT W2 dans l'interface de configuration du smartphone.
5. Si le WINBOT W2 a été connecté à un autre smartphone, commencer par se déconnecter de l'application, puis réessayer.

Remarque : Lors du couplage via Bluetooth, garder le WINBOT W2 près du smartphone et loin du routeur Wi-Fi. Si aucune des solutions ci-dessus ne résout le problème, contacter l'assistance ECOVACS.
