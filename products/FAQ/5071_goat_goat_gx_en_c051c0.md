# Why does the GOAT not continue with the unfinished task after it has fully recharged?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Why does the GOAT not continue with the unfinished task after it has fully recharged?

## 答案 / Answer

G00096

Mowing

(1) Please make sure that you have not reset or shut down the GOAT at any point in the process. 
 (2) Please make sure that the GOAT is charging normally. Once charging is complete, it will continue with unfinished tasks. 
 (3) Please check whether there is anything wrong with the GOAT. You can manually resume unfinished tasks when faults, if any, are fixed.
