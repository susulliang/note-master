# 如何创建多层地图？ / How to create a new map?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

如何创建多层地图？ / How to create a new map?

## 答案 / Answer

1.打开App”进入设备”点击“地图”点击“+”新增地图
注：请先将地宝搬至新环境

1.Open APP-Click Enter Device-Click map-Click "+" ，to create a new map;
Note: Please move the DEEBOT to the new environment.
