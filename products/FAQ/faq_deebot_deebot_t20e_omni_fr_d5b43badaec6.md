# Comment vérifier les roues motrices si elles sont bloquées ?

## Question

Comment vérifier les roues motrices si elles sont bloquées ?

## Answer

1. Vérifier que les bandes de protection anticollision du robot ont été retirées. Si ce n'est pas le cas, les retirer d'abord.
2. Mettre le robot hors tension, le retourner et le poser doucement à l'envers.
3. Appuyer sur les roues motrices et les faire tourner pour retirer tout débris coincé.
