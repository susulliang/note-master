## 问题 / Question

How to set virtual boundaries? / How to set virtual boundaries? / Wie lege ich virtuelle Grenzen fest? / Comment définir des limites virtuelles ? / Come si impostano le barriere virtuali? / バーチャルボーダーの設定方法を教えてください。 / 가상 경계는 어떻게 설정합니까?

## 答案 / Answer

バーチャルボーダーの設定方法を教えてください。

1.［マップ］をクリックし、［バーチャルウォール］を選択します。
2.必要に応じて、線/長方形を使用してバーチャルボーダーを設定できます。
3.バーチャルウォールのタイプを選択することもできます（［掃除機とモップ掛け］または［モップのみ］を有効にできます）。
4.作業中、ロボットはバーチャルボーダーエリアを迂回します。
