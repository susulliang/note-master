# DEEBOT / DEEBOT T30 OMNI Silver / EN - How do I quickly create a map?

## Question

How do I quickly create a map?

## Answer

Preparations before you create a map
1. Open the doors of the rooms where you want to map and remove obstacles that you think may disturb the cleaning. Ensure that there is sufficient light so that the map can cover the entire home environment.
2. Power on the robot (long press the auto button     ) and place it directly in front of the station.
3. Tap the return/exit button        on the robot to make the robot return to charge itself. Once docked it will start charging.
Quick Mapping(Make sure your robot is connected with the ECOVACS HOME App and is online. )
1. Using the voice assistant:
You can say to the robot: "OK YIKO, Quick Mapping"
2. Using the app:
Open the app-click Enter-  Start Mapping
3. After the mapping is complete, the robot will announce that mapping completed. This means the map was successfully created.                                                                                Note: ① When using the voice assistant, the three buttons on the main unit will flash white at the same time during voice interaction.
        ② If the robot is not connected to the internet, the quick mapping function cannot be used temporarily, but you can click the power button     of the machine, and the machine will build the map while working. After completion, there will be a voice prompt "Cleaning completed, return to station", and the map is created successfully.
