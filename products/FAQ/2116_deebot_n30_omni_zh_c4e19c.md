How to start a mopping task?

1. Open the clean water tank, add water up to the MAX line；
2. Flip the Robot over，then install the mopping pad assembly .
3. Place the Robot in front of the station; click the return button to enable the Robot to automatically return for charging.
4. Short press the power button to start the vacuuming and mopping task.
