# 我能否将机器搬到新草坪区域，并新增地图区域？

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我能否将机器搬到新草坪区域，并新增地图区域？

## 答案 / Answer

3- 建图

若新增草坪区域有稳定RTK信号，是可以的。不过，我们建议：
1.为确保新增区域与原有地图关联，请尽量从基站或已创建地图内出发进行区域新增。
2.若新增区域与原区域无通道连接，GOAT自动割草时将无法进入该区域工作，需设置通道或将GOAT手动移动到该区域内触发割草。

If the new lawn area has stable RTK signal, it is possible. However, we recommend:
 1. To ensure the new area connects to the existing map, start adding the new area from the station or within an already created map.
 2. If the new area has no path connecting to the original area, GOAT will not enter that area during automatic mow. You must set up a path or manually move GOAT into the area to trigger mow.
