# 拖地功能使用 / How to start a mopping task?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

拖地功能使用 / How to start a mopping task?

## 答案 / Answer

1. 取出清水箱，打开水箱上盖并加水至清水箱最高水位线。加水完成后，盖紧水箱上
盖并将清水箱装回基站。
2.取下集尘仓盖板，将手指伸入清洁液盒底部的扣手内，向外抽拉出整个清洁液盒，
并将其放置在硬质水平面
3.打开清洁液盒上盖，向内加入科沃斯专用清洁液。盖紧清洁液盒上盖，并将其装
入基站内。请确认听到“咔哒”声，以确保安装到位。
4.集尘仓盖板安装到位，以确保完全密封。
5. 将主机翻转，底部朝上放置，安装拖布及拖布支架。
6. 确认主机已开机后，并将主机放置基站正前方；长按主机启动键，让机器自主返回充电，对接成功后开始充电。
7. 短按主机启动键，启用扫拖任务。

1.Take out the clean water tank, add water up to the MAX line. After adding water, close the water tank and put it back to the station.
2.Remove the dust collection cabin cover, take out the cleaning solution unit.
3.Open the unit and add ECOVACS cleaning  solution. Close it and install it into the station. Make sure you hear the "click" sound to ensure that it is installed in place.
4.Then close the dust collection cabin.
5.Turn the robot over, install the mopping pad assembly.
6.Turn on the robot, place it in front of the station, long press the AUTO button to make the robot  automatically return for charging.
7. Short press the AUTO button to start cleaning task.
