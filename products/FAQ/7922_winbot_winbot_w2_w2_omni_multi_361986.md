# WINBOT W2 is a little noisy when working, is it possible to adjust the suction power?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

WINBOT W2 is a little noisy when working, is it possible to adjust the suction power?

## 答案 / Answer

W00160

WINBOT W2 uses a powerful fan system to ensure stable suction, which makes it more secure for usage. Therefore, suction power adjustment is not supported.
