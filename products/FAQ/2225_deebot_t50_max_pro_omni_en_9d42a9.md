# 如何设置定制清洁场景？ / How to set up a scenario clean?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

如何设置定制清洁场景？ / How to set up a scenario clean?

## 答案 / Answer

1.打开App点击进入”进入设备”完成家庭环境地图的创建，选择“定制”＞点击“编辑”
3.可直接在页面中添加“日常清洁/深度清洁/“等场景
4.也可针对选择的定制模式进行手动选区清洁，并对清洁偏好进行设定（吸力调节/水量调节/次数选择）

1.Open APP - click Enter Device - create a home environment map                                                                                                                              2.Click settings- Click Scenario-Click Customize
3.Can add default scenarios, such as Daily Clean/Post-meal Clean/Pet Area Clean/Deep Clean directly on the page
4.Directly added scenarios also support setting the area to be cleaned and setting cleaning preferences (suction power adjustment/water volume adjustment/frequency selection).
