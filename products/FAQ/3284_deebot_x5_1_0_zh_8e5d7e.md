# 동영상 관리자는 어떻게 사용하나요? / 1. 동영상 관리자 지침: 1.1 동영상 관리자와 스마트 청소는 동시에 사용할 수 없지만, 두 기능을 자유롭게 전환할 수 있습니다.
1.2 동영상 관리자는 사진 촬영, 동영상 녹화, 음성 통화, 돌아보기, 명령에 따라 도착, 갤러리 관리를 지원합니다. 

2. 지침: 2.1 실시간 사진을 촬영하려면 동영상 관리자 ＞ 카메라로 이동합니다. 2.2 무음 동영상(최대 15초)을 녹화하려면 동영상 관리자 ＞ 카메라로 이동합니다.
2.3 갤러리 사진 및 동영상을 관리하려면 동영상 관리자 ＞ 카메라로 이동합니다.
2.4 영상 통화를 하려면 동영상 관리자 ＞ 음성 통화로 이동합니다.
2.5 구성된 각 지점(북, 동, 남, 서)으로 이동해 사진을 촬영한 다음 자동으로 도킹 스테이션으로 돌아가려면 동영상 관리자 ＞ 돌아보기 ＞ DEEBOT으로 이동합니다. 2.6 지도에 위치를 표시하려면 동영상 관리자 ＞ 명령에 따라 도착으로 이동합니다. 표시된 위치로 DEEBOT이 자동으로 이동하게 하려면 이동을 탭합니다.
