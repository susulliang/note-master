# How do I restore the GOAT to default settings?

## Question

How do I restore the GOAT to default settings?

## Answer

(1) You can select Settings > Restore Default Settings on the display.
 (2) Simultaneously long press Start and Recharge on the GOAT for 2 seconds. Please take note that this method retains the original PIN code, and the bound navigation beacon will not be cleared after default settings have been restored.
