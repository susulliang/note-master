# PIN码设置后可以修改吗？ / Can I change the PIN code after it has been set?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

PIN码设置后可以修改吗？ / Can I change the PIN code after it has been set?

## 答案 / Answer

Intelligence&Security

（1）可在APP “设置”-“机器人设置设置”-“安全设置”-“修改PIN码”中进行修改

You can change it in the App by going to Settings ＞ Robot Settings ＞ Security Settings-＞Change PIN Code
