# Rien ne se produit lorsque j'appuie sur le bouton de réinitialisation. Que dois-je faire ?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

Rien ne se produit lorsque j'appuie sur le bouton de réinitialisation. Que dois-je faire ?

## 答案 / Answer

D20007

Enable

Usage advice

1. Vérifiez si le robot réagit lorsque vous appuyez sur le bouton. 
2. Appuyez brièvement sur le bouton de réinitialisation pour configurer la connexion réseau. Le robot émet un son du type « Ding ». Appuyez longuement sur le bouton de réinitialisation pour réinitialiser le robot. Maintenez le bouton enfoncé pendant 5 secondes avant de le relâcher. La musique de démarrage signifie que le robot a bien été réinitialisé.
