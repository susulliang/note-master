# El robot indica que debo tocar con cuidado el sensor D-TOF. ¿Qué debo hacer?

>

## 问题 / Question

El robot indica que debo tocar con cuidado el sensor D-TOF. ¿Qué debo hacer?

## 答案 / Answer

D20387

Alarm

El robot le indica que toque con cuidado el sensor D-TOF: 
1. Agite suavemente el conjunto D-TOF. 
2. Apague y reinicie. 
Nota: Si el problema persiste, póngase en contacto con el servicio de atención al cliente de ECOVACS.
