# 如果日常使用中有RTK基站丢失或者坏了，还能正常使用GOAT吗？ / If an RTK Reference Station is lost or broken, can GOAT still be used normally?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

如果日常使用中有RTK基站丢失或者坏了，还能正常使用GOAT吗？ / If an RTK Reference Station is lost or broken, can GOAT still be used normally?

## 答案 / Answer

RTK Reference Station

RTK基站丢失或者损坏会导致GOAT接收不到定位信号，当GOAT检测到信号丢失时将会自动停止工作。

The loss or damage of the RTK base station will cause the GOAT to lose the positioning signal. When the GOAT detects a loss of signal, it will automatically stop working.
