# Conexión de su T20e OMNI con la aplicación ECOVACS HOME

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

Conexión de su T20e OMNI con la aplicación ECOVACS HOME

## 答案 / Answer

A00063+

App and WiFi Connection

Preparación para la conexión
1. Escanee el código QR del robot o busque la aplicación ECOVACS HOME en Google Play o el App Store de Apple, descargue e instale la aplicación ECOVACS HOME según las instrucciones. Permita la autorización de ubicación relacionada (incluidos GPS y GPRS) para esta aplicación. 
2. Asegúrese de que el smartphone está conectado a la red Wi-Fi doméstica.
Nota: El robot admite una señal Wi-Fi de 2,4 GHz o una red mixta de 2,4 GHz/5 GHz. Si el router envía dos señales Wi-Fi, ignore temporalmente la señal Wi-Fi de 5 GHz. 

Conexión de su T20e OMNI con la aplicación ECOVACS HOME:
Abra la aplicación ECOVACS HOME y añada el robot escaneando el código QR del robot. Siga las instrucciones de la aplicación para conectar la red. También puede agregar manualmente el modelo y conectar el robot a la red.

Notas:
1. El robot no admite señales Wi-Fi ocultas, lo que significa que el nombre de la red de la señal Wi-Fi debe estar visible en el smartphone para la conexión.
2. La conexión no es compatible actualmente con VPN o servidores proxy.
3. La conexión no es compatible con autenticación web ni redes de certificación.
