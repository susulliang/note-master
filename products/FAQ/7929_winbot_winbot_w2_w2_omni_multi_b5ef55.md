# Unable to control the WINBOT W2 through the ECOVACS HOME App.

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Unable to control the WINBOT W2 through the ECOVACS HOME App.

## 答案 / Answer

W00167

1. Please make sure the WINBOT W2 is in adsorption/working state. The manual control in the ECOVACS HOME App is effective only when the WINBOT W2 is powered on and has been attached to the window surface. 

2. Please make sure that the remote control is used within the effective range of Bluetooth (effective distance is about 5 meters).

3. The robot supports multiple smart phone connections but does not support multiple phones to remote control at the same time. That means if mobile phone A is operating the WINBOT W2, then mobile phone B cannot use it.

Note: 
1) The WINBOT W2 can only be remote controlled through the ECOVACS HOME App.
2) When using the remote control, the Bluetooth function of your smart phone needs to be enabled.
