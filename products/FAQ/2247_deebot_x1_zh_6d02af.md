# The map is lost.

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

The map is lost.

## 答案 / Answer

The map is lost.

18 The map is lost.
Confirm that the map has been created. When starting cleaning, the robot will prompt that it finds a new environment and starts a new cleaning. The created map disappears.
Confirm that the map has been created. When starting cleaning, the robot will prompt that it finds a new environment and starts a new cleaning. The created map disappears. This phenomenon is usually caused by the failure of the robot positioning.
then you can do:
1. In the main interface of the APP, click "Customize" ＞ click "End Now" after the pop-up or press and hold the "Start/Pause" button on the base station for about 3 seconds to end the current task.
2. In the main interface of the app, open "Map Management" to check whether there is a map created before.
①If not, you can recreate the map.
②If yes, you can click "Use Map" to restore the map.
3. After clicking "Use Map" to restore, place the robot in an open area outside the base station, and click the leftmost "Recall/Exit" button on the base station to let the robot automatically return to the base station.
①If the map does not disappear and the DEEBOT icon appears on the map, which means that the map is retrieved successfully.
②If the new gray map still appears, it is recommended to use Quick Mapping to recreate the map after deleting the original map in the map management.
If you want to know how to use Quick Mapping, you can click this link Quick Mapping for more help.
Note: After using the map retrieval function, the current map settings and some 3D map settings will be updated synchronously.
