# DEEBOT / T50 降配版 / ZH - 提示尘袋已满后如何更换？

## Question

提示尘袋已满后如何更换？

## Answer

一：更换集尘袋
温馨提示：为了避免集尘袋内的垃圾长时间未清理而产生一些异味，给您带来不好的体验；当您机器人使用一段时间后，我们的app会定期推送告警信息，提醒您更换尘袋，那么您可以这样操作
1. 取下集尘仓挡板；
2. 取出尘袋并丢弃；
3. 用干抹布擦拭集尘仓，安装新尘袋；
4. 关闭集尘仓挡板；
5.尘袋更换后请点击“APP设置”>点击“耗材与部件”>点击“尘袋”我已更换可消除更换尘袋的告警信息。
