# 基站需要和GOAT进行配对吗？ / Does the base station need to be paired with GOAT?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

基站需要和GOAT进行配对吗？ / Does the base station need to be paired with GOAT?

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

1- 充电基站

如果您的机器是O LiDAR PRO,则不需要配对，GOAT的基站与主机仅靠充电接触片进行简易的通讯，无对应关系。                                                                                  若您的机器是A LiDAR PRO，则需要配对。                                                              1、正常情况下出厂时机器与充电基站是已经一一配对的状态，无需任何操作。充电基站和GOAT主机配对后，可以具有基站OTA的能力。
2、如何检查配对情况：可进入APP设置页面，点击“升级”，查看充电基站的配对情况，若无配对信息，可以点击“配对”，扫描充电基站背后的条码进行手动配对。
