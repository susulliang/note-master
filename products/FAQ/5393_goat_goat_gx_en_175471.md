# When using the schedule task function, what should I do if the grass has not been completely mowed by the end time, or the grass has been completely mowed before the end time is up?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

When using the schedule task function, what should I do if the grass has not been completely mowed by the end time, or the grass has been completely mowed before the end time is up?

## 答案 / Answer

34

Mowing

The GOAT can remember the position at the end of the current scheduled time. When the next schedule starts, it will continue to mow the grass from the position where it ended last time. If a round of mowing is completed before the end time, the GOAT will start mowing again until the scheduled end time.
