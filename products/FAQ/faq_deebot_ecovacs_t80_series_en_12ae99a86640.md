# DEEBOT / ECOVACS T80 Series / EN - How to Set Up a Virtual Wall?

## Question

How to Set Up a Virtual Wall?

## Answer

1.Draw a line or frame on the map to define the virtual wall area.
2.Choose the virtual wall's function: "Active for both sweeping and mopping" or "Only active for mopping."
3.Once set, the robot will automatically avoid the virtual wall area during cleaning.
