# 为什么我配网的时候，无法正常进入配网状态？ / Why can't I enter the distribution network state normally when I am in the distribution network?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

为什么我配网的时候，无法正常进入配网状态？ / Why can't I enter the distribution network state normally when I am in the distribution network?

## 答案 / Answer

（1）请确认是否已设置PIN码？如未设置，请先在GOAT屏幕上，设置PIN码。
   设置方式：屏幕上通过“+”和“-”键选择需要设置的密码数字，按OK键确认，到下一个数字。输入PIN码后，需要再次输入进行PIN码确认，设置后可正常使用机器。
**如使用以上情况均已排除，但问题还未解决，请联系科沃斯售后服务部门

(1) Please confirm if the PIN code has been set? If not set, please first set the PIN code on the GOAT screen.
Setting method: Select the password number to be set on the screen using the "+" and "-" keys, press the OK key to confirm, and proceed to the next number. After entering the PIN code, it needs to be entered again for PIN code confirmation. Once set, the machine can be used normally.
**If the issue persists, please contact ECOVACS Customer Care.
