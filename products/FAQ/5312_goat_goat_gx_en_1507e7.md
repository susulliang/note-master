# Why does the GOAT return to the docking station before mowing is complete?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Why does the GOAT return to the docking station before mowing is complete?

## 答案 / Answer

28

Mowing

(1) The lawn is too large and cannot be covered in a single mowing cycle, so the robot needs to return and recharge. It will continue with the unfinished task when its battery level is sufficient. 
 (2) Please check the App and the notifications to see if there are any errors or faults with the GOAT.
