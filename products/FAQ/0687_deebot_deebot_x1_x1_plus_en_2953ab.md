# I already have a map. Can I use quick mapping to save multiple maps?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

I already have a map. Can I use quick mapping to save multiple maps?

## 答案 / Answer

D20272

Intelligence

Storing multiple maps for the same environment is currently not supported. If you already have a map in the same environment, you will need to redo quick mapping and the original map will be replaced. This is also explained in the App. 
In addition, frequent use of the quick mapping command is not recommended unless you need to map a new environment.
