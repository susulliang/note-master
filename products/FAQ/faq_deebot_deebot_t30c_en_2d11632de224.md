# DEEBOT / DEEBOT T30C / EN - Alert: Low Cleaning solution level

## Question

Alert: Low Cleaning solution level

## Answer

1.Open the dust collection cabin and check if the cleaning solution unit is installed. If not, install it correctly.
2.Remove the cleaning solution unit and check if the cleaning solution is used up. If it is, add the Ecovacs cleaning solution in time.
3.After adding the solution, open the APP-enter-settings-maintenance-cleaning solution-I have added.
If the above operations are invalid, please contact after-sales service.
