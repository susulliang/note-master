# ULTRAMARINE / ULTRAMARINE P1 / ZH - How to properly replace the tracks?

## Question

How to properly replace the tracks?

## Answer

Please press and hold the power button to turn off the device first, then follow the steps below.
1.To remove the tracks
1.1 Press and hold the power button to turn off the device completely.
1.2 Pry open one end of the side panel by hand. Use a tool to gently lift the inside of the cover while pulling up with your hand. Repeat on the other end. Once you hear a click, remove the side cover.
1.3 Hold the handle, lift one side of the body, and slowly remove the track while rotating it.
1.4 Remove the track on the other side using the same method.

2.To install the tracks
2.1 Keep the device powered off. Lift the robot from the side so one track is parallel to the ground.
2.2 Take the new track, make sure the toothed side aligns with the gear grooves. Manually rotate the track to check smooth movement — it is correctly installed if it runs smoothly.
2.3 Install the other track using the same method.
