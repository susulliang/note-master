# GOAT / GOAT G1 / ZH - Can I create a linear no-go zone?

## Question

Can I create a linear no-go zone?

## Answer

The no-go zone needs to be a closed area. If you need to establish a linear no-go area, you can remotely control the machine to reach the farthest end and then return to the starting point to make it a closed area.
