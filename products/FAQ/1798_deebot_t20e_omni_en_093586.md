# 물걸레 패드 플레이트가 불규칙하게 회전하거나 회전하지 않으면 어떻게 해야 하나요?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

물걸레 패드 플레이트가 불규칙하게 회전하거나 회전하지 않으면 어떻게 해야 하나요?

## 答案 / Answer

D20393

Cleaning

먼저 로봇의 현재 청소 모드를 확인합니다. ECOVACS HOME 앱을 열고 스마트 청소 ＞ 청소 기본 설정으로 이동하여 다음을 확인합니다. 
(1) 진공 청소 모드로 설정된 경우 물걸레 패드 플레이트가 위로 올라가고 회전이 멈춥니다. 
(2) 물걸레 청소 모드로 설정된 경우 자동 기능이 활성화된 상태에서는 카펫이 감지되면 물걸레 패드가 자동으로 올라가지만 회전하지 않습니다. 카펫이 없는데 물걸레 패드가 회전하지 않는 경우 물걸레 패드 플레이트에 이물질이 얽혔는지 확인하고 이물질이 있으면 분해하여 청소한 후 다시 설치합니다. 
(3) 진공 청소 및 물걸레 청소 모드로 설정된 경우 자동 기능이 활성화된 상태에서는 카펫이 감지되면 물걸레 패드가 자동으로 올라가지만 회전하지 않습니다. 카펫이 없는데 물걸레 패드가 회전하지 않는 경우 물걸레 패드 플레이트에 이물질이 얽혔는지 확인하고 이물질이 있으면 분해하여 청소한 후 다시 설치합니다. 
(4) 청소 모드가 진공 청소 후 걸레질 모드로 설정된 경우에는 로봇이 두 가지 청소 과정을 차례로 완료합니다. 첫 번째 청소 단계에서는 물걸레 패드 플레이트가 자동으로 올라가고 회전하지 않습니다. 두 번째 청소 단계에서 자동 기능이 활성화되어 있으면 카펫이 감지되었을 때 물걸레 패드 플레이트가 올라가고 회전하지 않습니다. 카펫이 없는데 물걸레 패드가 회전하지 않는 경우 물걸레 패드 플레이트에 이물질이 얽혔는지 확인하고 이물질이 있으면 분해하여 청소한 후 다시 설치합니다. 
참고: 로봇이 스테이션으로 복귀하는 동안에는 물걸레 패드 플레이트가 위로 올라간 상태이고 회전하지 않습니다. 충전이나 패드 세척을 위해 스테이션에 도착한 후에만 물걸레 패드 플레이트가 자동으로 내려와 회전합니다.
