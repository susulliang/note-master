# Why does dust collection not start when the robot returns to the station?

## Question

Why does dust collection not start when the robot returns to the station?

## Answer

1. Please check that the station is connected to power and working properly；
2. Please check whether the power cord of the station is correctly inserted into the socket, and the main unit and station are connected;
3. Please confirm in the app that the auto-empty function is turned on; you can open the app-click enter - click smart cleaning - turn on auto-empty;
4. Please check whether the dust collection cabin of the station is installed in place. Remove it and reinstall it;
5. Please check that the disposable dust bag has been installed correctly;
6. Please check whether the Do Not Disturb is set on the APP. During Do Not Disturb period, automatic dust collection will not start;
7. If the main unit is manually moved back to the station, the auto-empty will not start. Only when it returns to the station automatically will the auto-empty be triggered;
8. If the transparent window of the charging contacts of the station is dirty, and the signal may not be transmitted. Please clean it with a dry paper towel and try again;
