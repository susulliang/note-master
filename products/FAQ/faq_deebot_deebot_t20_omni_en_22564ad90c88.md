# DEEBOT / DEEBOT T20 OMNI / EN - How do I use the customized scenario cleaning/cleaning sequence functions?

## Question

How do I use the customized scenario cleaning/cleaning sequence functions?

## Answer

Set up customized scenario cleaning
1. Open the app and go to Smart Cleaning > Customized Scenario Cleaning
2. Customized Scenario Cleaning > Create Scenario > select cleaning mode; Area > select the area you want to customize, tap Edit to set the cleaning frequency and suction power, then tap Save.
3. Customized Scenario Cleaning > Create Scenario > select cleaning mode; Furniture > select the furniture you want to customize, tap Edit to set the cleaning frequency and suction power, then tap Save.

Set the cleaning sequence
1. Open the app > go to Smart Cleaning > set the cleaning sequence.
