# WINBOT / WINBOT W1/W1 Pro / EN - Can the reminder about "the water reservoir need to be filled with Ecovacs cleaning solution or clean water before using the robot" be turned off?

## Question

Can the reminder about "the water reservoir need to be filled with Ecovacs cleaning solution or clean water before using the robot" be turned off?

## Answer

1. The user will be reminded to fill in cleaning solution when the robot is turned on. Both the voice prompt and the app notification will be played only once.
2. If you want to perform a waterless cleaning, you can turn off the "Auto Spray" function in the app.
