# DEEBOT / T90 PRO OMNI / ZH - How to set mop-only mode?

## Question

How to set mop-only mode?

## Answer

1. Open the app > Tap "Enter" > Tap the "Draw" icon > Tap the yellow "Single Mopping Mode" icon in the bottom right corner.
 Note: Single mopping mode can only draw one zone, with an area ≤ 2m x 2m.
