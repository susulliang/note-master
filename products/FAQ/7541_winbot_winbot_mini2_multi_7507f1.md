# Alerte : roue motrice bloquée.
 Comment y remédier ?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Alerte : roue motrice bloquée.
 Comment y remédier ?

## 答案 / Answer

1. Utilisez l'application pour contrôler à distance le WINBOT et le placer dans une position accessible.
 2. Saisissez la poignée et maintenez le bouton Start enfoncé pendant 2 secondes. Retirez le WINBOT une fois que le ventilateur s'est arrêté.
 3. Vérifiez si des corps étrangers sont coincés dans les chenilles de la roue d'entraînement. Si c'est le cas, retirez-les à l'aide d'un outil, puis redémarrez le WINBOT pour poursuivre le nettoyage.
