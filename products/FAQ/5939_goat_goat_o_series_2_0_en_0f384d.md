# GOAT在狭窄通道中产生漏割 / The GOAT leaves some uncut areas in the narrow path.

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

GOAT在狭窄通道中产生漏割 / The GOAT leaves some uncut areas in the narrow path.

## 答案 / Answer

4- 割草

当狭窄通道宽度小于0.7m时，GOAT会将其作为可通行通道行走，无法完全进行弓字型切割，建议若宽度过小，定期使用打草机进行修理。

When the width of the narrow path is less than 0.7m, GOAT will run through it as a passable channel and cannot completely mow all areas. If the width is too small, it is recommended to regularly use a manual lawn mower to mow.
