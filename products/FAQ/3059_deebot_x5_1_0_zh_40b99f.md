# Wie verwende ich den Sprachassistenten YIKO? / 1. Öffne die App ＞ geh auf die Seite zum App-Betrieb ＞ „Settings“ (Einstellungen) oben rechts ＞ „YIKO Setting“ (YIKO-Einstellungen) ＞ „Enable Voice Assistant“ (Sprachassistenten aktivieren). Hinweis: Wenn du den YIKO-Sprachassistenten ＞ „Voice Assistant“ (Sprachassistent) deaktivierst, wird die AUTO-Modus-Taste von DEEBOT gelb. 2. „OK YIKO“-Sprachbefehlanleitung
2.1 Tippe im YIKO-Sprachassistenten auf „All“ (Alle), um alle YIKO-Sprachbefehle anzuzeigen.
Du kannst DEEBOT Befehle geben, wie etwa „OK YIKO, reinige das Haus“ oder „OK YIKO, erhöhe die Saugleistung“.
Hinweis: ① YIKO lernt stetig neue Sprachbefehle. Öffne die App, um zu sehen, welche Sprachbefehle du verwenden kannst. ② YIKO-Sprachbefehle können innerhalb einer Reichweite von 5 m ausgelöst werden. ③ Der YIKO-Sprachassistent unterstützt derzeit die folgenden Offline-Funktionen. Andere Sprachbefehle können nur verwendet werden, wenn eine Verbindung zu einem Netzwerk besteht. OK YIKO, schalte Bluetooth ein, und stelle eine Verbindung her.
OK YIKO, beginne mit der Kartierung.
OK YIKO, beginne mit der Reinigung.
OK YIKO, reinige das Haus.
OK YIKO, kehre zur Dockingstation zurück.
OK YIKO, kehre zum Aufladen zurück.
OK YIKO, verlass die Dockingstation.
OK YIKO, beginne die Selbstreinigung der Dockingstation.
OK YIKO, schalte die Kindersicherung aus.
