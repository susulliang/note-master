# PIN码设置后可以修改吗？ / Can I change the PIN code after it has been set?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

PIN码设置后可以修改吗？ / Can I change the PIN code after it has been set?

## 答案 / Answer

5- 智能&安全

可在APP “设置”-“更多设置”-“安全设置”-“修改PIN码”中进行修改

You can change it in the App by going to Settings ＞ More Settings ＞ Security Settings ＞ Change PIN Code
