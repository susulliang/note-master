# 找到基站回不去（打滑）如何处理？ / What to do if the robot finds the station but can't return due to slipping?

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

找到基站回不去（打滑）如何处理？ / What to do if the robot finds the station but can't return due to slipping?

## 答案 / Answer

温馨提示：
当您在使用过程中若您有遇到机器人找到基站附近却无法回去等情况，您可以按如下步骤进行相关操作尝试：
①检查基站斜坡底座及周边地面是否水渍较多，若是，请使用干的抹布擦拭回充托盘及周围地面。
②将机器关机，取下污水盒，翻转后底部朝上，先把抹布打湿拧干后转动擦拭驱动轮，再用干抹布擦拭干净驱动轮上的水渍
③检查滚筒拖布是否已安装到位，若是，请重新安装。
④检查机器人可拆卸斜坡底座与可拆清洁槽托盘是否安装到位，若否，请同时取下并重新安装；
以上操作完成您可以将地宝放置基站正前方，长按机器人“启动按键”观察是否能够返回基站，若有效，说明机器返回基站的功能是正常的，若无效，请联系我们售后处理

1.Check if there is excess water inside the mop washing tray and the surrounding floor. If so, wipe the tray and surrounding area with a dry cloth.
 2.Turn off the robot, flip it over, and clean the drive wheels. First, dampen a cloth, wring it out, and wipe the wheels. Then, dry them with a clean cloth.
 3.Check if the roller mop is properly installed. If so, reinstall it.
 4.Check if the mop washing tray is properly installed. If not, remove and reinstall it.
 After completing the above steps, place the robot directly in front of the base station and press the "Auto" button to see if it can return. If it works, the function is normal. If not, contact our after-sales service.
