# ฉันจะอัปเกรดเฟิร์มแวร์ของหุ่นยนต์ได้อย่างไร

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

ฉันจะอัปเกรดเฟิร์มแวร์ของหุ่นยนต์ได้อย่างไร

## 答案 / Answer

D20337

Upgrade

1. ต้องวาง DEEBOT บนชุดถังน้ำและต้องชาร์จอยู่ 
2. ต้องชาร์จ DEEBOT สูงสุด 50% (ขอแนะนำให้อัปเกรดหลังจากชาร์จนาน 3 ชั่วโมง) 
3. ตรวจสอบว่า DEEBOT เชื่อมต่อกับแอป ECOVACS HOME และสัญญาณ WiFi มีความเสถียร
4. ไปที่การทำความสะอาดอัจฉริยะ ＞ การตั้งค่า ＞ เกี่ยวกับ DEEBOT ＞ อัปเดต DEEBOT

หมายเหตุ: หากเปิดใช้งานอัปเดตอัตโนมัติ DEEBOT จะอัปเกรดเป็นเวอร์ชั่นล่าสุดโดยอัตโนมัติ
