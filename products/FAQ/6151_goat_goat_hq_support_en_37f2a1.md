# GOAT G1为何充电很慢？

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

GOAT G1为何充电很慢？

## 答案 / Answer

G00013

Disable

基站相关

（1）G1在正常情况下约1个半小时可将电量充至80%，之后为了保护电池基站将会切换为小电流充电，充电时间会变长（电池完全充满约需2~2.5个小时）
（2）当电池温度≤8℃时为了保护电池基站将会切换为小电流充电，充电时间会变长（电池完全充满需3~5个小时）
（3）长期使用后电池老化，可能导致充电时间变长
如非以上情况，请联系科沃斯售后服务部门。
