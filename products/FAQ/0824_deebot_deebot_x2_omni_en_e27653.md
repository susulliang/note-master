# Cuando el DEEBOT está limpiando, las placas para la mopa de limpieza no se levantan o chocan con los felpudos. ¿Qué debo hacer?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

Cuando el DEEBOT está limpiando, las placas para la mopa de limpieza no se levantan o chocan con los felpudos. ¿Qué debo hacer?

## 答案 / Answer

D20418

Mopping

¿Las bandejas de las mopas de fregado no se levantan? 
1. Puede abrir la aplicación, ir a Limpieza inteligente (Smart Cleaning) y tocar la alfombra en el mapa para consultar la estrategia de limpieza de alfombras. Si desea cambiar la configuración la alfombra, puede seleccionar la alfombra que desea añadir o eliminar, o bien restablecer la estrategia para la alfombra que se ha añadido.

Instrucciones de configuración de la estrategia para alfombras:
Evitación (Avoid):  El DEEBOT evitará la alfombra durante la limpieza. Le recomendamos esta configuración cuando tenga alfombras con pelo medio y largo.
Solo aspiración (Vacuum Only):  Para alfombras con pelo corto (menos de 10 mm) o alfombrillas de interior.
Solo pasar por encima (Pass Only):  Le recomendamos esta configuración si tiene alfombras con pelo medio o largo situadas al lado de una puerta o en una habitación.

2. Confirme el modo de limpieza del robot: 
(1) En el modo Aspiración (Vacuum), las bandejas de las mopas de fregado se levantan. Este comportamiento es normal.
(2) En el modo Fregado (Mopping), las bandejas de las mopas de fregado solo se levantarán automáticamente cuando se detecte una alfombra. 
(3) En el modo Aspiración y fregado (Vacuum and Mopping), las bandejas de las mopas de fregado solo se levantarán automáticamente cuando se detecte una alfombra. 
(4) En el modo Fregado tras aspiración (Mop after Vacuum), las bandejas de las mopas de fregado se levantarán para la fase de aspiración y se bajarán para la fase de fregado. Solo se volverán a levantar si se detecta una alfombra. 
3. Si las situaciones anteriores no son relevantes teniendo en cuenta su problema, pruebe los siguientes pasos: 
(1) Compruebe si las bandejas de las mopas de fregado tienen residuos atascados. En caso afirmativo, limpie dichos residuos. 
(2) Compruebe si las bandejas de las mopas de fregado están bien fijadas al robot. De no ser así, vuelva a colocarlas. 

Las bandejas de las mopas de fregado se levantarán al limpiar alfombras, pero el robot podría atascarse si choca con alguna esquina de alfombra enrollada. Se recomienda utilizar cinta de doble cara para pegar las esquinas enrolladas o definir una pared virtual para evitar el área.
