# ¿Por qué el DEEBOT derrama polvo cuando muevo el robot de forma manual?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Por qué el DEEBOT derrama polvo cuando muevo el robot de forma manual?

## 答案 / Answer

D10015

Enable

Usage advice

Si se derrama polvo al mover el DEEBOT de forma manual, es probable que el recipiente para polvo esté demasiado lleno. El recipiente para polvo debe vaciarse periódicamente para obtener la mejor limpieza. Cuando mueva el DEEBOT manualmente, levante el robot con las dos manos y mantenga el extremo con la marca "DEEBOT" ligeramente inclinado hacia arriba para evitar derrames.
