# How to use fixed-point cleaning?

## Question

How to use fixed-point cleaning?

## Answer

How to use fixed-point cleaning?
1. Place the robot in the area that needs to be cleaned
2. Manually press the "fixed cleaning button".
3. After the work is completed, the machine will return to the station.
Note: Fixed-point cleaning can only be triggered by the Dibao button
