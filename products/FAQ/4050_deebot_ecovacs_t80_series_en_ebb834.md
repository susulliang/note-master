# How do I set up the clean carpet first feature?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

How do I set up the clean carpet first feature?

## 答案 / Answer

1. Click "Settings" ＞ Select "Robot Advanced Settings" ＞ Select "Clean Carpet First" to turn it on or off.
Note: Set the cleaning strategy for the carpet to "Vacuum Only" in advance. The robot will vacuum the carpet first, return to the base to wash the mop, and then clean other areas.
