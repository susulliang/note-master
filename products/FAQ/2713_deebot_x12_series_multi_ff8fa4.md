# 20

> **产品线**：DEEBOT　**语言**：multi
>

## 问题 / Question

20

## 答案 / Answer

Si le robot vous signale que le Réservoir d’eau sale n’est pas installé ou qu’il est plein, vous pouvez essayer les étapes suivantes :
1. Retirez le réservoir et videz les eaux usées. (S’il reste des saletés au fond du réservoir, vous pouvez utiliser une brosse de nettoyage pour faciliter le nettoyage.)
2. Vérifiez le flotteur dans le Réservoir d’eau sale pour vous assurer qu'il pivote correctement.
3. Refermez le couvercle supérieur du Réservoir d’eau sale et assurez-vous que les clips sont bien en place.
4. Réinstallez le Réservoir d’eau sale dans la station.
