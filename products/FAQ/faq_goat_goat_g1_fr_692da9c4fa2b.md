# Que faire si j'ai oublié le code PIN de ma GOAT G1 ?

## Question

Que faire si j'ai oublié le code PIN de ma GOAT G1 ?

## Answer

(1) Si la GOAT est liée à l'application, accéder à Paramètres > Plus de paramètres > Paramètres de sécurité > Modifier le code PIN > J'ai oublié mon code PIN pour réinitialiser le code PIN. Il sera nécessaire de saisir le mot de passe de votre compte ECOVACS HOME.
(2) Si la GOAT n'est plus liée à l'application, contacter le service clientèle pour réinitialiser le code PIN.
