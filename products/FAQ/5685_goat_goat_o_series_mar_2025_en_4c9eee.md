# 通道可以横跨一个已经建好地图的草坪区域吗？ / Can the path on the map pass across a created lawn area during mapping?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

通道可以横跨一个已经建好地图的草坪区域吗？ / Can the path on the map pass across a created lawn area during mapping?

## 答案 / Answer

3- 建图

不可以，创建通道时如果横跨一个已经建好地图的草坪区域，会自动结束通道创建，保留当前已经建立的通道。

No, if the draw-path is created pass across the lawn on the map, the path creation will be automatically terminated.
