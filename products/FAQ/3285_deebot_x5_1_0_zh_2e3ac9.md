# 세척조의 폐수를 재활용할 수 없거나 폐수통에 물이 없지만 로봇 청소기는 폐수통이 가득 찼다고 알려줍니다. / * 스테이션에서 표시등이 깜박이는지 확인합니다. 표시등이 깜빡이면 먼저 스테이션의 전원을 꺼야 합니다. 그런 다음 스테이션의 전원을 다시 켜고 문제를 해결합니다.

2. 스테이션의 상단 덮개를 열고 물탱크와 폐수통을 꺼냅니다. 탱크의 덮개를 열어 실링 플러그가 올바르게 설치되었는지 확인하고 10초 후에 닫습니다.
3. 물탱크와 폐수통의 실링 플러그를 누릅니다.
4. 물탱크와 폐수통을 다시 스테이션에 놓고 누릅니다.
