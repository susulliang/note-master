# 使用沿边打草时，GOAT未完全按照我选择的边缘进行打草。 / When using edge trimming, GOAT did not completely follow the edge I selected for trimming.

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

使用沿边打草时，GOAT未完全按照我选择的边缘进行打草。 / When using edge trimming, GOAT did not completely follow the edge I selected for trimming.

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

12- 打草

1.由于定位精度的限制，如果禁区轮廓之间或禁区与外轮廓之间存在交叠将默认一起切割所有交叠的轮廓。如果轮廓间的间距小于1m, GOAT有一定概率认为轮廓存在交叠，从而无法抵达这部分轮廓。
2.打草过程中若遇到人、动物或其他障碍物，GOAT会避开，直到完全避开后才会靠近选择的边缘。
（1）建议在GOAT打草时，不要跟随太近，避免避障导致的漏打草，可以选择多次打草，以保证较好的打草效果
（2）若有一些无法到达的地方，可使用遥控打草功能。
