# 메인 브러시는 어떻게 분리하고 세척하나요?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

메인 브러시는 어떻게 분리하고 세척하나요?

## 答案 / Answer

D20352

Maintenance

1. DEEBOT 전원을 끈 다음 뒤집어서 바닥이 위로 향하게 놓습니다. 
2. 아래로 눌러 메인 브러시 덮개를 분리하고 메인 브러시 어셈블리를 분리합니다. 
3. 메인 브러시에 엉킨 이물질을 제거합니다(메인 브러시 양쪽 끝의 액세서리를 분해하여 세척할 수도 있습니다). 
4. 메인 브러시 어셈블리를 로봇에 부착합니다. "딸깍" 소리가 나면 제대로 설치된 것입니다. 
팁: 메인 브러시를 설치한 후 메인 브러시 덮개를 부착하기 전에 메인 브러시를 돌려 부드럽게 회전하는지 확인하십시오.
