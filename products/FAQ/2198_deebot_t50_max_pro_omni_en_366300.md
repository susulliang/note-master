# 自动集尘仓/更换集尘袋 / How to replace dust bag?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

自动集尘仓/更换集尘袋 / How to replace dust bag?

## 答案 / Answer

1. 取下集尘仓挡板；
2. 取出尘袋并丢弃；
3. 用干抹布擦拭集尘仓，安装新尘袋；
4. 关闭集尘仓挡板；

1. Remove dust collection cabin baffle;
2. Remove and discard the dust bag;
3. Wipe the dust collection cabin with a dry rag and install a new dust bag;
4. Install the dust collection cabin bafffle;
