# 如果把RTK基站头取下后未按原位置放回，还能正常使用GOAT吗？ / Can I still use GOAT if the RTK Reference Station is removed and not put back in original place?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

如果把RTK基站头取下后未按原位置放回，还能正常使用GOAT吗？ / Can I still use GOAT if the RTK Reference Station is removed and not put back in original place?

## 答案 / Answer

RTK Reference Station

不建议移动RTK基站
（1）RTK基站头位置移动，小范围移动(＜5m)无法准确检测出来，可能会导致机器定位出错，存在机器出界、跌落等风险，不建议移动。
（2）RTK基站头位置移动，大范围移动(＞5m),RTK基站可自行检测出被移动，GOAT将会自动停止工作
 (3)可将RTK基站归回原位，或移动基站并固定后，重新建图。

It is not recommended to move.
(1) If the movement occur in the small-range ＜5m, it cannot be accurately detected, which may lead to the GOAT positioning errors and risks such as out-of-boundary or falling.
(2)  If the movement occur in the large-range ＞5m, it can be detected, and the GOAT will automatically stop working. 
(3)To restore proper positioning, it is recommended to return the RTK Reference Station to its original location, or remap after moving the RTK Reference Station.
