# 如何使用智能体模式及设置YIKO清洁偏好？ / How to Use Agent Mode and Set Cleaning Preferences via YIKO？

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

如何使用智能体模式及设置YIKO清洁偏好？ / How to Use Agent Mode and Set Cleaning Preferences via YIKO？

## 答案 / Answer

一、如何启用智能体以及打扫参数设置：
1.打开APP-点击进入设备-开启智能体模式-点击启动
2.点击进入智能体设置入口-选择需要设置区域-设置相应的吸力大小/水量大小/工作模式/工作效率
二、智能体模式清洁偏好设置：
1..打开APP-点击进入设备-点击进入智能体模式
2.点击右上角YIKO按钮，打开YIKO对话框
3.点击“我的偏好”打开偏好设置对话框
4.在偏好设置在对话框说出/输入偏好-例如：”晚上10点以后就不要打扫卧室了“
5.待AI智能体生成相对应方案-点击“采纳”/刷新按钮重新生成
6.点击“采纳”按钮后，偏好将在偏好设置对话框上端列表展示
7.偏好设置删除：点击偏好设置按钮-点击“√”取消勾选-点击保存即可

温馨提示：若您想使用智能模式进行清洁，在完成建图之后，需先执行一次基础清洁任务，方可启动智能模式。

1. Enable Agent Hosting & Set Cleaning Parameters
1.1 Open the app ＞ Enter  ＞ Enable Agent Hosting ＞Tap "Start"
1.2 Go to Agent Hosting ＞ Select areas ＞Set suction power, water level, cleaning mode, and efficiency
2. Set Cleaning Preferences via YIKO
2.1 Open the app＞Enter＞Agent Hosting
2.2 Tap the YIKO icon (top right)
2.3 Tap "My Preferences" to open the settings
2.4 Say or type your preference (e.g., "Don’t clean the bedroom after 10 PM")
2.5 Tap "Adopt" to save it or "Refresh" to regenerate
2.6 Saved preferences will appear in the list above                                                                                2.7 To delete: uncheck it and tap "Save"
Note:
Complete a basic cleaning task after mapping to enable Agent Hosting.
