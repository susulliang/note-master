# DEEBOT / DEEBOT T30 OMNI Silver / EN - Machine alarm: The machine is running difficult. Please check the driving wheels. What should I do?

## Question

Machine alarm: The machine is running difficult. Please check the driving wheels. What should I do?

## Answer

1. Check the anti-collision protection strip on the main unit to see if it has been removed. If not, please remove it before use.
2. Turn off the main unit and turn it over with the bottom facing up and place it gently;
3. Press and turn the driving wheel to clear the entanglement;
