# How do I use the Area Cleaning/Funiture Area Cleaning/Custom Cleaning/Housekeeper modes?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

How do I use the Area Cleaning/Funiture Area Cleaning/Custom Cleaning/Housekeeper modes?

## 答案 / Answer

D20412

Usage advice

Housekeeper Mode 
1. Go to Smart Cleaning and select Housekeeper Mode. 
2. This mode can only be used after mapping is complete. 
In Housekeeper Mode, the robot will automatically adjust the suction power and other functions according to the room type. 

Area Cleaning 
1. This mode can only be used after mapping is complete. 
2. After mapping is complete, the robot will divide the map into areas for cleaning. 
3. Select which area you want to clean based on your needs. In cleaning preferences you can select the cleaning mode, the cleaning frequency, suction power etc. 
4. Select multiple areas to clean. DEEBOT will clean the areas in sequence according to the selected cleaning order (this must be set each time). 
5. The suction power cannot be adjusted in Vacuum and Mopping mode, and the frequency cannot be adjusted in Mop after Vacuum mode. 
How to use: 
(1) Using the voice assistant commands: 
For example, you can say to the robot: "OK YIKO, clean Room A" 
(2) Using the app: 
(1) If you have already set the cleaning order in cleaning preferences, DEEBOT will give priority to this order. 
(2) If the robot has already started cleaning, the cleaning mode and frequency cannot be changed. The suction power level can be adjusted in real time according to needs. 

Furniture Area Cleaning 
1. This function can only be used once mapping is complete and the map contains furniture (You can add furniture through Map ＞ Home Furnishing). 
2. Select the cleaning mode (e.g. vacuum), frequency, and suction power in cleaning preferences. 
3. The suction power cannot be adjusted when mopping, and the frequency cannot be adjusted when in Mop after Vacuum mode. 

Custom Cleaning 
1. Once mapping is complete, you can use Custom Cleaning. Custom cleaning can only be set within the map range. 
2. One or more custom areas can be added to the map. DEEBOT will clean the areas according to the order in which they are added. 
3. Select the cleaning mode (e.g. vacuum), frequency, and suction power in cleaning preferences. 
4. The suction power cannot be adjusted when mopping, and the frequency cannot be adjusted when in Mop after Vacuum mode.
