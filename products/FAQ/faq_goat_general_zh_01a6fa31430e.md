# GOAT未割完草就返回基站了

## Question

GOAT未割完草就返回基站了

## Answer

1. For large maps where a single mow session cannot be completed, the machine will return to recharge mid-task and resume the unfinished job once battery is sufficient.
 2. If conditions triggering return to base occur (e.g., darkness, animal protection, or rain), the machine will pause operation and return to the station first. 3. If a mow task is paused for over 30 minutes, GOAT will automatically return to the station to pause and prevent prolonged outdoor exposure that could drain its battery.You may resume the task, and GOAT will automatically return to the paused location to continue working.
 4. Check the app's push notifications to see if GOAT has encountered any abnormalities or malfunctions.
