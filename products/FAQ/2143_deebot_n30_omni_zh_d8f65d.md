## 答案 / Answer

How do I set custom cleaning?

1. Ensure that the Robot has successfully connected to the App and is online.
2. Map should be created first. Open App-Click robot controls-Click Settings-Robot Advanced Settings-Scenario Clean.
3.You can directly add 'Daily Cleaning/Deep Cleaning' and other scenarios.
4.Also support  set cleaning preferences of each area in the scenario.
