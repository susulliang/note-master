# DEEBOT / ECOVACS T80 Series / EN - How do I install an overflow float?

## Question

How do I install an overflow float?

## Answer

1.Remove the mop washing tray.
2. Install the longer end of the float onto the mount first, followed by the shorter end. After completing the installation, pivot the overflow float up and down, if it returns naturally, the installation is considered normal.
Note: The magnet should always remain in the bottom position of the float after installation is complete.
