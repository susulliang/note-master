# 자체 세척 기능을 사용하여 더러워진 스테이션의 세척조를 청소하려면 어떻게 하나요? / 베이스 스테이션의 자동 청소 기능 안내 

1. 스테이션의 시작 버튼을 3초 동안 길게 누릅니다. 로봇이 자동으로 스테이션에서 나오고 세척조에서 물이 자동으로 흘러나옵니다. 
2. 청소용 브러시를 사용하여 세척조를 청소합니다. 
3. 세척이 완료되면 스테이션의 시작 버튼을 5초 동안 길게 누릅니다. 그러면 세척조에서 폐수가 배출됩니다. 
4. 로봇을 스테이션 앞에 놓고 시작 버튼을 길게 눌러 로봇이 돌아가 충전되도록 합니다. 
5. 스테이션의 상단 덮개를 열고 폐수통을 꺼내 폐수를 비웁니다. 
6. 청소 싱크 안의 청소 트레이에 머리카락이나 먼지가 많이 쌓인 경우 청소 트레이의 분리 버튼을 눌러 청소 트레이를 분리하여 청소할 수 있습니다. 청소 후 다시 장착합니다.
참고: (1) 사용하기 전 물탱크에 물이 충분한지 확인하십시오. 
          (2) 자체 세척 기능은 필요할 때마다 실행할 수 있습니다.
