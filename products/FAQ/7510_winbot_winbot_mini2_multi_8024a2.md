# ¿Cómo se utiliza el botón de reinicio?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

¿Cómo se utiliza el botón de reinicio?

## 答案 / Answer

Consejo: 
 Si el WINBOT se bloquea, utilice el botón de reinicio para recuperarlo. Siga estos pasos:
 
 . En modo de espera, dé la vuelta al WINBOT y busque el pequeño orificio «Reset».
 2. Utilice una herramienta puntiaguda, como un palillo, para mantener pulsado el botón de reinicio. Suéltelo cuando se apague el indicador.
 3. Apague y vuelva a encender el WINBOT para completar el reinicio.
