# Le module de connexion automatique est-il toujours disponible après le remplacement du robot ?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Le module de connexion automatique est-il toujours disponible après le remplacement du robot ?

## 答案 / Answer

G00139

Disable

Additional Connection Module

Le module de connexion automatique est lié au module. Un service de trois ans peut être utilisé sur le robot A pendant un an, puis sur le robot B pendant les deux années restantes.
