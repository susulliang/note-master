# If there is too much dust on the glass, do I have to remove the dust before using WINBOT?

> **产品线**：WINBOT　**语言**：en
>

## 问题 / Question

If there is too much dust on the glass, do I have to remove the dust before using WINBOT?

## 答案 / Answer

W00081

Usage advice

The W1/W1 PRO WINBOT have a smart climbing system that enables the robot to stick to the glass, so do not need to remove the dust beforehand.
