# 4

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

4

## 答案 / Answer

1. Retirez le WINBOT de son crochet.
2. Utilisez votre téléphone pour scanner le code QR à l'intérieur de la station. Vous pouvez également rechercher « ECOVACS HOME » dans votre Magasin d’applications, puis télécharger l'application et créer un compte.
3. Connexion Bluetooth :
① Cliquez sur le bouton « + » (Ajouter) sur la page d'accueil de l'application et scannez le code QR à l'arrière de la station. Appuyez sur le bouton d'alimentation de la station et maintenez-le enfoncé pendant 2 secondes pour l'allumer, puis attendez que le son de démarrage se termine. Suivez les instructions de l'application : cliquez sur « Allumé », puis sur « Ignorer la connexion pour l'instant » et enfin sur « Commencer à utiliser » pour terminer la connexion Bluetooth.
4. Connexion Wi-Fi :
① Cliquez sur le bouton « + » (Ajouter) sur la page d'accueil de l'application et scannez le code QR au dos de la station. Appuyez sur le bouton d'alimentation de la station et maintenez-le enfoncé pendant 2 secondes pour l'allumer, puis attendez que le son de démarrage se termine. Cliquez sur « Allumé », puis sélectionnez « Choisir le réseau Wi-Fi domestique » et entrez votre mot de passe Wi-Fi. Appuyez sur le bouton de fonction de la station et maintenez-le enfoncé pendant 3 secondes. Après avoir entendu le message vocal « Entrée en mode d'appairage Wi-Fi », cliquez sur « Terminé » dans l'application et attendez que la configuration Wi-Fi soit terminée.
Conseils :
Si vous ne parvenez pas à scanner le code QR, vous pouvez également cliquer sur « Sélectionner le modèle » dans l'interface de scan. Choisissez le modèle Winbot correspondant et suivez les instructions à l'écran pour terminer la connexion.
