# Comment télécharger l'application ECOVACS HOME ? / Scanner le code QR sur le robot ou rechercher l'application ECOVACS HOME dans Google Play ou l'App Store d'Apple, puis suivre les instructions pour télécharger et installer l'application. 

Conseils :
* Suivre les instructions de l'application pour terminer l'enregistrement, la connexion et la connexion Wi-Fi. 
* S'assurer que le téléphone est connecté au réseau Wi-Fi domestique avant d'ajouter un robot.
