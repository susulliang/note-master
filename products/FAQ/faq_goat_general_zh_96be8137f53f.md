# 我的前后院是不连通的，应该如何建图？

## Question

我的前后院是不连通的，应该如何建图？

## Answer

(1) It is recommended that you only create a map for the front yard or backyard if there is no any path connecting the front and back lawns.
(2) It is recommended to create a single complete area that includes both the front yard and backyard if there is a path connecting the front and back lawns. Use the multi-zone function to schedule the mowing task effectively.
(3) It is also recommended that you can map two areas and a path will connect these two mowing areas.
