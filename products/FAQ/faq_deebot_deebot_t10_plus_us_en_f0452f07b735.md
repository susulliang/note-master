# DEEBOT / DEEBOT T10 PLUS（US） / EN - How do I select DEEBOT T10's suction power?

## Question

How do I select DEEBOT T10's suction power?

## Answer

You can set the suction power via the App: Quiet mode, Standard, Max, Max+.
(1) There is reduced suction power in Quiet mode. It is recommended to use in Vacuum and Mopping mode.
(2) Select Max or Max+ for a dirty floor. However, please note that the single cleaning time of the DEEBOT may be reduced when using Max/Max+ suction power.
