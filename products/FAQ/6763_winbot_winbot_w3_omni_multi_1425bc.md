# 18

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

18

## 答案 / Answer

Reminder: When attaching the WINBOT, if it is too close to the edge, the robot cannot complete the edge detection smoothly, which will trigger the alarm. You can try the following operations:
1.Press and hold the start button for ≥2 seconds, and remove the WINBOT by holding the handle firmly.
2.Reattach the WINBOT. It is recommended to place it more than 10cm away from the window edge.
