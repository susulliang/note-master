# ¿Puedo descargar actualizaciones de versión para el robot directamente desde Internet?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Puedo descargar actualizaciones de versión para el robot directamente desde Internet?

## 答案 / Answer

D20031

Enable

OTA

Cuando se conecta a una red WiFi, el DEEBOT puede recibir actualizaciones (OTA). La aplicación descarga automáticamente el paquete de firmware más reciente. Solo tiene que seguir los pasos de la aplicación para completar las actualizaciones.
