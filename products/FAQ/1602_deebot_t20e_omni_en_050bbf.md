# ¿Qué debo hacer si las bandejas de las mopas de fregado giran intermitentemente o no giran en absoluto?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Qué debo hacer si las bandejas de las mopas de fregado giran intermitentemente o no giran en absoluto?

## 答案 / Answer

D20393

Cleaning

En primer lugar, confirme el modo de limpieza actual del robot. Abra la aplicación ECOVACS HOME, vaya a Limpieza inteligente (Smart Cleaning) ＞ Preferencias de limpieza (Cleaning Preferences) para comprobar lo siguiente: 
(1) Si el modo de limpieza se establece en Aspiración (Vacuum), las bandejas de las mopas de fregado se levantarán y no girarán. 
(2) Si el modo de limpieza se establece en Fregado (Mopping), las bandejas de las mopas de fregado se levantarán automáticamente pero no girarán cuando se detecte una alfombra si la función Estrategia automática (Auto strategy) está activada. Si no hay ninguna alfombra y las bandejas de las mopas de fregado no giran, compruebe si las bandejas tienen residuos enredados y, de ser así, desmóntelas y límpielas. A continuación, vuelva a instalarlas. 
(3) Si el modo de limpieza se establece en Aspiración y fregado (Vacuum and Mopping), las bandejas de las mopas de fregado se levantarán automáticamente pero no girarán cuando se detecte una alfombra si la función Estrategia automática (Auto strategy) está activada. Si no hay ninguna alfombra y las bandejas de las mopas de fregado no giran, compruebe si las bandejas tienen residuos enredados y, de ser así, desmóntelas y límpielas. A continuación, vuelva a instalarlas. 
(4) Si el modo de limpieza se establece en Fregado tras aspiración (Mop after Vacuum), el robot realizará dos procesos de limpieza. Durante la primera limpieza, las bandejas de las mopas de fregado se levantarán automáticamente, pero no girarán. Durante la segunda limpieza, si la función Estrategia automática (Auto strategy) está activada, cuando se detecten alfombras, las bandejas de las mopas de fregado se levantarán pero no girarán. Si no hay ninguna alfombra y las bandejas de las mopas de fregado no giran, compruebe si las bandejas tienen residuos enredados y, de ser así, desmóntelas y límpielas. A continuación, vuelva a instalarlas. 
Nota: Cuando el robot vuelve a la estación, las bandejas de las mopas de fregado se levantan y no giran. Las bandejas de las mopas de fregado solo se bajarán y girarán automáticamente tras llegar a la estación, ya sea para que el robot se cargue o para que limpie las mopas.
