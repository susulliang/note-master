# WINBOT / WINBOT mini2 .0 19langs / ZH - 28

## Question

28

## Answer

第一步：取下機器。
  請連接APP手動遙控機器至可手動取下的位置，重新吸附工作即可。若使用時沒有連接APP，則可以通過如下兩種方法連接：
  1. 若機器停駐在外窗且可以掃描到二維碼的位置，直接用APP掃描並按步驟連接
  2. 無法掃描到二維碼時，可以直接在APP種選擇手動添加，選擇對應型號之後，也可完成連接。
  機器同時會有語音提醒，提醒您按照APP步驟來完成操作。
第二步：檢查機器及窗戶。
  1、檢查擦窗布是否安裝正確，寬窄邊對齊；
  2、為確保機器安全運行，機器在窗戶邊框≤2mm和有縫隙的玻璃上不建議進行沿邊清潔，避免機器有掉落風險，可使用快速清潔模式對此區域進行清潔。
