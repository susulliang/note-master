## 问题 / Question

How to set clean along the floor direction? / How to set clean along the floor direction? / Wie kann ich festlegen, dass die Reinigung entlang der Ausrichtung des Bodens erfolgt? / Comment configurer le nettoyage dans le sens du sol ? / Come si imposta la pulizia lungo la direzione del pavimento? / 床の向きに沿って清掃するよう設定する方法を教えてください。 / 바닥 방향을 따라 청소를 설정하는 방법은 무엇입니까?

## 答案 / Answer

床の向きに沿って清掃するよう設定する方法を教えてください。

1.［設定］-［DEEBOT詳細設定］-［床に沿って清掃］の順にクリックして、設定のオン/オフを切り替えます。
2.床材を設定するエリアを選択し、［木］を選択し、90°アイコンをクリックして、床の木目が水平方向または垂直方向に表示されるように調整します。
