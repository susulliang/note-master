# 基站安装注意事项 / Notes for base station installation

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

基站安装注意事项 / Notes for base station installation

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

1- 充电基站

1、放置区域：基站可放置在雨棚底下、车库等非草坪区域，但为保证更好的回充效果，请勿将其置于狭窄通道中，充电基站左右各需预留40cm的平坦区域，且前方2m内不要有障碍物遮挡；同时建议尽可能将基站放在房屋附近。
2、位置调整：在地图创建前可随意调整基站位置，地图生成后改变基站位置会造成定位信号移动，需重新创建地图。
3、固定方式：建议用附件的地钉将基站固定在地上，若不用地钉固定，可能导致基站移动、回充失败，长期不固定还可能使底板变形，影响回充。
