# Can you use the real-time location function after installing the Cellullar Module?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Can you use the real-time location function after installing the Cellullar Module?

## 答案 / Answer

G00156

Additional Connection Module

Yes, after the Cellullar Module is installed, you can turn on the real-time location switch in "Settings" - "More Settings" - "Network Settings". When the switch is turned on, GOAT detects that it has moved away from the mowing range (around 200m), it will push a Google map to your phone, marking GOAT's current location
