# What should I do if the mopping pad plate does not retract properly? / 1. Go to App ＞ Settings ＞ Robot Advanced Settings and make sure that TruEdge Adaptive Edge Mopping is enabled.
2. Manually move the mopping pad plate back and forth to check for any stuck foreign objects.
3. Restart DEEBOT.
4. If the issue persists, please contact customer service.
Note: Please be aware that if the mopping pad plate is manually extended when DEEBOT is turned off, it cannot be manually retracted. The mopping pad plate will automatically retract when DEEBOT is switched on.
