# Puis-je modifier le code PIN une fois qu'il a été défini ?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Puis-je modifier le code PIN une fois qu'il a été défini ?

## 答案 / Answer

G00115

Enable

Intelligence & Privacy

(1) Il peut être modifié dans l'application en accédant à Paramètres ＞ Plus de paramètres ＞ Paramètres de sécurité ＞ Modifier le code PIN 
(2) Il peut être modifié sur l'écran en accédant à Paramètres ＞ Modifier le code PIN
