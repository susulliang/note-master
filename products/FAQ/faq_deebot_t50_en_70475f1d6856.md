# DEEBOT / T50降配版 / EN - What should I do if the robot does not perform Intelligent Interrupted Cleaning Resume?

## Question

What should I do if the robot does not perform Intelligent Interrupted Cleaning Resume?

## Answer

1.Check the setting: Please confirm whether the "Intelligent Interrupted Cleaning Resume" function is enabled in the App settings.

2.Do Not Disturb Mode: Note that this function will not be triggered if the robot returns to charge during the set "Do Not Disturb" hours.

3.Error Alerts: After the robot automatically returns to the base station to charge, check if any error alerts have been triggered. If an error alert is active, the Interrupted Cleaning Resume function will not activate.

4.Avoid Interruption: After the Intelligent Interrupted Cleaning Resume function has been triggered, do not turn the robot off and on again or perform a factory reset, as this will cancel the resumed cleaning task.

Note: The Interrupted Cleaning Resume function is only effective when the robot is operating in Automatic Cleaning mode.
