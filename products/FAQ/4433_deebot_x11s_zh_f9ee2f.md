## 问题 / Question

35

## 答案 / Answer

1. If the robot cannot find the base station, you can try the following steps:
① Ensure the station is placed correctly and the area in front of it is clear of obstacles. Remove any if present.
② Check if the station is unplugged or has been moved. If so, plug it back in and return it to its original position.
③ Check if the robot got stuck or issued an alarm during cleaning. If so, please assist it manually.
④ Check if the floor where the station is placed is uneven. If so, place the station on a flat, level surface.
⑤ Check if the path for recharging is blocked, for example, if the door to the room with the station is closed.
⑥ If your robot is connected to Wi-Fi, check the map page in the APP to see if the station icon is displayed. If it is not displayed, the Deebot will attempt to find the station through exploration, which has a low success rate. Please manually move the Deebot back to the station to charge it, and then remap the area before using it again.

2. If the robot finds the station but cannot enter it, or enters and then automatically backs out, you can try the following steps:
① Check if there is excess water on the station base and the surrounding floor. If so, use a dry cloth to wipe the charging tray and the surrounding floor.
② Check if the roller mop is installed correctly. If not, please reinstall it.
③ Check if the station base and the washing tray on the station are installed correctly. If not, remove both and reinsta ll them.
④ Check if the charging contacts on the station are dirty. If so, clean the station contacts and confirm they spring back normally when pressed.
⑤ Check if the rod inside the station are stuck in the raised position. If so, unplug the station, plug it back in, and observe again."
