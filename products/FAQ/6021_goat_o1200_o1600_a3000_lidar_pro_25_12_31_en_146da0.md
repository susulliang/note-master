# 如何安装打草头模块？ / How to install the trimmer module?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

如何安装打草头模块？ / How to install the trimmer module?

## 答案 / Answer

A LiDAR PRO

11- 打草头安装

（1）打草头模块需要三颗螺钉，其中两颗已放入备件包中，其中一颗是内置在打草头模块中的；
（2）建议使用长度＞10cm的PH2十字螺丝刀；
（3）若比较难对准螺钉，可从打草模块地面向内观察螺丝刀的角度，以便于快速对准螺钉。
