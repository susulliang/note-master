# How to Use Mopping Function?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

How to Use Mopping Function?

## 答案 / Answer

1.Refill the clean water tank and reinstall it..
2.Remove dust collection cabin cover and pull out the cleaning solution unit.
3.Open the unit, add Ecovacs cleaning solution, close it, and reinstall..
4.Reattach the cover.                                                                                                                                                5.Turn the Robot over, install mopping pad assembly.
6.Power on the robot and press recharge button to return to charge.
6.Press "Auto" button to begin vacuuming and mopping.
