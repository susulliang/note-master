# Can the reminder about adding ECOVACS cleaning solution be disabled?

## Question

Can the reminder about adding ECOVACS cleaning solution be disabled?

## Answer

1.The user will be reminded to add ECOVACS cleaning solution when the cleaning solution is insufficient. Both the voice reminder and the App notification will be played only once. It does not affect the operation of the WINBOT W2.

2. If you want to perform a waterless cleaning, you can disable the Auto Spray function in the ECOVACS HOME App.
