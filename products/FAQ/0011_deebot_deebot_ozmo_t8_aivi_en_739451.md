# Nothing happens when I press the reset button. What should I do?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

Nothing happens when I press the reset button. What should I do?

## 答案 / Answer

D20007

Enable

Usage advice

1. Check whether there is any response when you press the button. 
2. Pressing the reset button for a short time to set up network connection, and the robot will make a "ding" sound. Pressing the reset button for a long time to reset the robot. Press and hold the button for 5 seconds before releasing it. The startup music means the robot has successfully reset.
