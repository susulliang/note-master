# APP上RTK信息中，信号覆盖地图大面积显示无信号，还可以割草吗 / Can GOAT work if there is a large area without signal shown through RTK signal quality map on the APP?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

APP上RTK信息中，信号覆盖地图大面积显示无信号，还可以割草吗 / Can GOAT work if there is a large area without signal shown through RTK signal quality map on the APP?

## 答案 / Answer

RTK Reference Station

可以割草
（1）Goat在无RTK信号的位置会用视觉传感器进行定位，保证割草效果
（2）在无信号区域会根据区域长宽，算法自行调整割草方向和割草策略。
（3）大面积最好长宽不要超过5m，超出可能定位较差。

Yes.
(1) GOAT will use visual sensor to complementary positioning when RTK signal is affected in the shaded area.  
(2) In the poor RTK signal area, the GOAT will adjust the mowing direction according to the senario which will be slightly inconsistent with the setting. 
(3) The length and width of the area without signal should not exceed 5m, too large no-signal area will make the positioning too poor.
