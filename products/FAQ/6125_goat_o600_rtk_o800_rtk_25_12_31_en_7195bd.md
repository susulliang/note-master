# 如何将GOAT恢复出厂设置？

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

如何将GOAT恢复出厂设置？

## 答案 / Answer

7- 主机其他

1.在GOAT上同时长按“开始+回充”5秒  
2.待PIN码输入页面弹出后，输入PIN码并点击OK确认，等待约30秒内存清理完成，主机将自动重启，此时重置成功。

1. Simultaneously press and hold the "Start + Return to Charge" buttons on GOAT for 5 seconds. 
 2. When the PIN code input page appears, enter the PIN code and click OK to confirm. Wait approximately 30 seconds for memory clearing to complete. The ROBOT will automatically restart, indicating a successful reset.
