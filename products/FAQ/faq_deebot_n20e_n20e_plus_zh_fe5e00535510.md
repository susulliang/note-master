# DEEBOT / N20e&N20e Plus / ZH - 机器人连接网络指导 Robot Network Connection Guide

## Question

机器人连接网络指导                                                                Robot Network Connection Guide

## Answer

下载并注册登入ECOVACS HOME App
1.将主机放在靠近充电座的地方，用手机扫描主机上的二维码下载并安装app(提示:您也可以从App Store下载ECOVACS HOME应用程序);
2.注册账号，然后登录到App主界面。
配网
1.扫描主机二维码，输入Wi-Fi密码；                                                                                                                                                       2.按照App界面提示，长按主机“启动”键开机，听到开机音乐后点击确认；                                                                                              3.同时短按定点清洁按键和回充键，在听到“进入网络设置模式”语音提示后，启动热点连接，等待网络连接。
4.连接完成后，您可以继续为DEEBOT命名。                                                                                                                                        Download and register to log in ECOVACS HOME App.                                                                                                                         1.Make sure the Robot is near the docking station. Scan the QR code to download and install the ECOVACS HOME App. You can also search it on the app market.                                                                                                                                              2.Register an account, then log in to the main interface of the app.                                                                                               Network Connection
1. Scan the QR code，input wifi code, click to enter;
2.Follow the App prompts,long press the power button until the startup music starts, confirm and click NEXT;                               3. Short press the spot cleaning button and return button at the same time. After hearing the voice prompt "Entering network setup mode", it starts the network connection;                                                                                                                            4.After it is completed, you can name the Robot.
