# How to install it handheld?

## Question

How to install it handheld?

## Answer

1. Assemble the handheld and floor brush extension rod (upper)
2. Assemble the floor brush and the floor brush extension rod (bottom)
3. Finally, assemble the floor brush extension rod (upper) and the floor brush extension rod (lower)
4. Press the handheld power button once; you can start the brush work
