# How to set virtual boundaries?

## Question

How to set virtual boundaries?

## Answer

1.Click "Map" - Select "Virtual Wall"
2.According to the requirements, you can choose use lines/rectangles to set virtual boundaries;
3.Can also select the virtual wall type, enabled in Vac&Mop, enabled in Mop-Only.;
4.While working, Robot will bypass the virtual boundary area.
