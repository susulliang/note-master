## 答案 / Answer

Disassembly, clean and installation guide of main brush

1.Long press the power button to turn off the Robot; Turn the Robot over;
2.Remove the brush cover and take out the main brush;
3.Clean the tangled material off the main brush and comb teeth;
4.Reinstall the main brush, and confirm that it can rotate smoothly.
5.Align the brush cover with the slot and install it. Make sure that you hear a "click".
