# DEEBOT / DEEBOT T30 PRO OMNI Rosé / EN - How to start spot cleaning?

## Question

How to start spot cleaning?

## Answer

1. Place the robot in the area that needs to be cleaned;
2. Manually press the        fixed-point cleaning button;
3. After the work is completed, the machine will return to the station;
