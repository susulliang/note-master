# 安装4G  Cellullar Module后盖板盖不紧？ / The cover of the 4G Cellullar Module slot cannot be closed after installing the module.

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

安装4G  Cellullar Module后盖板盖不紧？ / The cover of the 4G Cellullar Module slot cannot be closed after installing the module.

## 答案 / Answer

4G  Cellullar Module

- 如果已经理好了辅助模块的连接线，请确保没有线压在模块下面，盖上最上面的盖子的时候若盖子轻微浮起是正常现象，是因为密封条结构导致，拧紧螺丝后即可与机身贴合

If the Cellullar Module cable has been arranged, please make sure that no cable is pressed under the module,  it is normal for the top cover to float slightly when closing it, because of the sealing strip structure. After tightening the screws, it will fit into the main body.
