# DEEBOT / T30 S Combo / EN - How to deal with the disorderly cleaning route when the robot is working?

## Question

How to deal with the disorderly cleaning route when the robot is working?

## Answer

1. Allow the robot to start from the station and complete a full cleaning cycle before observation.
2. If the cleaning route remains messy, follow these steps to observe:
①Please check whether the TrueDetect 3D module is covered in dust. If there is dust, please gently wipe it with a dry tissue.
②Check if there are too many obstacles in the indoor environment. High-precision obstacle avoidance may make the route look messy. It is recommended to tidy up a bit.
③Check if the driving wheels are dirty. If so, please wipe them clean with a dry cloth.
Reminder: Do not add laundry detergent or other non-Ecovacs cleaning liquids to the water tank, as it may cause the machine to slip.
