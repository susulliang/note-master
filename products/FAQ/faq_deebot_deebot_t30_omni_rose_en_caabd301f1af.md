# How to use the YIKO voice assistant?

## Question

How to use the YIKO voice assistant?

## Answer

1、OK YIKO Voice Assistant
Open the APP-Click to enter-Click Settings-OK YIKO Voice Assistant-Enable OK YIKO function.
Note: If you turn off the OK YIKO voice assistant, the robot auto button will display an orange light constant;
2、OK YIKO voice command guidance
Settings-YIKO Voice Assistant>Click "All" to view all YIKO voice skills
①YIKO voice skills will be updated, subject to the actual content displayed on the APP.
②YIKO voice commands can only be used after being connected to the Internet. If not connected to the Internet, the machine can be woken up, but the task will not be performed.
③YIKO voice command can wake up within 5M range.
