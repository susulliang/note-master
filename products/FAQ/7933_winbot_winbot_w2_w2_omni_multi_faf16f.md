# What are the working modes of the WINBOT W2?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

What are the working modes of the WINBOT W2?

## 答案 / Answer

W00171

The W2 series have four cleaning modes:

1. Deep cleaning mode: 
The robot walks in intensive S-shaped path first, then walks along the edges. This is suitable for external windows that have not been cleaned for a long time (≥6 months) or the windows are very dirty.
* If the window is still not clean, it may be because the surface of the window is quite dirty. Please replace the wiping pad in time and continue to use this mode multiple times to achieve the best cleaning effect.

2. Fine cleaning mode: 
The robot walks in intensive S-shaped path. This is suitable for the window surface where there is less dust but there are some areas with local dirt.

3. Fast cleaning mode: 
The robot walks in sparse S-shaped path. This is suitable for internal windows that are cleaned regularly (≤3 months) or not very dirty. 

4. Edge cleaning mode: 
The robot walks along the edges of the window surface. This is suitable for situations where only the edges are dirty or have not been cleaned, and can be used for supplementary cleaning.

Tips: 
1) After connecting the WINBOT W2 to the ECOVACS HOME App, you can also use the App to control the robot cleaning.
2) The default mode of the WINBOT W2 is deep cleaning, which can be updated through the App.
