# DEEBOT / DEEBOT OZMO T8 AIVI / EN - How can I clean the hair off the roller brush? Should I use water?

## Question

How can I clean the hair off the roller brush? Should I use water?

## Answer

For floors with a large amount of hair, we recommend cleaning with the vacuum assembly, while the main brush assembly is recommended for floors with less hair. The structure of main brush has been optimized for better performance when cleaning up hair. The bristles of the main brush can be easily removed for covenient cleaning of tangled hair.
