# ¿Cómo puedo utilizar la función Gestión de mapas (Map Management)?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Cómo puedo utilizar la función Gestión de mapas (Map Management)?

## 答案 / Answer

D20432

Usage advice

La función Gestión de mapas (Map Management) no estará disponible hasta que se haya creado un mapa. 
Los mapas se guardan automáticamente al crearlos. Puede tener creados un máximo de 3 mapas permanentes y 1 mapa temporal. Puede cambiar de mapa manualmente. 
Abra la aplicación, vaya a Limpieza inteligente (Smart Cleaning) ＞ Gestión de mapas (Map Management) para realizar los ajustes correspondientes.
1. Configuración de varias plantas (Multifloor setting)
2. Creación rápida de mapas (Quick mapping)
3. Designación, eliminación, copia de seguridad y restauración de mapas (Map naming, map deletion, map backup and restore)
(1) Cuando haya creado un mapa, se hará una copia de seguridad automática del mismo. 
(2) Si edita manualmente un mapa en otro momento (como al configurar paredes virtuales) pero no realiza una copia de seguridad manual, cuando restaure el mapa se restaurará su versión original. 
(3) Si hay una copia de seguridad manual del mapa tras haberlo editado, se restaurará esa versión. 
4. Pared virtual (Virtual Wall):  toque Editar mapa (Map Edit) para establecer una pared virtual 
Nota: No defina paredes virtuales alrededor de la estación. El DEEBOT dejará de funcionar mientras se añaden paredes virtuales y volverá a funcionar cuando haya terminado el proceso. 
5. Estrategia para alfombras (Carpet strategy)
6. Tipo de área (Area Type): Editar mapa (Map Edit) ＞ Tipo de área (Area Type)
7. División de áreas (Area Division): Editar mapa (Map Edit) ＞ División de áreas (Area Division)
8. Combinación de áreas (Area Merging): Editar mapa (Map Edit) ＞ Combinación de áreas (Area Merging)
