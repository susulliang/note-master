# La estación base no suministra agua caliente al limpiar las mopas de fregado.

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

La estación base no suministra agua caliente al limpiar las mopas de fregado.

## 答案 / Answer

D20417

Station

Nota: Cada vez que se inicia una tarea de limpieza, las mopas de fregado se humedecen con agua fría y, a continuación, se limpian con agua caliente. 

1. Asegúrese de que el robot está conectado a la aplicación ECOVACS HOME. 
2. Abra la aplicación y vaya a Limpieza inteligente (Smart Cleaning) ＞ Estación (Station). Seleccione el lavado en agua caliente (hote water washing) o el lavado intensivo (deep washing). Si selecciona el programa de lavado de bajo consumo (energy-saving washing), no se suministrará agua caliente para la limpieza de las mopas.

Nota: 
(1) El proceso de calentamiento del agua limpia es dinámico, y la temperatura será algo menor durante la fase inicial del proceso de limpieza. 
(2) Si la temperatura del agua es demasiado elevada, la función se desactivará temporalmente para evitar lesiones.
