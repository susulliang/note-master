# À quoi sert la commande manuelle dans l'application ECOVACS HOME ?

## Question

À quoi sert la commande manuelle dans l'application ECOVACS HOME ?

## Answer

1. Dans les situations où l'appareil rencontre de nombreux obstacles, le nettoyage via la commande manuelle dans l'application ECOVACS HOME permet d'éviter ces obstacles et de nettoyer plus efficacement.
2. Lorsque le WINBOT W2 rencontre des obstacles et reste coincé, vous pouvez utiliser la commande manuelle dans l'application ECOVACS HOME pour nettoyer ou diriger le robot vers un endroit facile d'accès afin de le récupérer.
