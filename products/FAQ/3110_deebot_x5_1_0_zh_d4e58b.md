# Comment connecter le robot DEEBOT à Internet ? / 1. Avant de se connecter
1.1 Scanner le code QR sur le robot et télécharger l'application ECOVACS HOME (activer la localisation, le réseau local et les autres autorisations requises lors de l'installation de l'application).
1.2 S'assurer que les signaux sans fil 2,4 GHz sont activés sur votre routeur. 1.3 S'assurer que votre téléphone est connecté à votre réseau Wi-Fi domestique et que vous pouvez accéder à Internet normalement via n'importe quel navigateur. 1.4 S'assurer que Bluetooth est activé sur votre téléphone. Remarque : Si votre routeur est configuré pour envoyer deux signaux Wi-Fi, configurez votre téléphone pour qu'il ignore les signaux de point d'accès Wi-Fi de 5 GHz.
Vous ne pouvez pas configurer votre routeur pour qu'il masque les signaux Wi-Fi.
Actuellement, DEEBOT ne prend pas en charge les VPN, les serveurs proxy ou les réseaux authentifiés via une page Web.
Assurez-vous que le filtrage des adresses MAC est désactivé sur votre routeur. Une fois connecté, vous pouvez trouver votre adresse MAC en ouvrant l'application et en accédant à Paramètres ＞ Détails du robot. 2. Connexion du robot DEEBOT
2.1 Suivre les invites de l'application et appuyer sur Ajouter un robot. La méthode de connexion par défaut du robot DEEBOT consiste à scanner le code QR sur le robot, mais il est également possible de le connecter manuellement (rechercher le modèle ou le nom du robot DEEBOT, puis sélectionner le nom du produit sous la série appropriée).
2.2 Avant de se connecter
① Mettre en marche l'interrupteur d'alimentation du DEEBOT. Une fois l'invite de mise sous tension terminée, sélectionner « J'ai allumé le robot » (le voyant Wi-Fi du robot doit clignoter), puis appuyer sur Suivant.
② Maintenir le bouton RESET enfoncé pendant 1 seconde avant de le relâcher. Lorsque vous entendez « Point d'accès Bluetooth activé », appuyer sur Suivant pour rechercher DEEBOT. La recherche doit trouver (ECOVACS-XXXX-XXXX). Appuyer pour coupler. Le message « Connexion réussie » s'affiche une fois le couplage réussi.
2.3 Connecter le DEEBOT
③ Une fois le couplage Bluetooth réussi, sélectionner la connexion Wi-Fi domestique, saisir le mot de passe Wi-Fi, puis appuyer sur Suivant pour commencer la connexion.
