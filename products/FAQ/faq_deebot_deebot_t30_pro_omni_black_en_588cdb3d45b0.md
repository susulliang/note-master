# The machine didn't start the scheduled cleaning task，why？

## Question

The machine didn't start the scheduled cleaning task，why？

## Answer

1. Check whether the machine is turned on; if not, please turn the machine on;
2. Check whether the Do Not Disturb mode is turned on and within the Do Not Disturb time period. If so, it cannot be activated;
3. Open the APP to check the current battery of the robot. If the battery is insufficient, the scheduled task will not be performed. Please ensure that the battery is sufficient before use;
4. When setting the sechdule task in the APP, it may not be set or saved correctly. Please reset the schedule task before using it;
5. If the above methods are invalid, please contact after-sales service.
