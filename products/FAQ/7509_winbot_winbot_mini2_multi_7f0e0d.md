# Alerta: Presión de aire insuficiente.
 ¿Cómo solucionarlo?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Alerta: Presión de aire insuficiente.
 ¿Cómo solucionarlo?

## 答案 / Answer

Recordatorio:
 Si la presión de aire es baja durante el uso, compruebe primero la ventana. Los huecos o los obstáculos bajos en el cristal pueden provocar pérdidas de presión. Para estas zonas, utilice el mando a distancia manual a través de la aplicación.
 Si no se trata de un problema ambiental, pruebe estos pasos:
 1. Utilice la aplicación para controlar a distancia el WINBOT hasta una posición accesible.
 2. Sujete el asa y mantenga pulsado el botón de inicio durante 2 segundos. Realice la retirada de WINBOT una vez que el ventilador se detenga.
 3. Asegúrese de que el Paño de limpieza esté alineado con los bordes anchos y estrechos y que esté bien fijado.
 4. Confirme que no haya anomalías y, a continuación, mantenga pulsado el botón de inicio para reiniciar el ventilador. El WINBOT volverá a funcionar una vez que se adhiera correctamente.
