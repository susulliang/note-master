# 机器人未按预约时间自动执行清洁工作? / What to do if DEEBOT doesn’t start cleaning as scheduled

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

机器人未按预约时间自动执行清洁工作? / What to do if DEEBOT doesn’t start cleaning as scheduled

## 答案 / Answer

1.确认地宝处于开机状态;
2.进入APP，确认地宝电池电量充足;
3.确认该任务不在勿扰时间段内;                                                                                                    4.确认在预约时间到时，地宝是否正在执行其他任务；
5.APP设置中检查预约任务，确认正确设置或者保存。

1.Ensure DEEBOT is powered on.
2.In the app, check that the battery is sufficiently charged.
3.Confirm the schedule is not within ‘Do Not Disturb’ time.
4.Ensure DEEBOT is not busy with other tasks.
5.Verify the schedule is set and saved correctly in the app.
