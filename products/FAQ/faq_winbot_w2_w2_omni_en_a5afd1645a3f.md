# WINBOT / W2/W2 OMNI / EN - WINBOT W2 failed to pair with the ECOVACS HOME App via Bluetooth.

## Question

WINBOT W2 failed to pair with the ECOVACS HOME App via Bluetooth.

## Answer

WINBOT W2 failed to pair with the ECOVACS HOME App via Bluetooth.

1. Please make sure the ECOVACS HOME App has been updated to the latest version.
2. Restart the WINBOT W2.
3. Enable the Bluetooth function again of your smart phone.
4. Please do Bluetooth pairing with the WINBOT W2 in the ECOVACS HOME App interface, please do not pair the Bluetooth with the WINBOT W2 in your smart phone setting interface.
5. If the WINBOT W2 has been connected to other smart phone, please log out the App first and then try again.

Note: When pairing via Bluetooth, please keep the WINBOT W2 close to the phone and away from the Wi-Fi router. If none of the above can solve your problem, please contact ECOVACS support.
