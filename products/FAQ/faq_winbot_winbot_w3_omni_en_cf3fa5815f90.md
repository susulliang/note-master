# WINBOT / WINBOT W3 OMNI / EN - How to Use the "Heavy‑duty Cleaning Mode"

## Question

How to Use the "Heavy‑duty Cleaning Mode"

## Answer

Reminder: For large and heavily soiled windows, you can use Heavy‑duty Cleaning to significantly reduce cleaning time and avoid inefficiency.
1.Press and hold the Start button on Winbot to turn it on, then attach the robot to the glass.
2.In the Ecovacs Home App, select Heavy‑duty Cleaning and set the cleaning duration (5 min / 10 min).
3.Based on the set duration, Winbot will pause cleaning, return to its starting point, and prompt you to replace the wiping pad. After replacing the pad, reattach Winbot to continue cleaning. This divides a large window into several sections from top to bottom for segmented cleaning.
4.After all sections are cleaned, the Heavy‑duty Cleaning task is not yet finished. Winbot will again prompt you to replace the wiping pad, then proceed with the final pass—wiping the entire glass once completely to ensure a thorough clean.
