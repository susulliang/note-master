# Je ne sais pas combien de balises de navigation utiliser pour mon jardin ni où les placer.

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Je ne sais pas combien de balises de navigation utiliser pour mon jardin ni où les placer.

## 答案 / Answer

G00021

Disable

Navigation Beacon

Scanner le code QR (ou utiliser l'adresse Web fournie), dessiner un bref plan de votre jardin dans le widget et l'algorithme générera automatiquement le nombre de balises et les points de positionnement pour vous. En cas de doute, il est recommandé de contacter le service après-vente pour obtenir une explication plus détaillée de la solution.
