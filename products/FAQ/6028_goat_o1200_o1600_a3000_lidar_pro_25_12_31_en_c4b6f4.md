# 使用沿边打草时GOAT出现了较多的卡困？ / Did GOAT get stuck more when using edge trimming?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

使用沿边打草时GOAT出现了较多的卡困？ / Did GOAT get stuck more when using edge trimming?

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

12- 打草

（1）当边界出现较多障碍物时可能对GOAT视觉识别带来一定的干扰，建议使用沿边打草时先对边界障碍物进行清理；
（2）若边界上有台阶，高度在5-7cm范围内，打草模块在打草时容易产生摩擦卡困，不建议在这个类型的边界上设置打草边界；
（3）为了可以更好的打草效果，GOAT会尽可能的靠近边界打草，容易在转弯处与边界上的障碍物产生碰擦，建议建图时可以在拐弯处稍向内建图。
