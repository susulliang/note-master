# 建图时RTK基站未添加是什么原因 / Why the APP shows that the RTK Reference Station is not added during maping?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

建图时RTK基站未添加是什么原因 / Why the APP shows that the RTK Reference Station is not added during maping?

## 答案 / Answer

RTK Reference Station

（1）确认RTK基站是否已成功上电，上电成功RTK基站将会蓝灯亮起.
（2）确认RTK基站上电后，扫码配对RTK。
 *若始终无法解决请联系科沃斯售后服务部门

(1) Confirm whether the RTK Reference Station has been successfully powered on, and the indicator will steady light if the RTK Reference Station is successfully powered on and the signal is good.
(2) If the RTK Reference Station is powered on and the signal is good, scan the code to match the RTK.
* If it cannot be resolved, please contact Ecovacs after-sales Service
