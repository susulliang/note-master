# DEEBOT / T30 S / EN - How to deal with map confusion/overlapping caused by robots?

## Question

How to deal with map confusion/overlapping caused by robots?

## Answer

1: About the robot's appearance of map confusion/overlapping/crooked images
When the map has been created, if there is confusion/overlapping/crooked map or inconsistency with the originally created map during use, you can try to restore the map.
1. Make relevant settings in the app main page - Map Management.
2. If the map recovery is invalid, it is recommended that you can use Quick Mapping to rebuild the map after deleting it.
Note: ① Restoring a map can only restore the last map you saved.
After the map is successfully restored, the reservation and some map settings will be lost, and the 3D map will also be updated synchronously.
