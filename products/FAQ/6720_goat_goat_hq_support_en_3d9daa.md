# Quel est le mode permettant de basculer entre le Wi-Fi et le module de connexion automatique ?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Quel est le mode permettant de basculer entre le Wi-Fi et le module de connexion automatique ?

## 答案 / Answer

G00143

Disable

Additional Connection Module

Le Wi-Fi est automatiquement utilisé lorsqu'il y a un bon signal. Le signal du module est utilisé lorsque le signal Wi-Fi est faible.
