# DEEBOT / T30 S Combo / EN - How to disassemble/clean/install the main brush correctly?

## Question

How to disassemble/clean/install the main brush correctly?

## Answer

1. Press and hold the AUTO button to power off the robot. Turn the robot upside down, with the bottom facing upwards.
2. Remove the main brush cover and then take out the main brush assembly;
3. Clean any debris or entanglements from the main brush.
4. After re-installing the main brush, manually rotate it to ensure smooth rotation.
5.  Align the side brush with the slot and firmly press it down.Once you hear a 'click,' it indicates that the installation is complete.
