# DEEBOT returns to the  docking station for charging before it has finished cleaning.

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

DEEBOT returns to the  docking station for charging before it has finished cleaning.

## 答案 / Answer

D20237

Cleaning

(1) If the room is large and cannot be cleaned in one go, it is necessary to return to the charging dock halfway through. We recommend that you enable the Continuous Cleaning function in the App. See the guidance in the App for specific steps. 
(2) If the home environment is particularly complex, cleaning efficiency will be reduced and it may not finish cleaning. 
(3) The room door will be recognaized as an obstacle in the map if it's closed during mapping. It wil be reported as a block when cleaning triggered. After another AUTO Cleaning cycle and map update, it will work normally.
