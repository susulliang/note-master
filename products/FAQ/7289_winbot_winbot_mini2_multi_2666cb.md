# 如何安装及使用窗宝？

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

如何安装及使用窗宝？

## 答案 / Answer

使用前准备：
1. 开箱后取出主机、配件（适配器、抹布、清洁液）及说明书，使用前请务必阅读说明书中的注意事项。
2. 打湿擦窗布：清洁前，建议手动将擦窗布打湿并尽量拧干至不滴水状态。
3. 粘贴擦窗布：按宽窄边方向，将擦窗布粘贴于底部擦窗布支架的魔术贴上，用手按压抹平确保粘贴牢固。
4. 注入清洁液：打开主机水箱橡皮塞，加入科沃斯窗宝专用清洁液或清水（最大容量50ml），盖紧橡皮塞。
   温馨提示：
 * 请勿使清洁液溢出水箱。
 * 禁止注入纯净水或过滤水。
 * 建议搭配本公司专用清洁液使用，非专用清洁液可能影响清洁效果或损坏产品。
 * 若清洁液用尽，可临时用自来水替代，但专用清洁液效果更佳。
5. 固定安全锁扣：将安全绳系在稳固不易移动的物体上（如金属栏杆、桌腿等），并锁好安全锁扣。
6. 连接电源：将机身电源线与适配器连接，插头插入电源插座。
 
窗宝使用：
 温馨提示：
 * 请充满电后使用，开机后机身背面蓝色指示灯常亮表示满电，充电时间约3小时。
 * 清洁无框玻璃时，吸附位置需距离边缘10cm以上。
 * 请勿将窗宝放置在窗户把手附近启动。
 * 仅适用于纯平表面，玻璃厚度不低于3mm。
 * 开机后请勿将风机靠近头发等细小物体，以免堵塞。
 * 清洁前请检查吸附位置，若有细小颗粒需先清除或更换位置，避免划伤玻璃。
 * 清洁前请擦干喷水口处的水滴。
1. 长按启动键2秒，听到风机启动后，将窗宝底部（带抹布一面）贴于玻璃，即可自动吸附并开始清洁。
2. 如需暂停，短按电源键或通过APP点击暂停，窗宝将暂停并静止。再次短按电源键或APP启动键，可继续完成剩余清洁任务。
3. 清洁完成后，窗宝自动返回原点并发出提示音。取下时，请紧握手柄，长按电源键2秒以上，按语音提示操作。
4. 使用完毕后，倒出剩余清洁液，取下擦窗布，断开电源，解开安全锁扣，将主机及配件整理收纳。
