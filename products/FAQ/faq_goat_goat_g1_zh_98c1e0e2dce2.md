# Can I use the automatic mapping function if there is a road in my garden?

## Question

Can I use the automatic mapping function if there is a road in my garden?

## Answer

It depends on the height difference between the road surface and the surrounding area. If the road surface is flat and has no height difference with the surrounding area and the width is less than 15cm, the automatic mapping function can be used; if the height difference between the road surface and the surrounding area is greater than 3cm, the automatic mapping function cannot be used.
