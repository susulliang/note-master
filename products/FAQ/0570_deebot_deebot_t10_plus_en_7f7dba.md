# I already have a map. Can I use quick mapping to save multiple maps?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

I already have a map. Can I use quick mapping to save multiple maps?

## 答案 / Answer

D20272+

Intelligence

Storage of multiple maps for the same environment is not currently supported in the App. If a map already exists in the same environment and another quick mapping is done, the original map will be replaced. 
In addition, frequent use of the quick mapping command is not recommended unless you need to map a new environment.
