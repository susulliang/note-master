# Comment utiliser le bouton de réinitialisation ?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Comment utiliser le bouton de réinitialisation ?

## 答案 / Answer

Conseil : 
 Si le WINBOT se bloque, utilisez le bouton de réinitialisation pour le réinitialiser. Suivez ces étapes :
 
 . En mode veille, retournez le WINBOT et repérez le petit trou « Reset » (Réinitialisation).
 2. À l'aide d'un outil pointu, tel qu'un cure-dent, appuyez sur le bouton de réinitialisation et maintenez-le enfoncé. Relâchez-le une fois que le voyant s'éteint.
 3. Éteignez puis rallumez le WINBOT pour terminer la réinitialisation.
