# 我应该在什么场景下使用强劲割草？ / In what scenarios should I use Enhanced  mowing

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我应该在什么场景下使用强劲割草？ / In what scenarios should I use Enhanced  mowing

## 答案 / Answer

Mowing

（1）当草坪长期未修剪，草坪草高超过10cm，低于20cm时，可使用强劲割草模式进行割草。
（2）使用强劲割草模式时，因为GOAT避障传感器可能被遮挡，请整理草坪上＜20cm的物品，避免GOAT碰撞。
（3）使用强劲割草模式时，因为GOAT避障传感器可能被遮挡，危险边界请设置物理围挡。

(1) When the lawn has not been mowed for a long time and the grass height exceeds 10cm and below 20cm, the enhanced mowing mode can be used for mowing.
(2) When using the enhanced mowing mode, please tidy up items＜20cm on the lawn to avoid GOAT collisions as the GOAT obstacle avoidance sensor may be obstructed.
(3) When using the strong mowing mode, please set physical barriers at the dangerous boundary as the GOAT obstacle avoidance sensor may be obstructed.
