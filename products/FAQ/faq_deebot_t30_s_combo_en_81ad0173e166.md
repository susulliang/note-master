# DEEBOT / T30 S Combo / EN - When the robot has a mopping pad plate that rotates or does not rotate, or the mopping pad plate does not rotate, how to deal with it?

## Question

When the robot has a mopping pad plate that rotates or does not rotate, or the mopping pad plate does not rotate, how to deal with it?

## Answer

1: The robot rotates when the mopping pad plate appears, or the mopping pad plate does not rotate
Please confirm the cleaning mode currently used by the machine
Open ECOVACS HOME app > Go to Robot Control > Swipe up page > View cleaning mode
If the cleaning mode is in the sweeping state, the machine will not rotate during the cleaning process when the rag bracket is in the raised state.
If the cleaning is in the mopping state, during the cleaning process, the machine will automatically lift and not rotate when encountering the carpet due to its Self-Adaptation carpet function. If it is not on the carpet and the rag bracket does not rotate or rotates from time to time, check if there are any entanglements on the rag bracket. If so, please disassemble and clean it before reinstalling.
③ If the cleaning is in the state of sweeping and mopping at the same time, the machine will automatically lift and not rotate when encountering the carpet during the cleaning process due to its Self-Adaptation carpet function. If it is not on the carpet and the rag bracket does not rotate or rotates from time to time, check whether there are any entanglements on the rag bracket. If so, please disassemble and clean it and reinstall it.
④ If the cleaning is in the state of sweeping first and then mopping, the machine will perform two cleaning operations. The first time, the rag bracket will not rotate when it is in the raised state. After the first cleaning is completed, the second cleaning will be performed. Due to the Self-Adaptation carpet function, it will automatically lift and not rotate when encountering a carpet. If it is not on the carpet and the rag bracket does not rotate or rotates from time to time, check whether there are entanglements on the rag bracket. If so, please disassemble and clean it before reinstalling it.
Note: When the machine returns to the station for charging, the entire cloth tray is in a raised state
Second, the rag holder rotates and does not rotate; how to deal with it?
1. Flip the main unit and check whether there is any foreign object entangled on the rag holder. If there is, please clean it up and observe it.
2. If there is no entanglement on the rag bracket after inspection, switch the position of the rag tray left and right and use it for observation; if it still does not turn, please contact the after-sales service of Ecovacs for processing
