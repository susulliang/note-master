# The base station or cleaning station cannot control the robot (DEEBOT is disconnected with the base station)

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

The base station or cleaning station cannot control the robot (DEEBOT is disconnected with the base station)

## 答案 / Answer

The base station or cleaning station cannot control the robot (DEEBOT is disconnected with the base station)

1. Update the firmware to the version 1.8.9, allowing users to place the base station as close as possible to the router at home.
2. If the firmware has just been upgraded or the robot has been shut down and restarted, the robot needs time to respond, and it will appear a disconnection prompt. Please wait for 3 minutes before using it.
3. Confirm whether the distance between the robot and the base station is too far. If the distance is exceeded, please use the APP to operate.
3. If the robot is near the base station, it does not respond to the base station command / APP prompts "the robot has been disconnected with the base station", turn off the power switch and restart it, wait for 3-5 minutes, then open the APP.
①In the app, get into "Settings", then check whether the base station and DEEBOT are connected in the "Base Station Information".
②If it shows that they are not connected, please re-pair the robot and the base station. The operation steps are as follows:
1) Disconnect the base station from the power supply, remove the top cover of DEEBOT, turn the DEEBOT red power switch to "O" and wait for 5 to 10 seconds.
2) Reconnect the base station power supply and confirm that the base station panel light is on.
3) Turn on the power switch of the robot again (move to "I"), and confirm that you hear the power-on prompt tone.
4) Press and hold the Auto start button on the robot to make it automatically return to the base station (or manually push the tail of it into the cleaning tank of the base station) to ensure that the charging contacts are properly docked. The Auto button of the robot will flash white light after successfully docked.
After waiting for about 10-15 seconds, click the "Start/Pause" button of the base station to control the robot.
