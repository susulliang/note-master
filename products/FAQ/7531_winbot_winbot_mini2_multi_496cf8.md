# Guide de connexion de l'application

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Guide de connexion de l'application

## 答案 / Answer

1. Branchez le câble d'alimentation à l'adaptateur et branchez-le, puis attendez que le message vocal de démarrage se termine.
 2. Scannez le code QR sur le WINBOT ou recherchez « ECOVACS HOME » dans l'App Store pour télécharger et installer l'application. Terminez l'enregistrement et accédez à l'interface principale.
 3. Sur la page d'accueil de l'application, cliquez sur « Ajouter un robot », scannez le code QR sur le WINBOT et suivez les instructions de l'application pour terminer la connexion.
