# Can the GOAT still be used as normal if the signal rod on the upper part of the navigation beacon is removed and not reinstalled in the original order?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Can the GOAT still be used as normal if the signal rod on the upper part of the navigation beacon is removed and not reinstalled in the original order?

## 答案 / Answer

G00033

Disable

Navigation Beacon

To ensure safety, the GOAT automatically stops working when it detects that a navigation beacon's position is inconsistent to that on the map. For the GOAT to resume normal operation, the navigation beacon needs to be placed according to its position when the map was first created. It is recommended to label the signal rod and the support rod of each navigation beacon before removal. This will help you find the correct position in future. If you have not labeled it, you can check the position of the navigation beacon and its corresponding pairing code in the app. If you are not able to put it back in its original position, a new map needs to be created.
