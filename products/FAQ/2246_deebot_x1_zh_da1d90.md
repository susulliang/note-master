# The robot cannot be connected to the Internet.

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

The robot cannot be connected to the Internet.

## 答案 / Answer

The robot cannot be connected to the Internet.

17. The robot cannot be connected to the Internet.
Users fail to setup the network
1: Failed to setup the network/unable to connect Internet/app cannot access the Internet
1. Check software download and phone settings.
①Scan the QR code on the robot to download the latest version of the App, and ensure that the positioning permission of the APP is enabled in the phone settings (including GPS\GPRS permission)
   IOS 14.1 and above, please open the phone settings - ECOVACSHOME - local network permissions, click the location again - confirm that "the accurate location" is open
② Temporarily turn off the 4G/5G mobile data service of the mobile phone, ensure that the mobile phone is connected to the Wi-Fi at home, and open other applications or browsers on the mobile phone to check whether it can access the Internet normally.
③If you have installed antivirus or wall climbing software on your phone, please close it first.
2. Check the router settings
① Wi-Fi name and password are recommended to be set to English or numbers, avoiding special symbols and Chinese characters.
②If you use a dual-band router at home, you should pay attention to the following two points:
    a. If the router has been set to ""dual-band preferred" or ""dual-band in one" (only one WIFI signal), you can directly setup the network.  b. If the router is set to send out two Wi-Fi signals, please temporarily ignore Wi-Fi signals in the 5G band in your phone wireless network list
③ During the network setup or after the network setup is completed, the router settings cannot hide the Wi-Fi signal.
3. Note points in the network setup
①According to the App prompt, complete the network setup step by step.
(Note: When inputting the Wi-Fi password, ensure it matches your home WIFI password. If there are letters, pay attention to the size to avoid spaces.)
②If you use other ways to setup the network, please pay attention to the following tips:
    Tip 1: In the "Connect Robot" "Wi-Fi" step, after Android phones are connected to "ECOVACS-XXXX" "Wi-Fi", the phone screen pops up a "WLAN cannot access the Internet", depending on the mobile phone prompts for the following situations, ensure that the mobile phone maintains a wireless connection with DEEBOT:
   a. When your mobile phone prompts whether to switch other networks, please select "Do not switch" b. Whether to allow switching to other better networks, please select "Not allowed" c. Whether to continue to use this network, please select "Use".
     Tip 2: "Return to the APP interface and wait for the network setup result", when you hear the voice prompt "DEEBOT is connected to your mobile phone", check whether the current network is your home Wi-Fi. If not, you must manually switch the network in the wireless LAN list, and return to the APP immediately to wait for the network setup result.
(Note: The robot network setup currently does not support VPN or proxy servers, and does not support networks that pass web page authentication and authentication.)
4. If the above methods do not work, you can try to use the hotspot to setup the network.
   ①Prepare two mobile phones, one of which has correctly downloaded the latest version of the app and enabled the positioning permission, and the other mobile phone has opened the mobile data as the shared hotspot and the home Wi-Fi used for the network setup. According to the APP prompt, complete the network step by step.
 ② If the hotspot can make the network setup successfully, please open the App-Settings-DEEBOT Information-Wi-Fi Management-"+" to manually add a wireless network.
