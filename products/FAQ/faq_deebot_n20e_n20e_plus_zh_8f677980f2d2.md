# DEEBOT / N20e&N20e Plus / ZH - 如何安装机器人？ How to correctly install the robot?

## Question

如何安装机器人？                                                                   How to correctly install the robot?

## Answer

1.请移除主机防撞保护条。
2.请将主机翻转后，底部朝上放置。
3.请取出边刷，对准卡槽后往下按，听到“嗒”一声表示安装到位。
4.请取出充电座并移除充电座上的保护膜。
5.请取出2个软胶塞并移除胶膜。
5.请将带胶端对准充电座背面上方椭圆形孔装好，以便于固定充电座，寻找合适位置靠墙摆放。                                                                    1.
