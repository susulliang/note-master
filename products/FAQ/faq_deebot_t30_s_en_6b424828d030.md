# How to deal with the robot not performing intelligent breakpoint continuation scanning?

## Question

How to deal with the robot not performing intelligent breakpoint continuation scanning?

## Answer

1: The robot does not perform intelligent breakpoint resume scanning
1. Confirm whether the smart breakpoint resume switch is turned on.
2. During the Do Not Disturb Mode, the intelligent breakpoint continues to scan without triggering.
3. Whether the machine automatically returns to charge and triggers a fault alarm, if a fault alarm occurs, the breakpoint resume cannot be triggered.
4. After triggering the intelligent breakpoint resume, the machine switch cannot be restarted or restored to factory settings.
Note: The breakpoint resume function is only available in automatic mode.
