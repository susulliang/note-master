# After double-clicking the station button, the handheld vacuum cleaner cannot perform automatic dust collection. How to deal with it?

## Question

After double-clicking the station button, the handheld vacuum cleaner cannot perform automatic dust collection. How to deal with it?

## Answer

1. Open the dust collection compartment cover and check if there is a dust bag installed. If not, please install it correctly.
2. If there is a dust bag, please remove it and reinstall it
3. Ensure that the dust bag is installed correctly and the dust bin cover is closed in place.
4. Double-click the station button again and observe.
