# Network requirements for DEEBOT to connect to the ECOVACS HOME App

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

Network requirements for DEEBOT to connect to the ECOVACS HOME App

## 答案 / Answer

1) Temporarily turn off the 4G or 5G mobile data services on your smart phone to ensure that it is connected to your home Wi-Fi network. 
2) If your home Wi-Fi router supports dual band (2.4GHz and 5GHz), and “Band steering” or "dual band in one", please activate it so that the two networks (2.4GHz+5GHz) will integrate into one network name. If your home Wi-Fi router is a dual band router, set your phone to temporarily ignore the 5G band Wi-Fi hotspot signal. 
3) During and after network configuration, the router settings cannot hide Wi-Fi signals. 
4) Network configuration for the robot does not currently support VPN or proxy servers. It also does not support networks that need web page authentication and certification. 
5) If the router is set to MAC address filtering, please disable this setting first. After successful network configuration, check the MAC address of the robot under “DEEBOT Information Center — Network Information” in the App, and set filtering after adding it manually.
