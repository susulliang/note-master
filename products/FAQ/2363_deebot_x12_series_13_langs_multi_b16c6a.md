# 12

> **产品线**：DEEBOT　**语言**：multi
>

## 问题 / Question

12

## 答案 / Answer

Lorsque le robot affiche le message « Niveau de liquide de nettoyage bas », vous pouvez suivre les étapes suivantes :
Solution de nettoyage désinfectante
 1. Retirez le couvercle des réservoirs de solution de nettoyage, sortez le réservoir de solution de nettoyage désinfectante, remplissez-le de solution de nettoyage ECOVACS, puis refermez le couvercle et placez-le dans la station.
 2. Dans l'application, allez dans Maintenance ＞ Solution de nettoyage désinfectante ＞ J'ai ajouté.
 
 Solution de nettoyage puissante
 1. Retirez le couvercle des réservoirs de solution de nettoyage, sortez le réservoir de solution de nettoyage puissante, remplissez-le de solution de nettoyage puissante ECOVACS, puis refermez le couvercle et placez-le dans la station.
 Dans l'application, allez dans Maintenance ＞ Solution de nettoyage puissante ＞ J'ai ajouté.
