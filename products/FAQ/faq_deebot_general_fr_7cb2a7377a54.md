# Comment configurer le nettoyage dans le sens du sol ?

## Question

Comment configurer le nettoyage dans le sens du sol ?

## Answer

1. Cliquer sur Paramètres, Paramètres avancés du DEEBOT, puis sur Nettoyer dans le sens du sol pour activer ou désactiver ce mode.
2. Sélectionner la zone pour définir le type de sol. Ensuite, sélectionner Bois et cliquer sur l'icône d'angle droit de 90° pour régler l'affichage du grain du bois dans le sens horizontal ou vertical.
