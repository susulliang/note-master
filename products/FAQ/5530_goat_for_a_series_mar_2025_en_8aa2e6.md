# 计划表-使用计划表割草时如果到了结束时间草未割完或者未到结束时间已完成割草怎么办？ / When using the schedule task function, what should I do if the grass has not been completely mowed by the end time, or the grass has been completely mowed before the end time is up?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

计划表-使用计划表割草时如果到了结束时间草未割完或者未到结束时间已完成割草怎么办？ / When using the schedule task function, what should I do if the grass has not been completely mowed by the end time, or the grass has been completely mowed before the end time is up?

## 答案 / Answer

Mowing

计划表任务为每周循环任务，计划表割草时到了结束时间，任务自动结束。 
未到结束时间已完成割草，则当次任务结束，等待下一个任务。

（1）Scheduled is weekly recurring. When the scheduled mowing time reaches the end of week, the task automatically ends. 
（2）If a round of mowing is completed before the end time, the GOAT will start mowing again until the scheduled end time.
