# GOAT的切割效率应该如何选择? / How can I select the mowing efficiency for the GOAT?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

GOAT的切割效率应该如何选择? / How can I select the mowing efficiency for the GOAT?

## 答案 / Answer

4- 割草

该型号仅支持一个切割效率：精修模式
该模式下，机器行走速度较低，可以有更好的切割效果和精度。

This model supports only one cutting efficiency:  Precision
The GOAT running speed is the most suitable which can have better cutting effect and accuracy.
