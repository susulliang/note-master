# YIKO音声アシスタントが機能しない、または「OK YIKO」のウェイクアップの反応が遅れる。 / 1. DEEBOTがECOVACS HOMEアプリに接続され、アプリでYIKO音声アシスタントが有効になっていることを確認します。
2. DEEBOTに「OK YIKO」と言う際に、YIKOが認識できるように標準的に発声してください。アプリの音声アシスタントガイダンスに従ってください。
3. 雑音が多すぎる場合や、DEEBOTが遠く離れている場合、YIKOが音声コマンドを認識できない場合があります。
4. ご自宅のWiFi信号が良好であること、ECOVACS HOMEアプリとDEEBOTファームウェアのバージョンが両方とも最新であることを確認してください。

注：ビデオ音声通話中は、YIKO音声アシスタントは機能しません。
問題が解決しない場合は、DEEBOTをリセットして再試行してください。
