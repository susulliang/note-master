# WINBOT does not spray water. How to deal with it?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

WINBOT does not spray water. How to deal with it?

## 答案 / Answer

Important Tips:
 WINBOT does not spray water in the following scenarios:
 1. During Edge cleaning.
 2. Cleaning windows with width ＜ 50cm (N-shaped path).
 3. Returning to the start point.
 4. During remote control (Manual spray is available).
 5. When the "Auto-spraying" function is turned off in the App.
 
 If WINBOT still fails to spray water after excluding the above scenarios, please try the following:
 1. Check if there is liquid in the water tank. If the voice prompt says "Low water level," please refill it in time.
 2. Wipe the spray nozzles with a clean, damp cloth to prevent blockage by foreign objects.
 3. Open the ECOVACS HOME App, go to ”Settings“, and confirm that the "Auto-spraying" function is turned on.
 4. If the problem persists, go to the “check solution” page and tap the "Spraying from the Front/Rear Nozzles" to observe the spraying status.
