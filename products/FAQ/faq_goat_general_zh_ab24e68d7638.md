# GOAT 未割草完毕返回基站

## Question

GOAT 未割草完毕返回基站

## Answer

(1) The map is too large and cannot be covered in a single mowing cycle, so the robot needs to return and recharge. It will continue with the unfinished task when its battery level is sufficient.
(2)It may trigger a return when it gets dark, a return during animal protection hours, a return when it rains, etc., which causes the machine to need to pause midway and return to the base station first;
(3) Please check the App and the notifications to see if there are any errors or faults with the GOAT.
