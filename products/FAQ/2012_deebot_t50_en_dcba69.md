## 问题 / Question

How to correctly install the robot? / How to correctly install the robot? / Wie wird der Roboter ordnungsgemäß installiert? / Comment installer correctement le robot ? / Come si installa correttamente il robot? / ロボットの正しい設置方法を教えてください。 / 로봇은 어떻게 올바르게 설치합니까?

## 答案 / Answer

ロボットの正しい設置方法を教えてください。

1.梱包箱を開けてロボットを取り出し、ステーションに付いているテープや衝突防止保護ストリップなどを取り除きます。
2.ロボットを裏返します。
3.サイドブラシを取り出し、スロットに合わせて、押し下げます。正しく取り付けられると、カチッという音がします。
4.ベースを取り付け、両側を押します。正しい場所に取り付けられると、カチッという音がします。
5.電源コードを取り出し、背面の電源ソケットに接続します。電源を入れて、壁際の適切な場所に配置します
（ロボットは、平らで硬い床に設置して、左右5cm、前方80cm以内に物を置かないようにしてください）。
注意：
ロボットはセラミックタイルの床に置くことを推奨します。板張りの床に置く必要がある場合は、ロボットの底部に水滴が付いていないか定期的に確認してください。水滴がある場合は、湿気による損傷を防ぐために速やかに拭き取ってください。
