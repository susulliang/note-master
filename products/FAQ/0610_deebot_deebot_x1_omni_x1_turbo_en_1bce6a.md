# How to set the child lock on the docking station?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

How to set the child lock on the docking station?

## 答案 / Answer

D20256

Station

(1) The child lock is activated by simultaneously pressing both the left and right buttons of the docking station for 3 seconds. The same operation is used to unlock it. 
(2) You can activate and deactivate the child lock on the App's setting about station.
