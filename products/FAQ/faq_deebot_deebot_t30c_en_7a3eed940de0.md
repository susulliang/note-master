# DEEBOT / DEEBOT T30C / EN - How to use spot cleaning?

## Question

How to use spot cleaning?

## Answer

1. Manually move the robot to the area to be cleaned;
2. Press the spot cleaning button on the cover;
3. When the work is completed, the machine will return to the OMNI station.
