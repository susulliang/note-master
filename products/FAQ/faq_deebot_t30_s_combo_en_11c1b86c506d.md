# DEEBOT / T30 S Combo / EN - How to install and remove the station ramp base?

## Question

How to install and remove the station ramp base?

## Answer

Place the detachable and easy-to-clean base on the ground, align it with the station, push it inward, and be sure to hear a 'click,' it indicates that the installation is complete.
Press and hold the buttons on both sides of the cleaning base, and pull out the removable cleaning base in parallel outward.
