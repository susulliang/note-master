# ¿Qué debo hacer si el robot empieza a limpiar automáticamente pero no se ha definido un programa de limpieza?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Qué debo hacer si el robot empieza a limpiar automáticamente pero no se ha definido un programa de limpieza?

## 答案 / Answer

D20397

Intelligence

1. El robot empieza a limpiar a una hora fija, pero no se ha definido un programa de limpieza. ¿Qué debo hacer? 
Abra la aplicación ECOVACS HOME y toque Mis escenarios (My Scenarios), el icono con forma de casa pequeña en la esquina superior derecha, para comprobar si hay un programa de limpieza y, de ser así, eliminarlo. 

2. El robot empieza a limpiar a horas aleatorias, pero no se ha definido un programa de limpieza. ¿Qué debo hacer? 
Compruebe si la función Limpieza continua (Continuous Cleaning) está activada. Si está activada, el robot ajustará el tiempo de carga en función de las tareas restantes y continuará con las tareas pendientes.
