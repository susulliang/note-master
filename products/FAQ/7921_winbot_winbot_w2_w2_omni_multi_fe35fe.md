# Does the WINBOT W2 have a memory mode?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Does the WINBOT W2 have a memory mode?

## 答案 / Answer

W00159

Yes, it has a memory mode that allows it to repeat the last used mode (fast, deep, and fine).
