# ¿Cómo puedo ajustar el intervalo de tiempo que debe pasar para que el robot vuelva a la estación para limpiar las mopas de fregado?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Cómo puedo ajustar el intervalo de tiempo que debe pasar para que el robot vuelva a la estación para limpiar las mopas de fregado?

## 答案 / Answer

D20398

Cleaning

Ajuste de los intervalos de limpieza de las mopas de fregado: 
Abra la aplicación ECOVACS HOME y vaya a Limpieza inteligente (Smart Cleaning) para definir el intervalo de limpieza de las mopas de fregado. 
Nota: El intervalo de limpieza de las mopas de fregado se puede ajustar durante la limpieza. Si se ajusta el intervalo de limpieza, el intervalo de limpieza actual se basará en el intervalo establecido anteriormente. La próxima vez que el robot vuelva a la estación, limpiará las mopas de fregado siguiendo el intervalo actualizado.
