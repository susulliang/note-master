# Comment utiliser l'assistant vocal YIKO ?

## Question

Comment utiliser l'assistant vocal YIKO ?

## Answer

1. Ouvrir l'Application > Accéder à la page de fonctionnement de l'application > Paramètres dans le coin supérieur droit > Paramètres YIKO > Activer l'assistant vocal. Remarque : Si Assistant vocal YIKO > Assistant vocal est désactivé, le bouton AUTO DEEBOT devient jaune. 2. Guide des commandes vocales OK YIKO
2.1 Dans l'assistant vocal YIKO, appuyer sur Tout pour afficher toutes les commandes vocales YIKO.
Vous pouvez essayer de donner au DEEBOT des ordres tels que « OK YIKO, nettoie la maison » ou « OK YIKO, augmente la puissance d'aspiration ».
Remarque : ① YIKO apprend toujours de nouvelles commandes vocales. Ouvrir l'application pour voir quelles commandes vocales vous pouvez utiliser. ② Les commandes vocales YIKO peuvent être déclenchées dans une portée de 5 mètres. ③ L'assistant vocal YIKO prend actuellement en charge les fonctions hors ligne suivantes. Les autres commandes vocales ne peuvent être utilisées qu'une fois connecté à un réseau. OK YIKO, active le Bluetooth et connecte-toi.
OK YIKO, démarre la cartographie.
OK YIKO, démarre le nettoyage.
OK YIKO, nettoie la maison.
OK YIKO, retourne à la station d'accueil.
OK YIKO, retourne à la recharge.
OK YIKO, quitte la station d'accueil.
OK YIKO, démarre l'auto-nettoyage de la station d'accueil
OK YIKO, désactive la sécurité enfant.
