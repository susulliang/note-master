# What to do if the voice prompt says that Communication malfunction between DEEBOT and the Station?

## Question

What to do if the voice prompt says  that Communication
malfunction between
DEEBOT and the Station?

## Answer

1. If the firmware has just been upgraded/the main unit has been shut down and restarted, it will take time for the main unit to start up, and a disconnection prompt will appear. Please wait for 3 minutes.
2. Confirm whether the distance between the main unit and the station is too far. If it exceeds the operating distance, it is recommended to use the APP for operation.                           3.If main unit is next to the station and finds that it does not respond to station:                                                                                                                                                                                                ① In the app, enter "Settings" - check "about station" - check whether the station and DEEBOT are connected;
② If it shows not connected, please pair the DEEBOT and station again. The steps are as follows:
a.Disconnect the station from the power supply and power off main unit and wait for 5~10 seconds.
b. Reconnect the power supply to the station and make sure the light on the station panel is on.
c. Power on the DEEBOT again , and make sure you hear the power on tone.
d.  Manually push the tail end of main unit  to the station to ensure that the main unit  is correctly docked and the charging contacts are properly aligned. Wait for about 10~15S, the station and main unit  will be re-paired successfully, please try again;                                                                                                                                                                                                                       If the above possible causes have been eliminated but the problem is still not solved, please contact Ecovacs after-sales.
