# Kodėl WINBOT rodo pranešimą „Prijunkite maitinimą“, nors yra prijungtas?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Kodėl WINBOT rodo pranešimą „Prijunkite maitinimą“, nors yra prijungtas?

## 答案 / Answer

Tai sukelia žemos temperatūros baterijos apsauga. Naudokite tik esant 0 °C–40 °C temperatūrai. Esant žemiau 0 °C, nenaudokite vandens ar drėgnų pagalvėlių, kad išvengtumėte apledėjimo pavojaus.
