# DEEBOT / N20e&N20e Plus / ZH - 机器人在进行沿边清扫任务时出现路径歪扭情况，不走直线？The robot has a path distortion when performing edge cleaning tasks and does not walk in a straight line？

## Question

机器人在进行沿边清扫任务时出现路径歪扭情况，不走直线？The robot has a path distortion when performing edge cleaning tasks and does not walk in a straight line？

## Answer

（1）请确认墙边是否有踢脚线，并确认踢脚线高度是否低于5公分（如脚踢线低于5公分会导致机器人沿边传感器误识别，导致机器人撞板碰撞到脚踢线后一直触发避障，导致路径歪扭）。                                                                                                                                     （1）Please confirm whether there is a skirting board next to the wall and confirm whether the height of the skirting board is less than 5 cm (if the skirting board is less than 5 cm, it will cause the robot to misrecognize the edge sensor, resulting in the robot hitting the board and hitting the skirting board, triggering obstacle avoidance and causing the path to be crooked).
