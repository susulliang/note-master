# GOAT / GOAT O Series Mar / ZH - 计划表任务中触发一次临时割草任务，我的计划表任务还能继续吗？

## Question

计划表任务中触发一次临时割草任务，我的计划表任务还能继续吗？

## Answer

If a manual mowing task is triggered in the schedule period, the system preferentially completes the manual mowing task. After the manual task is completed, the GOAT will switch to schedule task if it is still in the scheduled task time. If the scheduled task time exceeds the scheduled task time, the system automatically ends this period schedule mowing project this time.
