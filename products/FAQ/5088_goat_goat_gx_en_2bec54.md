# Why does the frequency of the robot getting stuck increase with use of automatic edge optimization?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Why does the frequency of the robot getting stuck increase with use of automatic edge optimization?

## 答案 / Answer

G00113

Intelligence & Privacy

There is a certain misrecognition rate in AI edge recognition. It is recommended to back up the existing map before starting automatic edge optimization. If there is a problem with the optimized map, you can retrieve maps that have been previously saved in Map Edit ＞ More ＞ Restore Map.
