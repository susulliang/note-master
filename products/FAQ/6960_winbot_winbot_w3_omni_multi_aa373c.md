# 29

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

29

## 答案 / Answer

Les boutons situés sur le dessus de la station sont au nombre de sept : « Ouvrir le Compartiment de nettoyage », « Marche/Arrêt », « Rétracter le câble », « Haut/Bas », « Commutateur de fonction » et « Démarrer/Pause/Confirmer ».
1. Ouvrir le compartiment de nettoyage
Appuyez sur le bouton « Ouvrir le compartiment de nettoyage » pour ouvrir la porte du compartiment lorsque vous devez nettoyer le tampon d'essuyage.
2. Rétracter le câble
Appuyez sur le bouton « Rétracter le câble » pour rétracter le câble une fois le nettoyage terminé.
3. Sélection du mode
Appuyez sur les boutons « Haut/Bas » pour passer d'un mode à l'autre, puis appuyez sur le bouton « Confirmer » pour activer le mode sélectionné.
4. Commutateur de fonction
Appuyez sur le bouton « Commutateur de fonction » pour basculer entre les écrans du Winbot, de la station et du guide d'utilisation.
5. Retour à la position d'origine
Appuyez sur le bouton « Démarrer/Pause/Confirmer » et maintenez-le enfoncé pour que le robot revienne à son point de départ.
