# DEEBOT / X11S Omnicyclone / EN - How to solve the issue of the cleaning solution consumption is abnormal?

## Question

How to solve the issue of the cleaning solution consumption is abnormal?

## Answer

If the cleaning solution is not being used up or is being used too slowly, please follow these steps:
1. Open the app and make sure your Deebot is updated to the latest firmware.
2. Check that you are using the official cleaning solution.
3. Confirm whether the automatic cleaning solution dispensing function is enabled in the app. If it's off, turn it on and try again. If it's already on, try turning it off and then on again.
4. After completing the steps above, restart the station and mark the cleaning solution box (e.g., draw a line). Observe the usage over the next week.
