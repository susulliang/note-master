# 我可以将RTK基站贴着墙放置吗 / Can I install the RTK station against the wall？

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我可以将RTK基站贴着墙放置吗 / Can I install the RTK station against the wall？

## 答案 / Answer

10- RTK基站

不建议RTK基站贴着墙壁安装。

RTK基站受建筑物遮挡，可能无法收到卫星信号，建议基于以下原则，可以根据实际情况判断是否适合。
（1）RTK杆远离墙体放置，大型树木，建议距离＞2m。
（2）RTK基站上方无遮挡物，保证卫星信号接收。
（3）RTK信号头需要竖直向上，不可倾斜，建议不要放在松软地面上，以免角度产生偏移；
（4）安装位置RTK基站信号良好，通电1min后，观察到基站蓝色灯常亮即可

It is not recommended to install RTK reference stations against walls.

The positioning signal will be blocked by buildings. It is recommended to install the RTK station location based on the following principles.
(1) Place the RTK station away from the wall, large trees, the recommended distance is ＞2m.
(2) There is no shelter or shadow above the RTK base station.
(3) The RTK reference station should be upright and not tilted. It cannot be placed on soft ground to avoid Angle deviation. 
(4) You can confirm the signal of the RTK station good if the indicator on the RTK is steady on after the power on for 1 minute.
