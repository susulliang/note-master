# 如果使用SIM卡，一个月大概会耗费多少流量？ / How much data will be consumed per month if using a SIM card?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

如果使用SIM卡，一个月大概会耗费多少流量？ / How much data will be consumed per month if using a SIM card?

## 答案 / Answer

A LiDAR PRO

9- 4G模块

如果您不使用SIM卡观看实时视频和OTA升级，一个月的流量应在150M以内。
（1）用SIM卡观看1小时实时视频的流量消耗在100M左右
（2）一个OTA升级包在210M左右
为了减少流量消耗建议您使用WiFi观看实时视频和进行OTA升级
