Mapping Guide

Preparation before creating a map                                                                                            1.Please open the door, remove any debris on the floor, and ensure there is sufficient light, so that the map can cover the entire living environment.                                                              2.Long press the power button to start the robot, then place it directly in front of the station.
3. Click the Return button to allow the robot to return for charging.
4. Confirm that the Robot is connected to the network and online.                                                                                   Mapping
1. Open ECOVACS HOME ＞ Enter Robot Controls＞Map your home.
2. After mapping is completed, the Robot will prompt  "Mapping has completed, please check in the app."
