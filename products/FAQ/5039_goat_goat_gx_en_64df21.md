# How long will the robot take to learn the map?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

How long will the robot take to learn the map?

## 答案 / Answer

G00064

Mapping

The time to learn a map depends on the size of the map and the complexity of the garden. In a relatively empty space, the mower can learn about 800 m2 in an hour.
