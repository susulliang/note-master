# DEEBOT does not return to base station when passing it as it cannot find the recharge signal.

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

DEEBOT does not return to base station when passing it as it cannot find the recharge signal.

## 答案 / Answer

DEEBOT does not return to base station when passing it as it cannot find the recharge signal.

1. Whether the base station is powered off or moved artificially, if so, please connect the base station to the power supply and return it to its original position.
2. The robot can be placed directly in front of the base station, and click the "robot exit/recall button" of the base station to observe whether it can return to the base station. If it does not work, please contact the after-sales service.
3. Observe whether the base station ground is uneven, if so, please place the cleaning seat on a flat ground.
