# What should be done if DEEBOT accidentally vacuums up liquid?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

What should be done if DEEBOT accidentally vacuums up liquid?

## 答案 / Answer

D10006

Enable

Usage advice

Please turn off DEEBOT immediately. Remove the Dust Bin, Filters, Main Brush and allow them to dry completely before reinstalling them.
If the DEEBOT does not function normally after You’ve completed these steps, please contact Customer Service.
