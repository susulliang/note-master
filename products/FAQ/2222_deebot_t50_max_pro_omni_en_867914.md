# 如何正确使用机器人Wi-Fi管理功能？ / How to add more WIFI signals?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

如何正确使用机器人Wi-Fi管理功能？ / How to add more WIFI signals?

## 答案 / Answer

1. 点击页面右上角“设置”＞点击“地宝高级设置”＞点击“机器人信息”＞点击Wi-Fi管理＞点击“+”可添加多个Wi-Fi信号。

Click Enter Device-click settings-click Wi-Fi management-click + to add.
