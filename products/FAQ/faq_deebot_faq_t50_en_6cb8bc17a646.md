# DEEBOT / FAQ T50 / EN - Robot Charging Guide

## Question

Robot Charging Guide

## Answer

1.Remove the top cover, push the power switch to "1" side;
2.Place the Robot in front of the station, long press the return key to make it automatically return to the station, there will be a voice prompt "start charging".
