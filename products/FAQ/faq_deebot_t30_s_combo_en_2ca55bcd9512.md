# How to use the robot Wi-Fi management function correctly?

## Question

How to use the robot Wi-Fi management function correctly?

## Answer

1: Use of the robot Wi-Fi management function
1. Confirm that Dibao has successfully connected to the APP and is online.
2. Open the APP > Enter the robot control > Settings in the upper right corner > Deebot information > Wi-Fi management > Click "+" to add multiple Wi-Fi signals.
