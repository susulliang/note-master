# J'ai installé le module de connexion supplémentaire. Pourquoi n'est-il pas reconnu ?

## Question

J'ai installé le module de connexion supplémentaire. Pourquoi n'est-il pas reconnu ?

## Answer

Si le module a été correctement installé en suivant les étapes du manuel d'instructions, redémarrer le robot. S'il n'est toujours pas reconnu après plusieurs redémarrages, contacter le service clientèle ECOVACS.
