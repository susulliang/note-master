# DEEBOT / T50降配版 / EN - Why doesn't the robot return to wash the mop when starting a mopping task from outside the base station?

## Question

Why doesn't the robot return to wash the mop when starting a mopping task from outside the base station?

## Answer

1.For optimal mopping performance, it is recommended to always start the mopping task from the base station. If your robot is already outside the base station, please command it to return first—using a voice command, the app, or by pressing and holding the button on the robot—before initiating a mopping task.

2.Additionally, if the robot is already inside the base station and its mop has been washed within the last 10 minutes without a mopping task being started, it will begin cleaning directly without an additional mop wash when a new mopping task is initiated.
