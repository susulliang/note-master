# 17

> **产品线**：DEEBOT　**语言**：multi
>

## 问题 / Question

17

## 答案 / Answer

Si le robot vous avertit que les Capteurs anti-chute sont poussiéreux ou présentent un dysfonctionnement, il est recommandé de commencer par éteindre le robot, puis de suivre les étapes suivantes :
1. Soulevez légèrement le côté où la serpillière à rouleau est installée, desserrez délicatement la boucle bleue du bac à eau, puis retirez le bac à eau.
2. Retirez le couvercle supérieur du robot, placez l'Interrupteur d’alimentation sur « O » pour l'éteindre, puis retournez le robot afin que son dessous soit tourné vers le haut.
3. Nettoyez les Capteurs anti-chute situés sur le dessous pour éliminer toute poussière susceptible de les obstruer.
4. Après avoir nettoyé les Capteurs anti-chute, remettez le bac à eau en place. Vous devriez entendre un « clic », ce qui signifie qu'il est bien en place.
5. Remettez le robot en marche et vérifiez si le problème est résolu.
