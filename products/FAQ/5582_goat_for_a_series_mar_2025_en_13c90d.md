# 更换机器后4G  Cellullar Module还可用吗？ / Is the 4G Cellullar Module still usable after replacing the machine?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

更换机器后4G  Cellullar Module还可用吗？ / Is the 4G Cellullar Module still usable after replacing the machine?

## 答案 / Answer

4G  Cellullar Module

4G  Cellullar Module不与机器绑定，在机器A上使用后插到机器B上，仍然可用

The 4G Cellullar Module is not bound to the machine and can still be used when plugged into machine B after being used on machine A
