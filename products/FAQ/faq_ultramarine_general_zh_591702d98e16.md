# Which pool types & structures is this device suitable for? Are there pools not suitable for this device?

## Question

Which pool types & structures is this device suitable for? Are there pools not suitable for this device?

## Answer

It fits for nearly all pool surfaces, including Pebble, Plaster, Concrete, Paint, Tiles, Gunite, Vinyl Liner, PVC and etc.; as well as infinity pools.
