# How do I select DEEBOT X1's suction power?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

How do I select DEEBOT X1's suction power?

## 答案 / Answer

D20236

Cleaning

You can set the suction power via the App or a YIKO smart voice command: Quiet mode, Standard, Max, Max+. 
(1) There is reduced suction power in Quiet mode. Vacuum and Mopping mode is recommended. 
(2) Select Max or Max+ for a dirty floor. However, please note that DEEBOT's single cleaning time may be reduced when using Max/Max+ suction power. 
(3) DEEBOT may be harder to wake up via a smart voice command when set to Max+. We recommend using other control modes in this situation.
