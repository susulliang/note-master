# 我想要建立线型的禁区？ / Can I create a linear no-go zone?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我想要建立线型的禁区？ / Can I create a linear no-go zone?

## 答案 / Answer

3- 建图

当前禁区需为一个闭合区域，如需建立线型禁区可遥控机器到达最远端后原路返回起点，使其闭合

The no-go zone needs to be a closed area. If the linear zone needs to be established, the remote control GOAT can return to the starting point after reaching the farthest end and make it closed
