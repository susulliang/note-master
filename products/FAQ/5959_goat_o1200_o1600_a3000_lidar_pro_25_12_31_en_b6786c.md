# 哪些区域我需要创建禁区？ / Which areas do I need to create forbidden areas?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

哪些区域我需要创建禁区？ / Which areas do I need to create forbidden areas?

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

3- 建图

（1）泳池、沙坑等容易跌落的区域
（2）植被高度低于20cm，无围挡，可能造成误割的花圃菜地
（3）有凸出树根的大树，或根部处有斜坡的大树
（4）倾斜超过27°（50%）（A Series）/24°（45%）(O Series)的斜坡或凹坑
（5）蹦床、秋千、滑梯等娱乐设置区域
（6）黑色的桌椅等户外家具
（7）易碰碎的透明物体
（8）地面上裸露的电线
