# DEEBOT / DEEBOT T30 PRO OMNI Silver / EN - The robot cannot return to the station, what should I do?

## Question

The robot cannot return to the station, what should I do?

## Answer

If the following conditions occur, the robot will be unable to return to the station.
1. Confirm the placement of the station, keep the ground in front of it clear, and remove any obstacles if there are any;
2. Check if the station is powered off or moved artificially. If so, please power on the station and put it in its original position;
3. Check if there are water stains in the cleaning sink and the surrounding ground. If so, please wipe it with a dry rag;
4. Check if the machine is trapped or alarming during the cleaning process. If so, please help handle it;
5. Check if the ground where the location of the station is uneven (such as on carpet). If so, please place the station on a flat ground;
6. Check whether the recharging route is blocked, for example, the door of the room with the station is closed;
7. You can place the robot directly in front of the station, short press the return button        to see if it can return to the station. If it does not work, please contact after-sales service.
Note:
1. When building a map, it is recommended to start from the station;
