# GOAT / GOAT O Series Mar / ZH - 多WIFI管理中，添加WIFI为什么添加不了？

## Question

多WIFI管理中，添加WIFI为什么添加不了？

## Answer

When adding multiple Wi-Fi networks, your phone must first be connected to the Wi-Fi network that needs to be added. There is no need to reconfigure the network for the GOAT after it has been added.
