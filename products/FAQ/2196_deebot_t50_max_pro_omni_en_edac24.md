# 机器人充电使用指导 / Robot Charging Guide

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

机器人充电使用指导 / Robot Charging Guide

## 答案 / Answer

1.取下主机正面上盖，拨动电源开关至“I”开机。
2. 将主机放置基站正前方；长按下“启动按键”，让机器人自动返回基站，听到语音提示“开始充电”。

1.Remove the top cover, push the power switch to "I" side;
2.Place the Robot in front of the station, long press the Auto button to make it automatically return to the station, there will be a voice prompt "start charging".
