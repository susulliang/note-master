# 3

> **产品线**：DEEBOT　**语言**：multi
>

## 问题 / Question

3

## 答案 / Answer

전원 코드를 연결하고 도킹 스테이션 주변에 물체(좌우 0.5m 이내, 전방 1.5m 이내), 특히 반사면이 있는 물체를 치웁니다. 전원 버튼을 길게 누릅니다.                                                                                                                                   1. 도킹 스테이션 앞에 로봇을 놓고, 로봇이 충전 스테이션으로 자동으로 돌아갈 수 있도록 복귀 버튼을 누르면 "충전 시작"이라는 음성 안내가 들립니다.                                                                                                                                    2. 로봇을 충전 스테이션에 수동으로 밀어 넣습니다. 그런 다음 좌우로 흔들어 도킹이 성공적으로 완료되면 '충전 시작'이라는 음성 안내가 들립니다.
