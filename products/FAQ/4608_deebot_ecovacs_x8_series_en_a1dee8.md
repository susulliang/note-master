# 1.Confirm that the mop washing tray is installed in place;
2.Confirm that the float is installed completely and the magnet is still there;
3.Please check whether there is water in mop washing tray；:
①If not
Please check if the float is stuck by any foreign object. If there is, please clean it.                                                                                              Please move it up and down, If the float can fall back naturally, then it is normal.
②If so
(1)Open the clean water tank, check whether there are obvious foreign objects on the sealing ring. If so, please wipe and clean; if not, please close the cover tightly;
(2)Remove sealing plugs to clean, then reinstall them, check that there are no foreign objects between the tank and the station, then put back the water tank and press it down; make sure the tank is in place;
(3)Open the APP-Settings-Move the device, click on the auxiliary draining, see if the water can be drained;
(4)If not, remove the mop washing tray, pour the water out, clean the mop washing tray, then reinstall the mop washing tray;
(5)Re-plug the station power switch and start self-cleaning to observe.
