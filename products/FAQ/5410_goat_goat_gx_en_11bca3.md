# What should I do if I have forgotten the PIN code for my GOAT?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

What should I do if I have forgotten the PIN code for my GOAT?

## 答案 / Answer

51

Intelligence & Privacy

(1) If your GOAT is linked to the App, you can go to Settings ＞ More Settings ＞ Security Settings ＞ Change PIN Code ＞ Forgot My PIN Code to reset the PIN code. You will be required to enter the password for your ECOVACS HOME App account.                                                                                                                                 (2)If your GOAT is linked to the App,but it's off line,you can stand close to GOAT, enter the app in Bluetooth mode to modify and reset the PIN code, specific path: Settings-SafetySettings-Change PIN Code-Forgot PinCode-Enter the login password-Enter New Pin code;
(3) If your GOAT is no longer linked to the App, please contact the Ecovacs after-sales team to provide a backup PIN code-turn on the GOAT-use backup PIN code to enter the GOAT control panel operation interface-settings-change PIN code-enter New PIN code. Then start scanning the QR code to connect the GOAT with the app, bind the beacon, create a map, and start mowing.
