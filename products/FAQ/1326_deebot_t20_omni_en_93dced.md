# How can I use the self-cleaning function to clean the cleaning sink of the station that are dirty?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

How can I use the self-cleaning function to clean the cleaning sink of the station that are dirty?

## 答案 / Answer

D20413

Usage advice

1. Open the Station's top cover and remove the cleaning brush. 
2. Press and hold the Station Start button for 5 seconds. The robot will automatically exit the Station and water will automatically flow from the cleaning sink. 
3. Use the cleaning brush to clean the cleaning sink. 
4. Once cleaning is complete, press and hold the Station Start button for 5 seconds, and the cleaning sink will drain out the waste water. 
5. Place the robot in front of the Station, press and hold the Start button to let the robot return to charge itself. 
6. Open the Station top cover, remove the waste water tank, and empty out the waste water. 

Note: (1) Before use, make sure that the clean water tank contains enough water. 
          (2) You can run the self-cleaning function as many times as needed.
