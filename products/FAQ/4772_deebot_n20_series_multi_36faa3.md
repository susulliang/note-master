# Lorsqu'un robot est utilisé pour la première fois, le coton ignifugé antibruit peut émettre une légère odeur lors du vidage, mais cela n'affecte pas l'utilisation.

> **产品线**：DEEBOT　**语言**：multi
>

## 问题 / Question

Lorsqu'un robot est utilisé pour la première fois, le coton ignifugé antibruit peut émettre une légère odeur lors du vidage, mais cela n'affecte pas l'utilisation.

## 答案 / Answer

Pourquoi la station d'accueil dégage-t-elle une odeur lorsqu'elle est vidée ?

Lorsqu'un robot est utilisé pour la première fois, le coton ignifugé antibruit peut émettre une légère odeur lors du vidage, mais cela n'affecte pas l'utilisation.
