# 正确安装机器人？ / How to correctly install the robot?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

正确安装机器人？ / How to correctly install the robot?

## 答案 / Answer

1. 请打开外包装依次取出产品及配件，移除基站上的胶带，基站清洁内组件胶带，主机防撞保护条等
2. 请将主机翻转后，底部朝上放置。
3. 取出边刷，对准卡槽后往下按，听到“嗒”一声表示安装到位。
4. 请安装基站斜坡底座，按压斜坡底座两边，听到“哒”声表示安装到位。
5. 请使用包装箱内的电源线，和基站背面电源接口连接，接通电源，寻找合适位置靠墙摆放。
 （基站放置在平坦的硬质地面，左右5cm和前方80cm 范围内不要放置物品）
温馨提示：
基站优先放置瓷砖地面使用，若您放置在地板使用，请定期检查基站底部是否残留水渍，若有请及时清理，以防受潮。

1.Please open the outer packaging box，take out the Robot, remove all the tapes on the station and inside the cleaning sink, remove the anti-collision protection strip, etc.;
2.Turn the Robot over.
3.Take out the side brush, align it with the slot, press it down. A "click" sound indicates that it has been installed properly.
4.Install the base, press both sides, the "click" sound heard indicates that the installation is in place;
5.Take out the power cord, connect it to the power socket on the back, turn on the power, and find a suitable position to place it against the wall.
(Please place the Robot on a flat, hard surface, without any objects within 5cm on both sides and 80cm in front of it.)
Warm Reminder：
Robot should be placed on ceramic tile floors as a priority. If you need to place them on wooden floor, please check the bottom of the Robot regularly for any water stains, and clean them promptly to prevent moisture damage.
