# DEEBOT T30 OMNI Silver,DEEBOT T30 OMNI Black,DEEBOT T30 OMNI Rosé,DEEBOT T30 PRO OMNI Rosé,DEEBOT T30 PRO OMNI Black,DEEBOT T30 PRO OMNI Silver

## 问题 / Question

DEEBOT T30 OMNI Silver,DEEBOT T30 OMNI Black,DEEBOT T30 OMNI Rosé,DEEBOT T30 PRO OMNI Rosé,DEEBOT T30 PRO OMNI Black,DEEBOT T30 PRO OMNI Silver

## 答案 / Answer

30

Que dois-je faire si le robot n'effectue pas de nettoyage continu ?

1. Vérifier que le nettoyage continu est activé dans l'application. 
2. Le nettoyage continu ne peut pas se déclencher en mode Ne pas déranger. 
3. Si le robot retourne au chargeur et qu'une alerte s'active, le nettoyage continu ne peut pas se déclencher. 
4. Une fois le nettoyage continu déclenché, le robot ne peut pas être redémarré et ses réglages ne peuvent pas être réinitialisés. 

Remarque : le nettoyage continu n'est possible qu'en mode AUTO.

Cosa si deve fare se il robot non esegue la pulizia continua?

1. Verificare se la funzione Pulizia continua è attivata nell'app. 
2. La funzione Pulizia continua non può essere attivata in modalità Non disturbare. 
3. Se il robot torna in ricarica e viene emesso un avviso, la pulizia continua non può essere attivata. 
4. Una volta attivata la pulizia continua, non è possibile riavviare il robot o ripristinare le impostazioni predefinite. 

Nota: la pulizia continua è valida solo in modalità automatica.

¿Qué debo hacer si el robot no realiza la limpieza continua?

1. Compruebe si la función Limpieza continua (Continuous Cleaning) está activada en la aplicación. 
2. La función Limpieza continua (Continuous Cleaning) no se puede activar si el modo No molestar (Do Not Disturb) está activado. 
3. Si el robot vuelve al cargador y emite una alerta, no se puede activar la limpieza continua. 
4. Una vez activada la limpieza continua, no se puede reiniciar el robot ni restaurar la configuración de fábrica. 

Nota: La limpieza continua solo es válida en el modo AUTOMÁTICO (AUTO).

ロボットが連続清掃を実行しない場合はどうすればよいですか。

1. 連続清掃がアプリで有効になっているかを確認します。 
2. 応答不可時間が有効になっていると、連続清掃は起動しません。 
3. ロボットが充電器に戻り、警告が発生した場合、連続清掃は起動しません。 
4. 連続清掃が起動すると、ロボットの再起動や工場設定の復元はできません。 

注：連続清掃は、AUTOモードでのみ有効です。
