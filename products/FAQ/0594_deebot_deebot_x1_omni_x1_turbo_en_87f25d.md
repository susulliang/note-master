# Why does DEEBOT not return to the docking station to wash the mopping pads if it starts mopping outside the docking station?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

Why does DEEBOT not return to the docking station to wash the mopping pads if it starts mopping outside the docking station?

## 答案 / Answer

D20238

Cleaning

We recommend DEEBOT starts mopping from the docking station. If DEEBOT is outside the docking station, tap the Recall button on the docking station or use the button in the App to make DEEBOT return to the docking station in advance, then start the mopping.
