# GOAT春季重新拿出来使用，有什么注意事项？ / What should be noted when using GOAT again in spring?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

GOAT春季重新拿出来使用，有什么注意事项？ / What should be noted when using GOAT again in spring?

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

8- 保养维护

（1）将充电站重新组装，并且安装在去年的原址
（2）在连接电线前检查电线是否有损坏；
（3）检查刀片是否有生锈损坏，若有，请及时更换刀片；
（4）轻拭顶部环激光雷达以及前部的AI鱼眼摄像头
（5）开启机器，查看APP和机器是否工作正常，如不正常，请重新创建地图。

请注意：操作过程中佩戴手套，以免被刀片割伤
