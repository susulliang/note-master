# ¿Cómo puedo desmontar las bandejas de las mopas de fregado y limpiar las mopas?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Cómo puedo desmontar las bandejas de las mopas de fregado y limpiar las mopas?

## 答案 / Answer

D20401

Maintenance

Extracción y limpieza de las bandejas de las mopas de fregado 
 1. Dele la vuelta al robot y colóquelo sobre un felpudo suave. 
 2. Gire las bandejas de las mopas de fregado hacia fuera (asegúrese de que las bandejas de las mopas de fregado estén levantadas). 
 3. Utilice las dos manos para sujetar las bandejas de las mopas de fregado y tire de ellas con un poco de fuerza para extraerlas. Entonces, podrá extraer las mopas de fregado lavables de las bandejas. 
 4. Lave y seque las mopas para volver a utilizarlas. 

Instalación de las mopas de fregado y sus bandejas 
1. Dele la vuelta al robot y colóquelo sobre un felpudo suave. 
2. Alinee las mopas de fregado con las bandejas de las mopas de fregado y presiónelas hasta que encajen. A continuación, coloque las bandejas en el robot. Asegúrese de que escucha el clic que indica que se han instalado correctamente.
