# How do I use the Home Furnishing function?

## Question

How do I use the Home Furnishing function?

## Answer

3D Map
The Home Furnishing function is available after the mapping is completed.

Open the app and go to Smart Cleaning > Map Management > Home Furnishing to set the relevant settings:
1. Home Furnishing > Interior Furniture > Select the furniture you want to add (e.g. a bed) > Select size adjustment.
2. Home Furnishing > Wall Edit > Select the outer wall border and adjust the size if needed
