# ¿Cómo puedo actualizar el firmware del robot?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿Cómo puedo actualizar el firmware del robot?

## 答案 / Answer

D20337

Upgrade

1. El DEEBOT debe estar colocado en la estación y debe estar cargándose. 
2. El DEEBOT debe tener un mínimo de un 50 % de batería (se recomienda actualizarlo tras haberlo cargado durante 3 horas). 
3. Asegúrese de que el DEEBOT está conectado a la aplicación ECOVACS HOME y que la señal Wi-Fi es buena.
4. Vaya a Limpieza inteligente (Smart Cleaning) ＞ Configuración (Settings) ＞ Acerca del DEEBOT (About DEEBOT) ＞ Actualizar el DEEBOT (Update DEEBOT)

Nota: Si la actualización automática está activada, el DEEBOT se actualizará automáticamente a la última versión.
