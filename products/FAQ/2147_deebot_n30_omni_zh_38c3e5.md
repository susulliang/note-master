## 答案 / Answer

What to do if the robot does not execute Auto Resume?

1.Confirm if the Auto Resume function is enabled.
2.Check if the current cleaning mode is AUTO mode.
3.Auto Resume will not trigger during the "Do Not Disturb" period.
4.If the robot returns automatically and triggers a fault alarm, Auto Resume will not activate.
