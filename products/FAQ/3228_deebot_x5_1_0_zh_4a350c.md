# ビデオマネージャーの使い方を教えてください。 / 1.ビデオマネージャーの使い方：1.1 ビデオマネージャーとスマートクリーニングを同時に使用することはできませんが、この2つの機能は自由に切り替えることができます。
1.2 ビデオマネージャーは、写真撮影、ビデオ録画、音声通話、パトロール、到着時のコマンド、 ギャラリーの管理をサポートします。 

2.使い方：2.1［ビデオマネージャー］＞［カメラ］＞［リアルタイムで写真を撮る］に移動します。2.2［ビデオマネージャー］＞［カメラ］＞［無音のビデオを録画する］(最大15秒 ) に移動します。
2.3［ビデオマネージャー］＞［カメラ］＞［ギャラリーの写真とビデオの管理］に移動します。
2.4［ビデオマネージャー］＞［音声通話］＞［ビデオ通話を発信］に移動します。
2.5［ビデオマネージャー］＞［パトロール］DEEBOTは、設定された各ポイント（北、東、南、西）に移動して写真を撮影し、自動的にドッキングステーションに戻ります。2.6［ビデオマネージャー］＞［到着時のコマンド］＞［マップの場所をマーク］に移動します。［GO］をタップすると、DEEBOTは自動的にマークされた場所に移動します。
