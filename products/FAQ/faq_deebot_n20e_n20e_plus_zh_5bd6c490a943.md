# DEEBOT / N20e&N20e Plus / ZH - 如何使用定点清洁？How to start spot cleaning?

## Question

如何使用定点清洁？How to start spot cleaning?

## Answer

1.将机器人拎至需要清洁的区域。
2.手动按下“定点清洁键”
3.工作完成后机器会返回基站。                                                                                                                                                                                                           1. Manually move the robot to the area to be cleaned;
2. Short press the spot cleaning button;
3. When the task is completed, the robot will return to the charging station.
