# ¿El DEEBOT se puede dañar si se deja cargando durante demasiado tiempo?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

¿El DEEBOT se puede dañar si se deja cargando durante demasiado tiempo?

## 答案 / Answer

D20015

Enable

Charging

No, una vez que DEEBOT se ha cargado completamente, se activa la función de reposo para evitar que se sobrecargue. No permita que los niños jueguen con él. 
Cuando reinicie el robot, pulse primero el botón Auto para activarlo y, a continuación, seleccione la operación que desee.
