# What if the WINBOT alarms or returns to start early during edge cleaning?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

What if the WINBOT alarms or returns to start early during edge cleaning?

## 答案 / Answer

Step 1: Recovery. Use the App to manually remote control the WINBOT to a reachable position. If not connected, scan the QR code or manually add the model in the App. Follow the voice prompts.
Step 2: Inspection. 
1. Ensure the pad is aligned correctly. 
2. Avoid edge cleaning on frames ≤2mm or glass with gaps; use Fast Cleaning Mode for these areas instead.
