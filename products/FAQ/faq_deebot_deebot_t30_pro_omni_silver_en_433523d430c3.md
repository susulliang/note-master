# The robot cannot be charged, what can I do?

## Question

The robot cannot be charged, what can I do?

## Answer

1. Check whether the power cord is correctly plugged into the power outlet. You can also try a different outlet. Also check that the power cord is correctly plugged into the back of the station.
2. Check that main unit  powers on normally.
    (1) If it can be powered on: Please place the robot directly in front of the station, press exit/return button to make the robot to return to the station to charge itself.
    (2) Unable to power on the robot: If the robot cannot power on, manually push the rear end of the robot into the station cleaning sink. Once docked, a voice prompt will be broadcast, the AUTO light flashes white, the robot will start charging.
4. If a red light flashes while robot is operating, follow the voice prompts to troubleshoot the problem.
6. Check whether the charging electrodes are dirty. Clean them and try again.                                                                                                                                                                                                                                   If the issue persists, please contact ECOVACS After-sales.
