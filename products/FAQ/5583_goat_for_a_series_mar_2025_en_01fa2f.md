# 安装4G  Cellullar Module后就可以使用实时定位功能了吗？ / Can I use the Distance Alarm after installing the 4G  Cellullar Module?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

安装4G  Cellullar Module后就可以使用实时定位功能了吗？ / Can I use the Distance Alarm after installing the 4G  Cellullar Module?

## 答案 / Answer

4G  Cellullar Module

1.4G  Cellullar Module与超距离防盗没有绑定关系，你可以在没有4G Cellullar Module情况下打开防盗功能（RTK定位）
2.防盗报警设置是超出机器超出基站位置200m外，一般情况下机器都会失去wifi信号导致无法报警到APP上，如果有4G  Cellullar Module，报警会正常工作

1.4G Cellullar Module has no binding relationship with Distance Alarm. You can turn on the anti-theft function without the 4G Cellullar Module（RTK positioning）
2. The Distance Alarm setting is set to exceed the machine by 200m beyond the charging station position. In general, the machine will lose WiFi signal and cannot alarm on the APP. If there is a 4G Cellullar Module, the Distance Alarm will work normally
