## 问题 / Question

How to start a mopping task? / How to start a mopping task? / Wie starte ich einen Wischvorgang? / Comment démarrer une tâche de lavage ? / Come avviare un'attività di lavaggio? / モップ掛けを開始する方法を教えてください。 / 물걸레질은 어떻게 시작합니까?

## 答案 / Answer

モップ掛けを開始する方法を教えてください。

1.洗浄水タンクを取り出して、MAXラインまで水を加えます。水を入れた後、洗浄水タンクを閉じてステーションに戻します。
2.ダスト回収キャビンカバーを取り外し、洗浄液ボトルを取り出します。
3.ボトルを開けて、ECOVACS洗浄液を追加します。ボトルを閉じてステーション内に取り付けます。正しく取り付けられるとカチッという音がします。
4.次に、ダストキャビンカバーを閉じます。
5.ロボットを裏返して、モップパッドアセンブリを取り付けます。
6.ロボットの電源を入れ、ステーションの前に置いて電源ボタンを長押しすると、ロボットが自動でステーションに戻り充電を開始します。
7.電源ボタンを短押しすると、清掃タスクが開始されます。
