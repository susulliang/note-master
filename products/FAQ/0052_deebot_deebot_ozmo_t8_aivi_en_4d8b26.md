# The unit still bumps into an object after AIVI recognizes it. (Behavior: still lightly coming into contact with a target object after recognition)

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

The unit still bumps into an object after AIVI recognizes it. (Behavior: still lightly coming into contact with a target object after recognition)

## 答案 / Answer

D17003

Enable

AI

●AIVI recognizes obstacles in order to: 
✔Avoid moving around furniture
✔Avoid getting stuck and tangled
Even while avoiding obstacles, AIVI gets the unit as close to them as possible to better clean the areas around them. For this reason, AIVI will choose to reduce speed and touch an object lightly or not touch it depending on the situation. This will seem to the user like the unit is lightly touching obstacles, however it is normal for AIVI.
●Some household environments are overly complex, or some of the target objects inside the household are unusually shaped. This can also make AIVI react more slowly, leading to contact. For the best recognition results, it is recommended to stay on top of the latest firmware updates and upgrade your unit through the ECOVACS Home App in a timely manner. 
●Insufficient lighting can cause AIVI recognition to have difficulty judging distances, which can cause the unit to clearly contact objects. It is recommended to use the unit in a well light environment.
