# 如果日常使用中有RTK基站丢失或者坏了，还能正常使用GOAT吗？ / If an RTK station is lost or broken, can GOAT still be used normally?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

如果日常使用中有RTK基站丢失或者坏了，还能正常使用GOAT吗？ / If an RTK station is lost or broken, can GOAT still be used normally?

## 答案 / Answer

10- RTK基站

若RTK基站丢失或损坏，GOAT不可正常使用。

RTK基站丢失或者损坏会导致GOAT接收不到定位信号，当GOAT检测到信号丢失时将会自动停止工作。

The GOAT cannot be used if the RTK reference station is lost or broken.
GOAT will not receive the positioning signal, then it cannot working when it detects the signal loss.
