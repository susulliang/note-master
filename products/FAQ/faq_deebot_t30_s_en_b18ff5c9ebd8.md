# When mopping the floor, the rag bracket cannot be stretched and retracted normally; how to deal with it?

## Question

When mopping the floor, the rag bracket cannot be stretched and retracted normally; how to deal with it?

## Answer

1: When mopping the floor, the rag bracket cannot be stretched and retracted normally; how to deal with it?
1. In App-Settings-Smart Cleaning Settings, check whether "TruEdge Gap Technology" has been turned on. If not, please turn it on before use
2. Manually move the rag holder; check for foreign objects stuck; if so, clean the foreign objects
3. Turn off the robot and restart the machine
4. If it is still not resolved, please contact after-sales service
2: Why does the cleaning cloth sometimes expand outward and sometimes not?
1. When Dibao is mopping the floor and working in the mode of sweeping and mopping at the same time, the rag tray is normally expanded outward to achieve full coverage.
2. However, the rag tray will retract when it is in the raised state, including the following scenarios: quick mapping, treasure navigation, collapse area, backwash, recharge, escape from trouble, lift the carpet, pause, end the task, and move the machine manually.
III. If the rag plate keeps expanding outward, will there be any leakage?
1. Ecovacs original dynamic inward rag can better cover the corners and legs of tables and chairs when it is outside, with stronger coverage;
2. For the gap between the two rags, the machine will make up for it when it is in the bow shape, so there is no need to worry about the situation of missing dragging.
Note: If the machine is turned off, manually expand the cloth bracket; the cloth bracket cannot be manually retracted, which is a normal phenomenon. Restarting the machine will automatically retract the cloth bracket.
