# What is the reason for failure to add the Navigation Beacon in the App?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

What is the reason for failure to add the Navigation Beacon in the App?

## 答案 / Answer

G00022

Navigation Beacon

(1) Confirm that the Navigation Beacon has been powered on successfully. The Navigation Beacon will beep when it is powered on successfully. 
 (2) Pair the Navigation Beacon within 1 m of the GOAT. 
 (3) Please confirm that the signal receiver on the GOAT is in the upright position. 
 (4) Confirm if the number of Navigation Beacons added has reached 10. 
 (5) Check whether the Navigation Beacon has not been unpaired from another machine. 
 If the problem persists, please contact ECOVACS Customer Care
