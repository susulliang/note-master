# DEEBOT 업그레이드 - 펌웨어 업그레이드 / 더 나은 제품 경험을 위해 때때로 ECOVACS HOME 앱의 펌웨어를 업그레이드해야 할 수 있습니다. 다음은 업그레이드에 관한 팁 및 설명입니다.

팁:
1. 로봇은 베이스 스테이션에 있고 충전 중이어야 합니다.
2. 배터리 잔량이 50%를 넘어야 합니다. (3시간 충전 후 업그레이드하는 것이 좋습니다.)
3. DEEBOT이 ECOVACS HOME 앱과 연결되어 있고 WiFi 신호가 양호한지 확인합니다.
단계:
1. ECOVACS HOME 앱에 로그인합니다.
2. 스마트 청소 전환을 누릅니다.
3. 화면 오른쪽 위 모서리에 있는 설정 아이콘을 누릅니다. 
4. "DEEBOT 정보" ＞ "DEEBOT 업데이트"를 선택합니다.

참고: 자동 업그레이드를 활성화한 경우 DEEBOT이 자동으로 최신 버전으로 업그레이드됩니다.
