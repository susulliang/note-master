# In welchem Modus kann von WLAN auf das Modul zum automatischen Verbinden umgeschaltet werden?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

In welchem Modus kann von WLAN auf das Modul zum automatischen Verbinden umgeschaltet werden?

## 答案 / Answer

G00143

Disable

Additional Connection Module

Wenn das WLAN-Signal gut ist, wird automatisch auf WLAN umgeschaltet. Bei schwachem WLAN-Signal wird auf das Signal des Moduls gewechselt.
