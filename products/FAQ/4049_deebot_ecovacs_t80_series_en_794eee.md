# How do I set up to clean along the floor?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

How do I set up to clean along the floor?

## 答案 / Answer

1. Click "Settings" ＞ select "Robot Advanced Setting" ＞ select "Clean along the floor" to turn it on or off.
2. Click "Settings" ＞ Select the area you want to set on the map ＞ Select "Wood Floor" ＞ Click "Right Angle 90°" icon to adjust the wood grain display.
