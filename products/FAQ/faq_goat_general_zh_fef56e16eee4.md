# 多区域分割是我可以将边界画成曲线么？

## Question

多区域分割是我可以将边界画成曲线么？

## Answer

At present, there are two kinds of drawing multi-zone mode, manual remote control and draw on the APP. If there is a need for curve zone boundary, please use manual remote control mode.
