# 設置および使用ガイド

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

設置および使用ガイド

## 答案 / Answer

準備：
 1. 箱を開け、製品、付属品、取扱説明書を取り出します。ご使用前に取扱説明書をよくお読みください。
 2. ワイピングパッドを水で濡らし、水滴が落ちなくなるまで絞ります。
 3. ワイピングパッドの幅の広い端と狭い端を合わせます。ワイピングパッドをベルクロに貼り付け、しっかりと押さえて固定します。
 4. ゴム製のキャップを開け、水タンクに最大50mlの水道水またはECOVACS WINBOT専用洗浄液を入れます。しっかりと閉めてください。
 ご注意：
 - 洗浄液を入れすぎて水タンクから溢れ出さないようにしてください。
 - 精製水やろ過水は使用しないでください。
 - ECOVACS WINBOT専用洗浄液の使用を推奨します。他の製品を使用すると、洗浄性能が低下したり、製品が破損したりする恐れがあります。
 - ECOVACS WINBOT専用洗浄液がなくなった場合は、一時的に水道水を使用できます。
 5. セーフティロープを安定した物体に固定します。事故を防ぐため、カラビナをロックしてください。
 6. 電源コードをアダプターに接続し、コンセントに差し込んでください。 WINBOTの操作：
 重要な注意事項：
 - 使用前に完全に充電してください（約3時間）。青色のライトが点灯し続けると、フル充電完了を示します。
 - フレームレスガラスを清掃する際は、ガラスに貼り付ける位置が端から少なくとも10cm離れていることを確認してください。
 - 窓のハンドルの近くでWINBOTを起動しないでください。
 - 厚さ3mm以上の平らなガラス専用です。
 - 電源投入後は、ファンが髪の毛や小さなゴミに接触して詰まらないよう注意してください。
 - ガラスに傷がつかないよう、吸着させる前に吸着面を点検し、異物を取り除いてください。
 - 作業開始前にスプレーノズルを乾かしてください。
 1. スタートボタンを2秒間長押しします。ファンが回転し始めたら、WINBOTをガラスに置くと、自動的に吸着して清掃を開始します。
 2. ボタンを短く押すか、アプリを使用して清掃を一時停止・再開してください。
 3. 清掃が完了すると、WINBOTは開始位置付近に戻ります。ハンドルをしっかりと握り、ファンが停止するまでスタートボタンを長押ししてから、WINBOTを取り外してください。
 4. 使用しなくなった場合は、洗浄液を捨て、ワイピングパッドを速やかに取り外してください。
