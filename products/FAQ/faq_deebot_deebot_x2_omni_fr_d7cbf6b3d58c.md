# Les plaques de patin de lavage ne sont pas correctement installées/sont coincées.

## Question

Les plaques de patin de lavage ne sont pas correctement installées/sont coincées.

## Answer

Le robot indique que les plaques de patin de lavage ne sont pas correctement installées :
Après avoir démonté et réinstallé les plaques de patin de lavage, vous entendrez un clic indiquant qu'elles sont correctement installées. Redémarrer ensuite le robot. Si le problème persiste, contacter le service clientèle.

Le robot indique que des débris sont coincés dans les plaques de patin de lavage :
Retourner le robot et vérifier si des débris sont coincés dans les plaques de patin de lavage. Si c'est le cas, les nettoyer. Si le problème persiste après le nettoyage, contacter le service clientèle.
