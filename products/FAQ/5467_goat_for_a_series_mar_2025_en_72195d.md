# 自动建图-我的基站未放置在草坪上，可以使用自动建图吗？ / Can I use automatic mapping if my charging station is not placed on the lawn?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

自动建图-我的基站未放置在草坪上，可以使用自动建图吗？ / Can I use automatic mapping if my charging station is not placed on the lawn?

## 答案 / Answer

MAP

可以在机器退出基站后，遥控机器到达草坪区域，然后点击自动建图，启动建图。
*注意距离不要过远，可能影响回充效果

sure
After GOAT exits the docking station, you can remotely control it to reach the lawn area, and then click hosting mode to start mapping.
*The distance should not be too far, as this may affect the recharging effect.
