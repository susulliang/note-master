# How to set clean along the floor direction?

## Question

How to set clean along the floor direction?

## Answer

1.Click Settings-Click DEEBOT Advanced Settings-Click Clean along the Floor, to turn it on or off;
2.Select the area to be set ground material-Select Wood-Click the 90° right angle icon to adjust the floor wood grain to display in the horizontal or vertical direction.
