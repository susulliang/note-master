# 30

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

30

## 答案 / Answer

1. L'écran est divisé en trois sections : Winbot, Station et Guide d'aide.
2. Appuyez sur le bouton d'alimentation de la station et maintenez-le enfoncé pour l'allumer. Ensuite :
Appuyez sur le bouton de sélection des fonctions pour sélectionner l'icône Winbot. Utilisez les boutons Haut/Bas pour choisir entre les modes de nettoyage Rapide, En profondeur et Nettoyage des bords (d'autres modes sont disponibles dans l'application). Appuyez sur le bouton Démarrer/Pause pour confirmer et démarrer le mode sélectionné.
3. Appuyez sur le bouton Function Switch pour sélectionner l'icône Station. Utilisez les Boutons Haut/Bas pour choisir entre les modes Lavage standard, Nettoyage en profondeur et Self-Clean. Appuyez sur le bouton Démarrer/Pause pour confirmer et démarrer le mode sélectionné.
4. Appuyez sur le bouton Function Switch pour sélectionner l'icône Help. Utilisez les Boutons Haut/Bas pour parcourir les questions et réponses courantes.
