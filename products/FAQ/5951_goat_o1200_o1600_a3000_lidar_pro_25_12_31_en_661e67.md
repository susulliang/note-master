# 我的花园里有狭窄通道，应该如何建图？ / There is a narrow passage in my garden, how should I map it?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我的花园里有狭窄通道，应该如何建图？ / There is a narrow passage in my garden, how should I map it?

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

3- 建图

1、若窄道宽度大于对应机型标准即可使用自动建图功能：O LiDAR PRO≥0.8m、A LiDAR PRO≥0.9m；宽度不足则无法使用。
2、若宽度小于1.2m / 1.3m且有高墙遮挡的狭长通道中定位信号较弱，GOAT通过时易产生卡困，可尝试切换为手动模式，并请尽量贴边遥控。
