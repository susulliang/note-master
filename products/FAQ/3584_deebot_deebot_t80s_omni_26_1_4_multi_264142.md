# 47

> **产品线**：DEEBOT　**语言**：multi
>

## 问题 / Question

47

## 答案 / Answer

Vous pouvez résoudre le problème en procédant comme suit :
1. Vérifiez que le DEEBOT est allumé.
2. Vérifiez si le mode Ne pas déranger est activé dans l'application. Sur une plage horaire « Ne pas déranger », le robot ne répondra pas aux tâches planifiées.
3. Vérifiez le niveau de la batterie dans l'application pour vous assurer que l'autonomie est suffisante.
4. Vérifiez les tâches planifiées dans les paramètres de l'application pour confirmer qu'elles sont correctement configurées et enregistrées.
Notez également que si la carte actuelle utilise la fonctionnalité Fusion de zones, les tâches planifiées pour les zones associées ne seront pas exécutées.
