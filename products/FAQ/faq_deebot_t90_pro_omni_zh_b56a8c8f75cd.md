# Abnormal Cleaning Solution Consumption

## Question

Abnormal Cleaning Solution Consumption

## Answer

If your robot shows slow or no Cleaning Solution consumption, try the following steps:
 1. Update the robot to the latest firmware via the app.
 2. Confirm you are using Ecovacs-branded Cleaning Solution.
 3. Check if the "Auto Cleaning Solution Adding" switch in the app is enabled. If disabled, enable it before use. If already enabled, disable and then re-enable it.
 4. After completing the above steps, restart the station and mark the Cleaning Solution box (e.g., with a horizontal line). Monitor usage over the next week.
