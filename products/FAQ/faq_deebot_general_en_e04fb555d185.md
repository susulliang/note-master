# The robot voice prompts "Dust Bag installation error." How to handle it?

## Question

The robot voice prompts "Dust Bag installation error." How to handle it?

## Answer

1. Disconnect the power supply and remove the Dust Bin cover.
2. Remove the dust bag.
3. Reinstall the dust bag and close the Dust Bin cover.
4. Reconnect the power supply and test the dust collection function via the app again.
