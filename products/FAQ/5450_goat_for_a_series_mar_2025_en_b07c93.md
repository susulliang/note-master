# 我的花园中狭窄通道可以安装RTK基站杆？ / Can I install RTK Reference Station in a narrow passage in my lawn?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

我的花园中狭窄通道可以安装RTK基站杆？ / Can I install RTK Reference Station in a narrow passage in my lawn?

## 答案 / Answer

RTK Reference Station

RTK基站受建筑物遮挡，可能无法收到卫星信号，建议基于以下原则，可以根据狭窄通道的情况判断是否适合。
（1）RTK杆远离墙体放置，大型树木，建议距离＞2m。
（2）RTK基站上方无遮挡物，保证卫星信号接收。
（3）安装位置RTK基站信号良好，通电1min后，观察到基站蓝色灯常亮即可

The positioning signal will be blocked by buildings. It is recommended to install the RTK Reference Station location based on the following principles.
(1) Place the RTK Reference Station away from the wall, large trees, the recommended distance is ＞2m.
(2) There is no shelter or shadow above the RTK base station.
(3) You can confirm the signal of the RTK Reference Station good if the indicator on the RTK is steady on after the power on for 1 minute.
