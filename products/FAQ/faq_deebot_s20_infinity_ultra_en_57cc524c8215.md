# DEEBOT / S20 Infinity Ultra / EN - How to handle it when the robot prompts "Dust Bag Installation Error"?

## Question

How to handle it when the robot prompts "Dust Bag Installation Error"?

## Answer

1.Disconnect the power supply and remove the dust cabin cover.
2.Take out the dust bag.
3.Reinstall the dust bag and close the dust cabin cover.
4.Reconnect the power supply, then test using the Empty Dust Bin function in the APP.
