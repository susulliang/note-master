# Kann ich die Position einer Navigationsbake ändern, nachdem sie installiert wurde?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Kann ich die Position einer Navigationsbake ändern, nachdem sie installiert wurde?

## 答案 / Answer

G00024

Enable

Navigation Beacon

Sie können die Position einer Navigationsbake vor der Kartenerstellung nach eigenem Ermessen anpassen. Wenn Sie die Position einer Navigationsbake ändern, nachdem die Karte erstellt wurde, verschiebt sich das Positionssignal und eine Neuzuordnung wird erforderlich.
