# Comment sélectionner les modes de nettoyage ?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Comment sélectionner les modes de nettoyage ?

## 答案 / Answer

1. Appuyez longuement sur le bouton Démarrer pour allumer l'appareil et placez-le sur la vitre pour qu'il adhère.
2. Sélectionnez un mode de nettoyage via l'application :
① Mode nettoyage en profondeur : pour les fenêtres de plus de 50 cm de large, le WINBOT suit un parcours en Z pour essuyer une fois, puis effectue un passage de nettoyage le long des quatre bords ; pour les fenêtres de moins de 50 cm de large, il effectue deux passages de nettoyage en N.
② Mode nettoyage en profondeur : le WINBOT suit un parcours en Z/N pour essuyer deux fois. Pour les fenêtres de moins de 50 cm de large, il effectue deux nettoyages en N ; pour les fenêtres de plus de 50 cm de large, il effectue deux nettoyages en Z.
③ Mode nettoyage rapide : le WINBOT suit un parcours en Z/N pour essuyer une fois.
④ Mode nettoyage des bords : le WINBOT nettoie les quatre bords une fois dans le sens des aiguilles d'une montre.
⑤ Mode nettoyage localisé : activez-le via la télécommande ou l'application. Le WINBOT essuiera 4 fois de haut en bas, en se centrant sur sa position actuelle.
⑥ Une fois que le WINBOT est en marche, vous pouvez également utiliser les boutons de la télécommande pour le diriger à 360° et pulvériser de l'eau manuellement.
