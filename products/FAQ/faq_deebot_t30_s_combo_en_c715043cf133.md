# DEEBOT / T30 S Combo / EN - The robot prompts "cloth holder winding"/incomplete installation, how to deal with it?

## Question

The robot prompts "cloth holder winding"/incomplete installation, how to deal with it?

## Answer

How to handle the machine prompt "cloth holder winding"?
1. Flip the main unit and check whether there is any foreign object entangled on the rag holder. If there is, please clean it up and observe it.
2. If there is no entanglement on the rag holder after inspection, restart the machine and observe again. If it still prompts "the rag holder is entangled", please contact Ecovacs after-sales service for processing.
II. How to deal with the robot alarm: "The rag tray is not fully installed"?
1. Flip the main unit and check whether the rag bracket is installed in place. Please install it correctly. Make sure to hear the "click" sound to indicate that the installation is complete.
2. Check whether the rag holder is seriously worn, etc. If it is worn, please contact the after-sales service of Ecovacs.
3. Check whether the magnet of the rag holder is lost; if it is lost, please contact Ecovacs after-sales service.
