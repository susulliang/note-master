# Start mowing after moving the GOAT, does the GOAT need to be reacquainted with the environment?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Start mowing after moving the GOAT, does the GOAT need to be reacquainted with the environment?

## 答案 / Answer

27

Mowing

(1) GOAT needs to be familiar with the environment in the new lawn mowing environment. If not, you can choose not to be familiar with it again.
 (2) If GOAT is moved to the base station for charging, it does not need to familiarize itself with the environment again when it starts working next time.
