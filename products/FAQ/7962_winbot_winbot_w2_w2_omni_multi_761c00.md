# Dois-je vider la solution de nettoyage du réservoir d'eau après avoir utilisé le WINBOT W2 ?

> **产品线**：WINBOT　**语言**：multi
>

## 问题 / Question

Dois-je vider la solution de nettoyage du réservoir d'eau après avoir utilisé le WINBOT W2 ?

## 答案 / Answer

W00152

1. Si vous utilisez souvent le WINBOT W2 (par exemple tous les 1-3 mois), il est inutile de vider le réservoir d'eau.
2. Si vous n'utilisez pas le WINBOT W2 pendant une longue période (par exemple tous les trimestres ou plus), vider le réservoir d'eau pour éviter toute odeur désagréable.
