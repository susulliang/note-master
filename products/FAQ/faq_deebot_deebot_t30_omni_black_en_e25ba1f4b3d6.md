# DEEBOT / DEEBOT T30 OMNI Black / EN - How to start select/draw/intelligent hosting cleaning?

## Question

How to start select/draw/intelligent hosting cleaning?

## Answer

Intelligent Hosting:The robot will intelligently identify the room type and automatically adjust cleaning parameters.The cleaning parameters can not be adjusted artificially.
1.Need to create a map first;
2.Enter App-click enter-auto-AI-start
Select Cleaning
1. Need to create a map first;
2.After the map is successfully constructed for the first time, the machine will automatically partition it.
3. According to actual needs, select areas to clean. You can select the cleaning mode (such as mop-only), cleaning times, suction power, and water flow level in "Cleaning Preferences".
4.If you select multiple areas to clean, the robot will clean them in sequence according to the order of tapping (only effective once).
Draw Cleaning
1. Need to create a map first;
2. One or more custom areas can be added within the map range, and the robot will clean them in sequence according to the order of adding.
3. According to actual needs, you can select the cleaning mode (such as vacuum-only), cleaning times, suction power, and water flow level adjustment in "Cleaning Preferences".
4. The water flow level cannot be adjusted in vacuum-only  mode; the suction power cannot be adjusted in mop-only mode, and the number of cleanings cannot be adjusted in mop after vacuum mode.
5.Up to 5  areas can be added, and the minimum default size of the custom area is: 1m *1m.                                                                                                                                                                                                                                                                                                                                                                     Notes for select/draw cleaning:                                                                                                                                                                                                          ①The water flow level cannot be adjusted in vacuum-only  mode; the suction power cannot be adjusted in mop-only mode, and the number of cleanings cannot be adjusted in mop after vacuum mode;                                                                                                                                                                                                                                                         ②If the machine has started working, the cleaning times and cleaning mode cannot be adjusted; the suction power and water flow level can be adjusted in real time as needed.
