# RTK基站插歪了影响使用吗？ / Does the RTK station installed skew affect use?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

RTK基站插歪了影响使用吗？ / Does the RTK station installed skew affect use?

## 答案 / Answer

10- RTK基站

RTK基站需要竖直朝上安装，可用手机上的水平仪进行检测。若有偏斜将会造成定位偏差。建议定期检查RTK基站是否有倾倒的趋势，可进行扶正。
请务必保证RTK基站安装稳定，比如不要安装在松软地面上，避免大风天气或其他原因带来晃动等。

The RTK reference station should be installed vertically facing upwards, and you can use the horizontal level on your phone to check it. Any tilt will result in positioning errors. It is recommended to regularly check if the RTK base station has a tendency to tilt, and corrective measures can be taken if needed.

Please ensure that the RTK reference station is installed stably. For example, do not install it on soft ground to avoid shaking caused by strong winds or other factors.
