# Que dois-je faire si le WINBOT W2 glisse sur le côté ou?

## Question

Que dois-je faire si le WINBOT W2 glisse sur le côté ou?

## Answer

Un léger glissement est normal et n'affecte pas le fonctionnement.

Vous pouvez également essayer la procédure suivante :
1. Retourner le WINBOT W2 et essuyer la saleté ou les taches sur les chenilles d'entraînement à l'aide d'un chiffon propre.
2. Si la surface est trop humide, essuyer une zone avec un chiffon propre avant de fixer le WINBOT W2.
3. Afin d'éviter toute chute, ne pas utiliser le WINBOT W2 par temps humide, par exemple lorsqu'il pleut.
