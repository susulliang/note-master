# RTK基站安装完成后我还可以改变它的位置吗？ / Can I change the location of RTK Reference Station?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

RTK基站安装完成后我还可以改变它的位置吗？ / Can I change the location of RTK Reference Station?

## 答案 / Answer

RTK Reference Station

在您进行地图创建以前您可以随意调整RTK基站的位置，当地图生成后改变RTK基站的位置将会造成定位信号的移动，需要您重新创建地图

You can adjust the location of the RTK Reference Station before you create the map. 
Changing the location of the RTK Reference Stationafter the map is generated will cause the positioning signal error and require you to remap.
