# Comment entretenir mon WINBOT W2 ?

## Question

Comment entretenir mon WINBOT W2 ?

## Answer

Conseils d'entretien du WINBOT W2
1. Réservoir d'eau
Lorsque le WINBOT W2 a terminé le nettoyage, vider le réservoir d'eau (si vous avez utilisé la solution de nettoyage, nous vous conseillons d'ajouter un peu d'eau pour rincer le réservoir d'eau).
2. Tampon d'essuyage
① Lors du remplacement du tampon d'essuyage, veiller à l'installer correctement, la largeur du tampon correspondant à la largeur du fond du WINBOT W2.
② Utiliser un tampon d'essuyage propre.
③ Vérifier que le tampon d'essuyage est propre et sec avant de le ranger.
3. Chenilles d'entraînement
Avant de nettoyer les chenilles d'entraînement, s'assurer que le WINBOT W2 est connecté à la source d'alimentation et allumé, puis utiliser le contrôle par application pour faire tourner les chenilles d'entraînement vers l'avant/l'arrière, et les nettoyer.
4. Composants inférieurs
Avec un chiffon sec, il est possible d'essuyer les composants inférieurs du WINBOT W2, y compris le ventilateur, les capteurs, les rouleaux latéraux, etc., pour qu'ils restent propres et exempts de corps étrangers.
