# 机器人出现工作声音大/异常声音如何处理？ / What to do if the robot makes loud or unusual noises during operation?

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

机器人出现工作声音大/异常声音如何处理？ / What to do if the robot makes loud or unusual noises during operation?

## 答案 / Answer

地宝工作时异音：
1.打开APP＞进入设备＞向上滑动页面＞吸力选择标准（超强/强劲模式下声音会明显增大）
2.转动万向轮，确认转动是否顺畅；可使用干抹布清理万向轮
3.取下边刷，确认边刷与边刷轴承是否有缠绕；若有，请清理
4.取下滚刷与滚刷盖板，确认滚刷与滚刷盖板是否有缠绕；若有，请清理
5.取下滚筒拖布，确认滚筒拖布是否有缠绕；若有，请清理
6.清理尘盒及吸尘口，确认尘盒滤芯是否有潮湿，若有，请务必晾干后使用
基站工作时异音：
1.烘干异音：
请将基站进行断电重启，手动在APP上重新打开烘干功能。观察声音是否消除，若仍异响，请按流程处理。
2.集尘异音：
2-1请检查集尘仓门正确安装到位。当听到清晰的“哒”声时，表示仓门已安装到位。
2-2请检查尘袋正确安装到位。
3.洗滚筒拖布异音：
3-1.检查可拆底座是否有异物导致洗拖布异音，清理后使用观察。
3-2.检查污水盒是否堵塞导致污水吸取异常产生异音，建议先清理污水盒后使用观察。                                                                                                                                                                           温馨提醒：
1选择大吸力，工作声音会变大的同时工作时间也会变短。

For the robot
 1. Open APP＞enter ＞slide up the page＞select "Standard" suction power (the sound will be obviously increased in super/strong mode)
 2.Rotate the universal wheel to check if it moves smoothly.
 3.Remove the side brush and check for any debris entangled around it or the bearing. Clean if necessary.
 4.Remove the main brush and its cover, checking for any debris. Clean if necessary.
 5.Remove the roller mop and check for any debris. Clean if necessary.
 6.Clean the dust bin and suction inlet. Ensure the filter is dry before use if it is damp.
 For the station
 1. Drying noise:
 Power off and restart the station, then manually reopen the drying function in the app. Check if the noise stops. If not, contact after sales service.
 2. Dust collection noise:
 2-1 Please check the dust collection cabin cover is correctly installed in place. A clear "da" sound indicates it is secured.
 2-2 Please check that the dust bag is correctly installed.
 3. Mop washing noise:
 3-1. Check mop washing tray for any debris causing noise during mop washing. Clean and observe.
 3-2. Check if the dirty water tank is clogged, which may cause abnormal suction noise. Clean the tank first and observe.        Note:
Selecting high suction power increases operating noise and shortens working time.
