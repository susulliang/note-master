# 滚筒拖布支架无法外扩，如何处理？ / What to do if the roller mop won't expand?

> **产品线**：DEEBOT　**语言**：zh
>

## 问题 / Question

滚筒拖布支架无法外扩，如何处理？ / What to do if the roller mop won't expand?

## 答案 / Answer

1.在App-地宝高级设定“TruEdge灵隙技术”是否已经开启若未打开请打开后使用
2.在APP中检查清洁模式是否选择的是边扫边拖模式
3.检查滚筒拖布是否有异物卡住，若有请取下清理

1.In the app, check if "TruEdge Adaptive Edge Mopping" in the robot advanced settings is enabled. If not, enable it.
 2.In the app, check if the cleaning mode is set to "Vacuum and Mop."
 3.Check if the roller mop is jammed with debris. If so, remove and clean it.
