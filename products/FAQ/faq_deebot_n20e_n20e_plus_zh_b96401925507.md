# DEEBOT / N20e&N20e Plus / ZH - 机器人地图创建？ Mapping Guide

## Question

机器人地图创建？                                                                                 Mapping Guide

## Answer

一：创建地图前准备
1.请打开房门并移除地面杂物并保证光线充足，以便地图能够覆盖整个家居环境；
2.请将拖布支架拆下；
3. 长按主机“启动”键开机；放置在充电座正前方;
4. 点击主机“返回”键，让机器自主返回充电，对接成功后开始充电。                                                                                                          5.确认您的机器人已连接网络，并处于在线状态。
二：创建地图
1.打开ECOVACS HOME>进入机器人操控>建图。
2. 建图完成后机器人会有语音播报“建图已完成，请在app中查看”此时地图已创建成功。
3.您也可以短按机器人“启动按键”启动，机器会边工作边建图。                                                                                                                   Preparation before creating a map                                                                                                                                                        1. Please open the door, remove any debris on the floor, and ensure there is sufficient light, so that the map can cover the entire living environment.                                                                                                                                                               2.Please remove the mopping pad plate.
3.Long press the power button to power on the Robot, then place it directly in front of the docking station.
4. Press the return button to make it return for charging autonomously.
5. Please confirm that the Robot is connected to the network and online.                                                                                                  Mapping
1. Open ECOVACS HOME > Enter Robot Controls>Map your home.
2. After mapping is completed, the Robot will prompt  "Mapping has completed, please check in the app."                                                             3. Also can short press the power button to start cleaning and mapping at the same time.
