# 地图上GOAT的位置和实际和位置不符 / The location of GOAT on the map does not match the actual location

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

地图上GOAT的位置和实际和位置不符 / The location of GOAT on the map does not match the actual location

## 答案 / Answer

O LiDAR PRO,A LiDAR PRO

5- 智能&安全

（1）请确认是否搬动、拖动了GOAT，之后若未启动任务，APP地图上将仍显示GOAT被搬动前的位置；
（2）请确认是否搬动了充电基站的位置，若充电基站位置发生改变，地图位置也会产生偏移；
（3）若启动任务时GOAT在基站外，GOAT需要时间获取定位，此期间APP上的GOAT位置显示可能不准；
（4）若GOAT在过于空旷的地方，距离GOAT60m外无房屋或其他高大物体，GOAT位置可能会略有偏差。

如已排除以上情况，请检查
（1）GOAT的摄像头是否有脏污
（2）当前天气是否晴好无雨
如果以上操作GOAT始终在地图上显示的位置不正确，可删除地图后重新建图
