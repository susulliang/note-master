# How to handle map issues (distortion, overlap)?

> **产品线**：DEEBOT　**语言**：en
>

## 问题 / Question

How to handle map issues (distortion, overlap)?

## 答案 / Answer

1.Use the "Restore Map" feature in the app's map management to revert to the original saved map.
2.If the original map is inadequate, delete it and create a new one.
