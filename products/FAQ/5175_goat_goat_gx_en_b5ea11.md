# Will use of the robot be affected if the navigation beacon is not upgraded or there is an upgrade failure?

> **产品线**：GOAT　**语言**：en
>

## 问题 / Question

Will use of the robot be affected if the navigation beacon is not upgraded or there is an upgrade failure?

## 答案 / Answer

G00041

Navigation Beacon

Normal operation will not be affected if the navigation beacon is not upgraded or there is an upgrade failure.
