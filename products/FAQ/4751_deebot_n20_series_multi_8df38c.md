# 1. Veuillez ouvrir la porte, retirer tous les débris sur le sol et vous assurer que la lumière est suffisante pour que la cartographie puisse couvrir l'ensemble de l'environnement de vie.                                                              2. S'assurer que le module d'aspiration/réservoir sans patin de lavage est installé.
3. Appuyer longuement sur le bouton d'alimentation pour mettre le robot sous tension, puis le placer directement devant la station d'accueil.
4. Appuyer sur le bouton de retour pour qu'il revienne à la charge de manière autonome. 
5. Veuillez confirmer que le robot est connecté au réseau et en ligne.
6. Ouvrir ECOVACS HOME ＞ Saisir les contrôles du robot ＞ Cartographie rapide.
7. Une fois la cartographie terminée, le robot affiche le message « La cartographie est terminée, veuillez vérifier dans l'application ». À ce stade, la cartographie a été créée avec succès.
