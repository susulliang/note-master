# DEEBOT / X11S Omnicyclone / EN - How to use the Agent Hosting mode?

## Question

How to use the Agent Hosting mode?

## Answer

1. Click to enable Agent Hosting mode - Click Start.
2. Click on the working status bar - Enter the working progress page.
3. Click the area parameter list button - Adjust the corresponding area parameters.
4. During operation, the robot can use the Skip and Add Cleaning functions as needed.
TIPS: The Agent Hosting mode can only be enabled after completing map construction and successfully executing at least one cleaning task.
