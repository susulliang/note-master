# The robot is alerting that there is an issue with the Anti-drop Sensor. What should I do?

## Question

The robot is alerting that there is an issue with the Anti-drop Sensor. What should I do?

## Answer

App prompt: The Anti-drop Sensor is covered with dust. Please clean up.
1. Flip DEEBOT over and wipe the Anti-drop sensors located at the bottom of the robot. (When flipping the robot, place it down gently)
2. Shut down and restart.
