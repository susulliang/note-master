Factory Reset Goat

Folder: AMR Email Templates

Template ID: 00Xcz0000058g8rEAA

Follow the steps below to factory reset your GOAT:

  1. Power On: Press and hold the OK button for about 3 seconds to power on the GOAT.
  2. Initiate Reset: Press and hold both the Start and Home buttons simultaneously. Continue holding until the device shows a countdown from 5 to 0, ending with four flashing "0000."
  3. Enter PIN: Enter your correct PIN code (or the temporary PIN provided by the team). The system will begin cleaning the memory, which takes about 30 seconds. Once completed, the device will automatically reboot. The factory reset is successful after the reboot finishes.

For a detailed video guide, please refer to the following link:
https://youtu.be/kxKdN-UF0_o

After the reset is complete, you can set up a new PIN code and re-enter it to confirm.

Important: Please note that performing a factory reset will erase the existing map and all stored data from the robot's memory. After the reset is complete, you will need to set up the GOAT again and remap the area before resuming normal operation.
