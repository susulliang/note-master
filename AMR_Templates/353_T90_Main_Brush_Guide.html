If you're noticing unusual sounds like clicking, receiving alerts about the Main Brush being tangled, or finding that dust isn't being picked up effectively, we recommend taking the following steps to resolve the issue:

  1. Turn OFF the Device: Before starting any troubleshooting, turn off your robot to ensure safety.
  2. Remove the Main Brush Assembly: Press and hold the two clips on the Main Brush Cover toward the center. Then, remove the cover and take out the Main Brush assembly.
  3. Clean the Main Brush: Remove any tangled debris from the Main Brush.
  4. Reinstall the Main Brush: Align the Main Brush mounting bracket precisely with the motor. Push it in smoothly until it's fully seated. Gently rotate the Main Brush to ensure it turns freely without resistance.
  5. Reattach the Main Brush Cover: Align the cover with the machine's slots, then press it into place. You should hear a "click" sound when the cover is properly installed.
