Please note that the Mop-Only cleaning mode is exclusively available within the Zone Cleaning feature.

To start a Mop-Only task:

  1. Ensure the map is complete—Zone Cleaning will be available once done.
  2. Click on Zone, adjust the frame, select the orange Mop icon, and initiate Mop-Only mode.

This mode is best suited for smaller, focused cleaning tasks where only mopping is needed.
