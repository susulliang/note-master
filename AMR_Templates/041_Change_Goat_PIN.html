Thank you for reaching out to us. 

If you would like to change the PIN code after the initial setup of your GOAT, please follow these steps:

1. Open the robot control page via Standard Mode (WiFi Mode – no need to be near the machine) or Bluetooth Mode (recommended to be within 6 meters of the GOAT). 

2. Tap Settings, then select Robot. 

3. Go to Robot Settings, then enter Safety Settings.

4. Tap Change PIN Code and follow the on-screen instructions.

If you need further assistance, please don't hesitate to reach out again. We are always here to help!
