Incomplete Cleaning/Unable to Find Designated Areas

Description: 无法找到指定清洁区域 (通用)

Folder: AMR Email Templates

Template ID: 00Xcz0000057T0nEAE

  1. Please first confirm if the environment has changed (for example, if any furniture, or even the location of the Docking Station, has been moved).
  2. Make sure the DEEBOT has not been physically moved while it was powered on—If it has, kindly power it off, restart it, and place it back on the base station before restarting.
  3. If you see the error message "Unable to find designated area" when using Room or Zone mode, please try running AUTO vacuum only to check—If it runs normally, let it complete the full cleaning cycle once, then try Room/Zone mode again.
  4. If the issue persists, please go to Map Management, back up the map, then restore it once completed, and try again.
  5. If it still does not work, kindly delete the current map and rebuild a new one.
  • When rebuilding, do not use Quick Mapping.
  • Please select normal AUTO mode and let the DEEBOT run a full vacuum-only cleaning cycle for the entire house.
