Charging Issue

1. Check the Station Power
Confirm if there is a light on the station.
If not, please make sure the power cord is firmly plugged into the station.
If your station has a rocker switch, kindly ensure it is turned to the "I" position.

2. Check the Charging Dock Pins
Gently press the charging dock pins to confirm if they rebound smoothly.

3. Check the Robot Power
Ensure the main switch button of the robot is in the "I" position.

4. Clean the Charging Contacts
Please check if there is any dust or dirt on the charging dock pins or the robot's charging contacts.
Wipe them gently with a clean, dry cloth.
⚠️ Reminder: Make sure the robot is switched OFF and the charging dock is unplugged before cleaning.

5. Test Charging
Push the DEEBOT onto the charging dock and check whether it charges normally.

6. Check the Outlet
Confirm whether the outlet is working.
If not, please try another outlet.

7. For N79 Series Only
Please try charging the DEEBOT directly by plugging in the charging cord. (The port is located next to the main power switch.)
