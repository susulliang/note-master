Navigation_Module_Error

  • Gently adjust the navigation module at the front of the Deebot, check for debris or entanglement.
  • Restart the Deebot (Power OFF rarr; wait rarr; ON).
  • Run a short test cleaning cycle.
  • If issue persists, perform a factory reset.

How to reset: Press Reset Button for ~5 seconds. You will hear "Reset to default settings" followed by boot music.
