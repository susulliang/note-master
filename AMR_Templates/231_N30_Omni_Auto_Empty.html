N30 Omni: Auto empty issue (Dust can't be collected)

Folder: AMR Email Templates

Template ID: 00Xcz000005ZC9tEAG

  1. Confirm the Auto-Empty Frequency:
    Please check whether the Auto-empty frequency is set to 'Auto'. If so, the robot will empty its dustbin only after a full cleaning cycle is completed.
    If you would like the robot to empty the dustbin every time it returns to the docking station, we recommend setting the Auto-empty frequency to 'Extra'.
  2. Ensure the docking station is connected to the power source and verify that the docking station's power cord is correctly plugged into the socket.
  3. Confirm that the dust collection cabin on the docking station is in place for auto-emptying.
  4. Make sure that the disposable dust bag is fitted properly.
  5. Auto-emptying will not start if Do Not Disturb mode is enabled in the settings.
  6. Auto-emptying will not initiate if you manually return the DEEBOT to the docking station.
  7. Use the app to prompt the docking station to auto-empty the dust bin and listen for the suction noise. If the auto-empty still does not work, please send us a screenshot.
