Mobile Hotspot Connection Method

You can connect the robot to a mobile phone hotspot. Once the connection is successful, you can set functions in the ECOVACS Home App, such as scheduled cleanings. Note: Turning off the hotspot will only affect remote control, but any functions that have already been set will still work. If you need to modify settings later in the app, you will need to reconnect to the hotspot.

How to Set Up the Hotspot:

  • Enable a 2.4GHz mobile hotspot on another family member's phone (this can be done in your phone's settings).
  • Use your phone to connect to the Wi-Fi signal shared by that hotspot.
  • Then, use the same phone to connect the robot and check if the connection is successful.
  • To simplify the process, we recommend setting the hotspot name and password as a simple combination of numbers.
  • After successfully connecting to the hotspot, you may also try changing your home Wi-Fi name and password to match the hotspot, and then test the connection again.

Reason for Testing with a Hotspot:
This test helps determine whether the issue lies with the robot or the home network.
If the robot connects successfully to the hotspot, it indicates that the robot itself is functioning properly, and the connection failure is most likely related to the home Wi-Fi network.
