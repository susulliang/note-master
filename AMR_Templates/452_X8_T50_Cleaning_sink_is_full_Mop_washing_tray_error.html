X8/T50: Cleaning sink is full / Mop washing tray error / Wastewater not drained

Template ID: 00Xcz000006IaftEAC

Check the cleaning sink for water:

If there is no water:

  • Verify if the float is obstructed by any foreign objects. If so, clean it thoroughly.
  • Move the float up and down. If it falls back into place naturally, it is functioning properly.

If there is water residue:

  • Open the dirty water tank and inspect the sealing ring for foreign objects. Clean if needed.
  • Remove the sealing plugs, rinse them, and reinstall. Check for obstructions between tanks and station.

Ensure the overflow float ball can move freely. Use the app to test auxiliary draining.
