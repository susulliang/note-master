# N30 Omni: Mopping plate tangled issue 鎶瑰竷鏀灦缂犵粫鎶ラ敊

1. Remove and Clean: Remove the mopping plates and use the multi\-function cleaning tool to clean around the sockets and mopping pads\.

2. Reinstall Mopping Plates: Reinstall the mopping plates firmly until you hear a 'click' sound indicating proper installation\.

3. Power Cycle: Power off and on the DEEBOT before restarting the cleaning process for further testing\.

4. Switch Sides: If the issue persists, try switching the sides of the mopping plates to see if that resolves the problem\.

5. Ensure the firmware version of the Deebot has been updated to the latest version\.

If the issue continues, please perform a hard reset of the DEEBOT\.
