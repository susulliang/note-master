# X5 Pro Omni: How to restore map 鎭㈠鍦板浘

- Open the app and go to Enter\.

- Navigate to the Map Management section\.

- Select the current map in use and tap the down arrow button\.

- Choose Restore to revert to the previous map version\. Once restored, select Back Up to save the changes\.
