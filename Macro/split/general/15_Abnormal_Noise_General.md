## Abnormal Noise 寮傞煶/鍣煶:

Please switch **OFF** the DEEBOT and kindly follow the steps below:

1. **Main Brush**

    - Remove the main brush from the machine\.

    - Clean and check carefully if there is any dust or debris tangled around the ends\.

    - If no issues are found, please try running the machine **without the main brush** on a flat floor to check if the noise persists\.

2. **Side Brushes**

    - Remove the side brushes and clean both the brushes and their bearings\.

    - When reinstalling, please make sure the **color of each side brush matches the color of its slot**\.

3. **Main Brush Cover**

    - Remove the main brush cover, then take out the main brush\.

    - Remove and clean the accessories on both ends\.

    - When reinstalling the cover, ensure that **all four sides are properly secured**\.

4. **Universal Wheel**

    - Turn the universal wheel to check whether it moves smoothly\.

    - If it does not, remove the black and white universal wheel for cleaning\.

5. **Driving Wheels**

    - Slide both driving wheels to confirm they can rotate and rebound properly\.

    - Clean them if necessary\.

6. **Dust Bin \& Filter**

    - Regularly clean the dust bin and filter components\.

    - 鈿狅笍 If the filter is washed with water, please ensure it is **completely dry** before reinstalling and using it again\.
