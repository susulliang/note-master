## Hotspot connection method: 鐑偣閰嶇綉

**Using a Mobile Hotspot for Connection Testing**

1. You can connect the robot to a mobile phone hotspot\. Once connected successfully, you can set functions in the APP such as scheduled cleanings\. Turning off the hotspot will only affect **remote control**, but the functions that have already been set will still work\. If you need to modify functions in the APP later, you will need to reconnect to the hotspot again\.

2. **How to set up the hotspot:**

    - Please try enabling a **2\.4GHz mobile hotspot** from another family member鈥檚 phone \(you can turn this on in your phone settings\)\.

    - Use your phone to connect to the Wi\-Fi signal shared by that hotspot\.

    - Then, use the same phone to connect the robot and check if the connection is successful\.

    - To make it easier, we recommend setting the hotspot name and password as a simple combination of numbers\.

    - After successfully connecting to the hotspot, you may also try changing your home Wi\-Fi name and password to match the hotspot, and then test the connection again\.

3. **Reason for testing with a hotspot:**

    - This helps determine whether the issue is with the **robot** or with the **home network**\.

    - If the robot connects successfully to the hotspot, it means the robot itself is working fine, and the connection failure is most likely related to the home Wi\-Fi network\.
