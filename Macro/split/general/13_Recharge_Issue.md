## Recharge issue/Unable to find charging station: 鏃犳硶鍥炲厖

1. **Check Power Supply**

- Please first confirm the base station has power\.

- To verify, check the indicator light on the front of the station:

    - If the light is on, the station has sufficient power\.

    - If not, kindly check the back of the station to ensure the power cord is firmly plugged in\.

    - If your station has a rocker switch near the power port, please make sure it is switched to the **鈥淚鈥?* position\.

2. **Test Return to Charging Dock**

- Place DEEBOT about **39 inches \(1 meter\)** straight in front of the Charging Dock\.

- Press the **Return to Charger** button to see if it returns smoothly\.

- If successful, please continue with the following checks:

3. **Further Troubleshooting Steps**

- Ensure all **protective strips** have been removed from the Charging Dock\.

- Wipe both the bumper and the dock sensors with a clean, dry cloth\.

- Confirm that DEEBOT starts cleaning **from the Charging Dock**\.

- Check the **placement of the Charging Dock**:

    1. Place it in an **open area** \(not in a narrow space\)\.

    2. Position it against a wall with at least **1\.6 ft \(0\.5 m\)** clearance on both sides, and **5 ft \(1\.5 m\)** in front\.

    3. Keep it away from devices that may cause **signal interference** \(e\.g\., routers, TVs\)\.

    4. Avoid placing it near reflective surfaces \(e\.g\., mirrors, glass windows\)\.

4. **Relocate Dock if Needed**

- If the issue persists, try changing the location of the Charging Dock and observe whether DEEBOT can dock properly\.
