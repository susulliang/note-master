# T20 Omni: How to set up carpet cleaning strategy 鍦版娓呮磥绛栫暐

- Please adjust the auto page to move upwards\.

- Please choose the option "Carpet Cleaning Strategy\."

- Please reopen the "Auto" function to allow the machine to lift the mopping plate when passing over the carpet, or alternatively select "Bypass" for the machine to pass over the carpet without mopping\.
