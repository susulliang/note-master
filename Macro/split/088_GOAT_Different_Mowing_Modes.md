1. Auto Mode
This mode allows for whole lawn mowing using the existing complete map with continuous mowing\.

    - Under normal conditions, the GOAT will automatically recharge when the battery level drops below 15% and will resume mowing after it reaches 85%\.

    - Recommended: For optimal mowing, the grass height should be less than 12cm\.
     

2. Area Mode
This mode allows you to select a specific zone from the existing map to mow\.

    - You can start mowing only within the designated zone\.
     

3. Edge Mode
When activated, the GOAT will focus solely on trimming/cutting the edges of your lawn\.

    - Edge Mode Settings can be found in Settings \> Robot \> Mowing Settings \> Edge Mode\.

4. Manual Mode
You will manually control the GOAT when the mowing task starts, using the remote control panel\.

    - Options include activating/deactivating the blade\-disc and adjusting the mowing height\.

    - Safety Note: During manual control, please stay within 3 meters of the robot to avoid accidents\.
     

5. Enhance Mode
Designed for grass heights between 10cm and 15cm, this mode will adjust obstacle avoidance to 25cm\.

    - We recommend setting No\-Entry Zones or physical barriers to block any dangerous areas\.
