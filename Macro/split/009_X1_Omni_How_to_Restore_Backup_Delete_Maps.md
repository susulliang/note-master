# X1 Omni: How to restore/backup/delete maps 鎭㈠/澶囦唤/鍒犻櫎鍦板浘

1. Navigate to *Map Management* for more options\.

2. Select the map currently in use and tap the *Edit* button\.

3. Choose *Restore Map* to revert to the previous version\. Once restored, you may then select *Back up Map* to save the current version again\.
