# X2 Omni: How to create a map 寤哄浘

Kindly adhere to the instructions provided below to create the map\. Additionally, a tutorial video has been attached at the end for your reference\.

**Preparations:**

1. Position the OMNI station against a wall in a clear area \(with no nearby obstacles\)\.

2. Ensure the Deebot is fully charged before initiating the map\-building process\.

3. Keep all doors open and clear any debris from the floor to facilitate a smooth path for the robot\.



**Initiating Map Building:**

4. Simply instruct the Deebot by saying "Ok Yiko, start quick mapping," and the Deebot will commence mapping your residence\.

5. While the map\-building process is underway, refrain from moving the Deebot or manually terminating the cleaning task through the app\. Allow the Deebot to continue mapping, and you will observe the map gradually taking shape within the app\. 

6. After the mapping process is finished, Deebot will autonomously return to the station, and the map will be saved automatically\. \(A successfully created map is displayed with distinct colors and labels for each area\.\)
