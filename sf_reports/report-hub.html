▮▮ Ecovacs Report Hub / R2 source report downloader

Authenticate with Salesforce first, then pull every report straight into sf_reports/. AWS Connect stays manual — its CSV link is dynamic.
One-time setup for automatic save location: set your browser's default download directory to (Chrome/Edge: Settings → Downloads → Location → Change). Every report download then lands in sf_reports/ automatically. Without this, each download asks where to save — choose the same folder.

How this works

The report URLs are plain GET endpoints. When a browser navigates to one, it sends your Salesforce session cookies and receives Content-Disposition: attachment — the file downloads immediately and this page never unloads. No page is ever rendered, which is why an iframe is useless here (Salesforce blocks embedding with X-Frame-Options anyway). Everything you need is a valid browser session:

  1. Click Open login window and log in (popup = top-level navigation, so Salesforce allows it).
  2. Click Test session — if a report file downloads without a login prompt, you are authenticated.
  3. Then use ⤓ Download buttons or Download all (SF). Chrome may ask "Allow multiple downloads?" once — click Allow.
  4. AWS Connect stays manual: open the page, then Actions → Download CSV (dynamic link).
Sync pipeline: after downloads finish, run REQUIRE_COMPLETE_DASHBOARD_DATA=1 npm run sync:reports, then publish to R2 with wrangler r2 object put eco-dash/dashboard-data.json --file dashboard_publish/dashboard-data.json --remote.
Raw files in sf_reports/ are untracked by Git — the R2 bucket is the single source of truth for the dashboard.
